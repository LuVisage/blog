## 一、Cypress 是什么

前端 E2E 测试框架，最大卖点是**开发者体验**：

- **时间旅行**：测试运行后可以看到每一步的快照；
- 自动等待，无需手写 wait；
- 浏览器内运行，可直接访问 `window`、DOM、网络请求；
- 交互式 Test Runner，实时看到每个命令的执行过程。

## 二、安装与初始化

```powershell
pnpm add -D cypress
npx cypress open      # 首次运行会生成 cypress/ 目录并打开界面
npx cypress run       # 无头模式运行
```

目录结构：

```
cypress/
├── e2e/              # 测试用例 *.cy.ts
├── fixtures/         # 测试数据（JSON）
├── support/
│   ├── commands.ts   # 自定义命令
│   └── e2e.ts        # 全局配置
└── downloads/
cypress.config.ts
```

## 三、配置

`cypress.config.ts`：

```ts
import { defineConfig } from 'cypress';

export default defineConfig({
  e2e: {
    baseUrl: 'http://localhost:5173',
    viewportWidth: 1280,
    viewportHeight: 720,
    video: false,
    screenshotOnRunFailure: true,
    retries: { runMode: 2, openMode: 0 },
    defaultCommandTimeout: 8000,
    specPattern: 'cypress/e2e/**/*.cy.{ts,tsx}',
    setupNodeEvents(on, config) {
      // 插件挂载点
      return config;
    },
  },
});
```

## 四、编写测试

```ts
describe('待办事项', () => {
  beforeEach(() => {
    cy.visit('/todos');
  });

  it('可以添加一条待办', () => {
    cy.get('[data-testid="new-todo"]').type('买牛奶{enter}');
    cy.get('[data-testid="todo-list"] li').should('have.length', 1);
    cy.contains('li', '买牛奶').should('be.visible');
  });

  it('可以勾选完成', () => {
    cy.get('[data-testid="new-todo"]').type('写周报{enter}');
    cy.contains('li', '写周报').find('input[type=checkbox]').check();
    cy.contains('li', '写周报').should('have.class', 'completed');
  });
});
```

### 常用命令

```ts
cy.visit('/login');
cy.get('#username').type('admin');
cy.get('button[type=submit]').click();
cy.get('.error').should('contain.text', '密码错误');
cy.get('input').clear().type('new');
cy.get('select').select('shanghai');
cy.get('input[type=file]').selectFile('fixtures/a.png');
cy.url().should('include', '/dashboard');
cy.title().should('eq', '控制台');
cy.reload();
cy.go('back');
```

断言链：

```ts
cy.get('.card')
  .should('have.length', 3)
  .first()
  .should('have.text', '标题')
  .and('be.visible');
```

### 网络请求

```ts
// 等待请求
cy.intercept('POST', '/api/login').as('login');
cy.get('form').submit();
cy.wait('@login').its('response.statusCode').should('eq', 200);

// Mock 响应
cy.intercept('GET', '/api/users', { fixture: 'users.json' }).as('users');
cy.visit('/users');
cy.wait('@users');
```

### 自定义命令

`cypress/support/commands.ts`：

```ts
Cypress.Commands.add('login', (username: string, password: string) => {
  cy.session([username, password], () => {
    cy.visit('/login');
    cy.get('#username').type(username);
    cy.get('#password').type(password);
    cy.get('form').submit();
    cy.url().should('include', '/dashboard');
  });
});
```

类型声明 `cypress/support/index.d.ts`：

```ts
declare global {
  namespace Cypress {
    interface Chainable {
      login(username: string, password: string): Chainable<void>;
    }
  }
}
export {};
```

`cy.session` 可缓存登录态，大幅加速测试套件。

## 七、Cypress vs Playwright

| 维度 | Cypress | Playwright |
| --- | --- | --- |
| 调试体验 | 时间旅行，最佳 | Trace / UI 模式，很好 |
| 架构 | 浏览器内执行 | CDP 外部控制 |
| 多标签页 | 有限（需 workaround） | 原生支持 |
| 浏览器覆盖 | Chromium 系 + Firefox/WebKit 实验 | 三大内核完整 |
| 免费并行 | 需 Cypress Cloud | 内置 |
| 上手门槛 | 低 | 低 |
| 适合 | 前端团队 / 快速起步 | 复杂场景 / 跨浏览器要求高 |

## 八、常见问题

| 问题 | 解决 |
| --- | --- |
| 元素找不到 | Cypress 自动重试，但确认定位器是否正确；避免用会变化的 class |
| 跨域访问失败 | 配置 `chromeWebSecurity: false`（仅测试环境）或 `cy.origin()` |
| 需要访问 `window` 上的变量 | `cy.window().then(win => ...)` |
| flaky 测试 | 用 `cy.intercept` 稳定网络；避免固定 `cy.wait(1000)` |
| 上传文件 | `cy.selectFile()`，注意路径相对 fixtures |
| 测试跑得慢 | 开启 `cy.session`；拆分 spec；只在 CI 用 `--record` 并行 |

## 九、最佳实践

1. 用 `data-testid` 定位，别依赖样式类名。
2. 不要滥用 `cy.wait(ms)`，改用 `cy.intercept` + `cy.wait('@alias')`。
3. `beforeEach` 中通过 API 快速准备数据，而非走完整 UI 流程。
4. 关键流程（登录）用 `cy.session` 缓存。
5. 只测 E2E 该测的东西（跨模块串联），细粒度逻辑放单元测试。
