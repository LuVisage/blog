## 一、工具定位

| 工具 | 角色 | 说明 |
| --- | --- | --- |
| pip | 包安装器 | Python 自带，基础工具 |
| venv | 虚拟环境 | 标准库自带，隔离依赖 |
| uv | 新一代一体化工具 | Rust 编写，安装依赖快 10-100 倍，可管理 Python 版本 |
| poetry | 项目依赖 + 打包 | 声明式依赖管理，pyproject.toml 为核心 |
| conda | 科学计算环境 | 可管理非 Python 依赖（CUDA、C 库），数据科学习惯 |

## 二、pip + venv（标准做法）

### 创建与激活虚拟环境

```powershell
# 创建
python -m venv .venv

# 激活（Windows PowerShell）
.\.venv\Scripts\Activate.ps1
# 若报执行策略错误，先执行：
# Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# macOS / Linux
source .venv/bin/activate

# 退出
deactivate
```

### 安装与管理依赖

```powershell
python -m pip install --upgrade pip
pip install requests flask
pip install "requests==2.32.0"     # 锁定版本
pip install -r requirements.txt
pip freeze > requirements.txt      # 导出当前环境（含版本）
pip uninstall requests
pip list
pip show requests
```

### 国内镜像加速

```powershell
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
# 常用：清华 tuna、阿里 mirrors.aliyun.com/pypi/simple
```

## 三、uv（强烈推荐，现代替代）

### 安装

```powershell
# Windows
winget install --id astral-sh.uv
# 或 powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
# macOS/Linux
brew install uv
```

### 核心用法

```powershell
uv python install 3.12          # 安装 Python 版本（替代 pyenv）
uv python list
uv init myproject               # 新建项目（生成 pyproject.toml）
uv venv                         # 创建虚拟环境（默认 .venv）
uv add requests                 # 添加依赖并写入 pyproject.toml + uv.lock
uv add --dev pytest             # 开发依赖
uv remove requests
uv sync                         # 按锁文件同步环境（CI 用 --frozen）
uv run python main.py           # 自动在项目环境中运行
uv run pytest                   # 无需先 activate
uv pip install -r requirements.txt   # 兼容 pip 工作流
uv tool install ruff            # 安装全局 CLI 工具（替代 pipx）
uvx ruff check .                # 临时执行工具（替代 pipx run）
```

`pyproject.toml` 示例：

```toml
[project]
name = "myproject"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = ["requests>=2.32", "click"]

[dependency-groups]
dev = ["pytest", "ruff"]
```

> uv 的速度优势明显：装 100 个包通常只需几秒，并自动缓存。

## 四、poetry（项目化管理）

```powershell
# 安装
pip install poetry
# 或 (irm https://install.python-poetry.org | iex) 官方脚本

poetry new myproject
poetry init                    # 在已有目录初始化
poetry add requests
poetry add --group dev pytest
poetry install                 # 安装全部依赖
poetry run python main.py
poetry shell                   # 进入虚拟环境
poetry lock
poetry build                   # 打包 wheel/sdist
poetry publish                 # 发布到 PyPI
```

特点：`pyproject.toml` 声明依赖，`poetry.lock` 锁死版本，打包发布一体化。

## 五、conda（科学计算 / 数据科学）

```powershell
# 安装：推荐 miniconda（轻量）
winget install Anaconda.Miniconda3
```

```powershell
conda create -n ml python=3.11
conda activate ml
conda install numpy pandas pytorch -c pytorch
conda install -c conda-forge jupyterlab
conda env export > environment.yml
conda env create -f environment.yml
conda deactivate
conda env list
```

优势：能装非 Python 依赖（CUDA toolkit、MKL 等），科研/深度学习项目常用。

## 六、如何选择

| 场景 | 推荐 |
| --- | --- |
| 一般 Web / 脚本 / 工具开发 | **uv**（新项目） / pip+venv（传统） |
| 需要发布 Python 包到 PyPI | poetry 或 uv |
| 深度学习 / 科研 | conda 或 uv + pip |
| CI 追求秒级安装 | uv（`uv sync --frozen`） |

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| PowerShell 禁止运行 Activate.ps1 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| `pip` 装到系统环境 | 先激活虚拟环境再操作；用 `where python` 确认路径 |
| 多个 Python 版本混乱 | 用 uv / pyenv 管理；`python -m pip` 确保用对应解释器 |
| 依赖冲突 | 用 uv/poetry 的解析器；或 `pip install --upgrade --force-reinstall` 单个排查 |
| 编译型包（如 lxml）安装失败 | 升级 pip，找预编译 wheel，或使用 conda |
| 换机后环境不一致 | 提交锁文件：uv.lock / poetry.lock / requirements.txt（带版本） |

## 八、最佳实践

1. **永远在虚拟环境中开发**，不要往系统 Python 装包。
2. 项目根目录放 `.python-version`（写 `3.12`），配合 uv/pyenv 自动切换。
3. 锁文件必须进 Git；`requirements.txt` 用 `pip freeze` 生成时注意剔除本地路径依赖。
4. **一个项目只用一个依赖管理工具**，不要 pip/poetry/conda 混用。
