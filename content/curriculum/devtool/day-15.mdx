## 一、安装

```powershell
# Windows
winget install Microsoft.VisualStudioCode
# macOS
brew install --cask visual-studio-code
# Linux
sudo snap install code --classic
```

便携版/免安装 ZIP 版适合放 U 盘；也可用 https://vscode.dev 网页版直接打开 GitHub 仓库。

| 快捷键 | 功能 |

| `Ctrl+.` | 快速修复（Quick Fix） |
| `Alt+↑/↓` | 移动行 |
| `Shift+Alt+↑/↓` | 复制行 |
| `Ctrl+/` | 注释/取消注释 |
| `Alt+点击` | 多光标 |
| `Ctrl+D` | 选中下一个相同词（多光标） |
| `Ctrl+Shift+L` | 选中所有相同词 |
| `Ctrl+Shift+K` | 删除整行 |
| `Ctrl+Enter` | 在下方插入新行 |

## 四、配置文件

### settings.json（用户级：`Ctrl+Shift+P` → "Open User Settings (JSON)"）

```jsonc
{
  // 编辑体验
  "editor.fontSize": 14,
  "editor.fontFamily": "'JetBrains Mono', Consolas, monospace",
  "editor.tabSize": 2,
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit",
    "source.organizeImports": "explicit"
  },
  "editor.rulers": [100],
  "editor.bracketPairColorization.enabled": true,
  "editor.guides.bracketPairs": "active",
  "editor.linkedEditing": true,
  "editor.suggestSelection": "first",
  "editor.stickyScroll.enabled": true,

  // 文件
  "files.autoSave": "onFocusChange",
  "files.trimTrailingWhitespace": true,
  "files.insertFinalNewline": true,
  "files.exclude": {
    "**/.git": true,
    "**/node_modules": true,
    "**/dist": true
  },
  "search.exclude": { "**/dist": true, "**/coverage": true },

  // 终端
  "terminal.integrated.defaultProfile.windows": "PowerShell",
  "terminal.integrated.fontSize": 13,

  // 语言专属
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": { "source.fixAll": "explicit" }
  },
  "[go]": { "editor.formatOnSave": true, "editor.defaultFormatter": "golang.go" },
  "[markdown]": { "editor.wordWrap": "on" },

  // Git
  "git.autofetch": true,
  "git.confirmSync": false,
  "gitlens.currentLine.enabled": true
}
```

### 项目级 `.vscode/settings.json`（提交 Git）

```jsonc
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "typescript.tsdk": "node_modules/typescript/lib",
  "eslint.workingDirectories": ["apps/web", "packages/ui"]
```

### `.vscode/extensions.json`（推荐扩展，团队自动提示安装）

```json
{
  "recommendations": [
    "dbaeumer.vscode-eslint",
    "esbenp.prettier-vscode",

  ]
```

### `.editorconfig`（跨编辑器统一基础风格）

```ini
root = true

[*]
charset = utf-8
end_of_line = lf
indent_style = space
indent_size = 2
insert_final_newline = true
trim_trailing_whitespace = true

[*.md]
trim_trailing_whitespace = false
```

## 五、高效功能

### 1. 多光标与批量编辑

- `Ctrl+D` 连续选同名单词；
- `Alt+点击` 任意位置加光标；
- `Ctrl+Shift+L` 全选同名后统一修改；
- 列选择：`Shift+Alt+拖动`。

### 2. 代码片段（Snippets）

`Ctrl+Shift+P` → "Configure User Snippets" → 选语言：

```jsonc
// typescriptreact.json
{
  "React FC": {
    "prefix": "rfc",
    "body": [
      "export function ${1:Component}() {",
      "  return <div>${2:content}</div>;",
      "}"
    ]
  }
}
```

### 3. 全局搜索技巧

- 支持正则：`Ctrl+Shift+F` → `.*` 图标；
- 文件过滤：`src/**/*.ts`；
- 排除：`!**/test/**`；
- 大小写/整词匹配：右侧按钮。

### 4. 任务与调试

`.vscode/tasks.json`：

```jsonc
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "dev",
      "type": "npm",
      "script": "dev",
      "isBackground": true,
      "problemMatcher": []
    }
  ]
}
```

`Ctrl+Shift+B` 直接运行构建任务。

### 5. 设置同步

登录 GitHub 账号 → `Ctrl+Shift+P` → "Turn on Settings Sync"，配置、快捷键、扩展、代码片段自动同步。

## 六、键盘流扩展推荐

- **Vim 模式**：装 Vim 扩展后可用 Vim 操作；
- **Multi-command / Macros**：串联多个命令；
- **Project Manager**：多项目秒切；
- **Error Lens**：错误直接显示在行尾。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 中文乱码 | 右下角编码 → Reopen with Encoding → UTF-8 |
| 保存后格式化结果不符预期 | 检查 defaultFormatter 与项目配置优先级 |
| TS 版本与项目不一致 | `typescript.tsdk` 指向 node_modules，右下角切换 |
| 扩展太多导致卡顿 | `Ctrl+Shift+P` → "Developer: Show Running Extensions" 排查 |
| 搜索不到 node_modules 里的东西 | search.exclude 默认排除，按需加 `!` 例外 |
| 远程开发 | 装 Remote - SSH / WSL / Dev Containers，本地只做界面 |
