## 一、Docker 是什么

Docker 用**容器**打包应用及其依赖，实现「一次构建，到处运行」：

| 概念 | 说明 |
| --- | --- |
| 镜像（Image） | 只读模板，如 `node:20-alpine` |
| 容器（Container） | 镜像的运行实例 |
| 仓库（Registry） | 镜像存储服务（Docker Hub / 私有仓库） |
| Dockerfile | 构建镜像的说明书 |
| 数据卷（Volume） | 持久化数据 |
| 网络（Network） | 容器间通信 |

## 二、安装

```powershell
winget install Docker.DockerDesktop
# 或（无桌面版）winget install Docker.DockerCLI + WSL2 中安装 docker-ce
```

安装后启动 Docker Desktop，验证：

```powershell
docker --version
docker run hello-world
```

**国内加速**：Docker Desktop → Settings → Docker Engine，添加：

```json
{
  "registry-mirrors": ["https://docker.mirrors.ustc.edu.cn", "https://hub-mirror.c.163.com"]
}
```

## 三、核心命令

### 镜像

```powershell
docker images                       # 列出本地镜像
docker pull nginx:alpine            # 拉取
docker rmi <image>                  # 删除
docker image prune -a               # 清理无用镜像
docker build -t myapp:1.0 .         # 构建
docker history myapp:1.0            # 查看层
docker tag myapp:1.0 user/myapp:1.0
docker push user/myapp:1.0
```

### 容器

```powershell
docker run nginx                                    # 前台运行
docker run -d --name web -p 8080:80 nginx           # 后台 + 端口映射
docker run -it ubuntu bash                          # 交互式
docker run --rm node:20 node -e "console.log(1)"    # 用完即删
docker ps                                           # 运行中的容器
docker ps -a                                        # 所有容器
docker logs -f web                                  # 跟踪日志
docker exec -it web sh                              # 进入容器
docker stop web && docker start web
docker rm web                                       # 删除
docker stats                                        # 资源占用
docker inspect web                                  # 详细配置 JSON
docker cp file.txt web:/app/
```

### 数据卷

```powershell
docker volume create data
docker run -v data:/var/lib/mysql mysql
docker run -v ${PWD}:/app -w /app node:20 npm test   # 挂载代码目录
docker volume ls
docker volume inspect data
```

### 网络

```powershell
docker network create mynet
docker run -d --name db --network mynet postgres
docker run -d --name api --network mynet -p 3000:3000 myapi
# 同网络内可直接用容器名访问： postgres://db:5432
docker network ls
```

## 四、Dockerfile 编写

### Node 应用（多阶段构建）

```dockerfile
# ---------- 构建阶段 ----------
FROM node:20-alpine AS builder
WORKDIR /app

# 先复制依赖描述文件，利用层缓存
COPY package.json pnpm-lock.yaml ./
RUN corepack enable && pnpm install --frozen-lockfile

COPY . .
RUN pnpm build

# ---------- 运行阶段 ----------
FROM node:20-alpine
WORKDIR /app
ENV NODE_ENV=production

COPY --from=builder /app/dist ./dist
COPY --from=builder /app/package.json ./

# 以非 root 运行
USER node
EXPOSE 3000
CMD ["node", "dist/server.js"]
```

### Python 应用

```dockerfile
FROM python:3.12-slim
WORKDIR /app
ENV PYTHONDONTWRITEBYTECODE=1 PYTHONUNBUFFERED=1

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .
RUN useradd -m appuser && chown -R appuser /app
USER appuser
EXPOSE 8000
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 静态前端 + Nginx

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY . .
RUN corepack enable && pnpm install --frozen-lockfile && pnpm build

FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### 关键指令

| 指令 | 说明 |
| --- | --- |
| FROM | 基础镜像 |
| WORKDIR | 工作目录 |
| COPY / ADD | 复制文件（ADD 可解压 tar/URL，一般用 COPY） |
| RUN | 构建时执行命令 |
| ENV | 环境变量 |
| ARG | 构建参数（`--build-arg`） |
| EXPOSE | 声明端口（仅文档性质） |
| VOLUME | 声明卷 |
| USER | 运行用户 |
| CMD | 默认命令（可被覆盖） |
| ENTRYPOINT | 入口命令（不易被覆盖） |
| HEALTHCHECK | 健康检查 |

## 五、`.dockerignore`

```
node_modules
dist
.git
.env
*.log
coverage
```

不忽略 node_modules 会导致：① 构建上下文巨大 ② 覆盖镜像内已安装依赖。

## 六、最佳实践

1. **多阶段构建**：构建工具不进最终镜像（体积可从 1GB 降到 100MB）。
2. **利用层缓存**：先 COPY 依赖描述文件并安装，再 COPY 源码。
3. **alpine / slim 基础镜像**：更小更安全；注意 glibc 兼容问题（必要时用 `-bookworm-slim`）。
4. **固定版本**：`node:20.11.1-alpine3.19` 而非 `node:latest`。
5. **非 root 用户**运行容器。
6. **一个容器一个进程**（不要塞 supervisord 跑多个服务）。
7. **镜像仓库用 tag 语义化**（`1.2.3`、`latest`、`sha-xxxx`）。
8. 定期 `docker system prune` 清理磁盘（会删未使用镜像/容器，谨慎）。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 端口被占用 | `netstat -ano \| findstr 8080` 查占用，改映射端口 |
| 容器启动就退出 | 主进程结束即退出；`docker logs` 查看；CMD 不要是后台命令 |
| 磁盘占用暴涨 | `docker system df` 查看；`docker system prune -a --volumes` |
| WSL2 磁盘不释放 | `wsl --shutdown` + Optimize-VHD 压缩 |
| 容器内时间/时区不对 | `-e TZ=Asia/Shanghai`，或镜像装 tzdata |
| 挂载 Windows 目录权限问题 | 使用 WSL 路径或 named volume；避免挂载 `/mnt/c` 做数据库存储 |
| 拉镜像超时 | 配置 registry-mirrors；或使用代理 |
| COPY 找不到文件 | 检查 `.dockerignore` 与构建上下文路径 |
