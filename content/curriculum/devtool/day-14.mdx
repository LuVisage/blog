## 一、Vite 是什么

Vite（法语「快」）是新一代前端构建工具，由 Vue 作者尤雨溪主导：

- **开发阶段**：基于原生 ESM 按需编译，启动**毫秒级**，HMR（热更新）极快；
- **生产阶段**：用 Rollup 打包（Vite 6 起也支持 Rolldown 实验特性）。

支持 React、Vue、Svelte、Solid、原生 JS 等。

## 二、创建项目

```powershell
pnpm create vite my-app
cd my-app
pnpm install
pnpm dev
```

常用模板：

```powershell
pnpm create vite my-react --template react-ts
pnpm create vite my-vue --template vue-ts
pnpm create vite my-lib --template vanilla-ts
```

## 三、项目结构

```
my-app/
├── index.html          # 入口 HTML（Vite 以此为构建入口）
├── src/
│   ├── main.ts
│   └── App.vue
├── public/             # 静态资源（原样拷贝）
├── vite.config.ts      # 配置文件
└── package.json
```

## 四、常用命令

```powershell
pnpm dev                # 开发服务器（默认 5173）
pnpm dev --port 3000    # 指定端口
pnpm dev --host         # 局域网可访问
pnpm build              # 生产构建 → dist/
pnpm preview            # 本地预览 dist 产物
pnpm build --mode staging   # 使用 .env.staging 环境变量
```

## 五、配置文件详解

```ts
// vite.config.ts
import { defineConfig, loadEnv } from 'vite';
import react from '@vitejs/plugin-react';
import path from 'node:path';

export default defineConfig(({ mode }) => {
  const env = loadEnv(mode, process.cwd());
  return {
    plugins: [react()],

    // 路径别名（需同步 tsconfig paths）
    resolve: {
      alias: { '@': path.resolve(__dirname, 'src') },
    },

    // 开发服务器
    server: {
      port: 5173,
      open: true,
      proxy: {
        '/api': {
          target: 'http://localhost:8080',
          changeOrigin: true,
          rewrite: (p) => p.replace(/^\/api/, ''),
        },
      },
    },

    // 构建选项
    build: {
      outDir: 'dist',
      sourcemap: false,
      target: 'es2018',
      chunkSizeWarningLimit: 800,
      rollupOptions: {
        output: {
          manualChunks: {
            vendor: ['react', 'react-dom'],
          },
        },
      },
    },

    define: {
      __APP_VERSION__: JSON.stringify(env.VITE_VERSION ?? 'dev'),
    },
  };
});
```

## 六、环境变量

只有 `VITE_` 前缀的变量会暴露给客户端：

```ini
# .env.development
VITE_API_BASE=http://localhost:8080/api

# .env.production
VITE_API_BASE=https://api.example.com
```

```ts
console.log(import.meta.env.VITE_API_BASE);
console.log(import.meta.env.MODE);       // development / production
```

> 敏感信息（密钥）不要放进 `VITE_` 变量，它们会打进前端产物。

## 七、静态资源处理

```ts
// 1. 直接导入，返回 URL（小于 4KB 自动转 base64）
import logo from './assets/logo.png';

// 2. 批量导入
const modules = import.meta.glob('./pages/*.vue');

// 3. 作为字符串导入
import content from './file.txt?raw';

// 4. 显式指定 URL
import url from './worker.js?url';
```

`public/` 目录下的文件按原路径访问（如 `public/favicon.ico` → `/favicon.ico`）。

## 八、配置代理解决跨域

开发时前端 5173 调后端 8080 会跨域，用 `server.proxy` 转发，前端统一请求 `/api` 即可，无需后端改 CORS。

## 九、性能优化清单

| 手段 | 做法 |
| --- | --- |
| 依赖预构建 | 默认自动；依赖变更时 `--force` 强制重建 |
| 分包 | `manualChunks` 拆分 vendor |
| 按需加载 | `React.lazy` / 动态 `import()` |
| 图片压缩 | `vite-plugin-imagemin` 或构建前预处理 |
| 分析体积 | `rollup-plugin-visualizer` |
| CDN 外链 | `vite-plugin-cdn-import` |
| Gzip/Brotli | `vite-plugin-compression` |

## 十、常见问题

| 问题 | 解决 |
| --- | --- |
| 启动后白屏 | 检查 `index.html` 入口路径、控制台报错 |
| 修改依赖不生效 | `pnpm dev --force` 重建预构建缓存 |
| 别名 `@` 报错 | 同时配 `vite.config.ts` 的 resolve.alias 与 `tsconfig.json` 的 paths |
| 构建内存溢出 | `NODE_OPTIONS=--max-old-space-size=4096` |
| 老浏览器不支持 ESM | 用 `@vitejs/plugin-legacy` 生成降级包 |
| 部署到子路径 404 | 设置 `base: '/my-app/'` |
