本仓库按功能分类整理了现代软件开发中常用的工具，每个分类一个文件夹，内含该分类的总览 README 与各工具的具体使用教程。

> 适用环境：本教程以 **Windows + PowerShell** 为主，同时给出 macOS / Linux 的差异说明。所有示例均可在本地直接复现。

## 建议学习路线

如果你是初学者，推荐按以下顺序学习：

1. **打基础**：Git（01）→ Node/包管理（02）→ 终端与命令行（08）
2. **写代码**：编辑器与 IDE（07）→ 调试与网络（06）
3. **保质量**：代码检查与格式化（04）→ 测试（05）
4. **上生产**：构建打包（03）→ 容器与部署（09）→ CI/CD（10）
5. **可观测**：数据库与中间件（11）→ 日志与监控（12）
6. **团队协作**：文档与协作（13）

## 阅读约定

- `$` 开头的命令表示在终端中执行；注释用 `#` 标注。
- 命令中的 `xxx` 为占位符，替换为你自己的名称。
- 涉及安装的部分，默认给出 Windows（winget / scoop / choco）方式，并补充 macOS（brew）与 Linux（apt / dnf）方式。
