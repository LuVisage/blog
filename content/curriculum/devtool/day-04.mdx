## 一、为什么要用图形客户端

命令行适合日常提交，但以下场景图形化效率更高：

- 解决**冲突**（3 路合并视图，逐块选择）
- **交互式 rebase**（拖拽重排、合并提交）
- 浏览**历史图谱**与文件级变更
- **暂存部分行**（hunk / line 级暂存，比 `git add -p` 直观）

## 二、主流客户端对比

| 工具 | 平台 | 收费 | 特点 |
| --- | --- | --- | --- |
| Fork | Win / macOS | 免费（速度极快，界面清爽，推荐入门） | 冲突解决体验好 |
| GitKraken | Win / macOS / Linux | 免费版 + 付费 | 界面华丽，内置 GitFlow、Issue 集成 |
| SourceTree | Win / macOS | 免费（Atlassian） | 老牌，GitFlow 支持，偶有卡顿 |
| VS Code 内置 Git | 全平台 | 免费 | 编辑器内完成提交/分支/冲突解决 |
| GitLens（VS Code 插件） | 全平台 | 免费 + 付费版 | blame、历史图谱增强 |

## 三、Fork 快速上手

1. 官网下载安装：https://git-fork.com/
2. `File → Open Repository` 选择本地仓库，或 `File → Clone` 克隆远程。
3. 主界面四区：
 - 左侧：本地分支 / 远程分支 / 标签
 - 中间：提交历史列表
 - 右侧：选中提交的文件变更
 - 底部：工作区文件（未暂存 / 已暂存）
4. 常用操作：
 - 勾选文件 → 填写提交信息 → **Commit**（或 Commit & Push）
 - 右键分支 → `Merge into current` / `Rebase onto` / `Delete`
 - 冲突时点击 **Resolve Conflicts**，逐块选 `Ours / Theirs / Both`

## 四、GitKraken 快速上手

1. 下载：https://www.gitkraken.com/
2. 登录 GitHub/GitLab 账号授权，可直接克隆云端仓库。
3. 特色功能：
 - 顶部 **Git Graph** 拖拽 rebase
 - `Pull Requests` 面板直接 review / merge
 - 内置 `GitFlow`（Init GitFlow 后自动建 develop 分支）
 - `Undo` 按钮（撤销上一步操作，非常实用）

## 五、SourceTree 快速上手

1. 下载：https://www.sourcetreeapp.com/
2. `Clone` 或 `Add` 本地仓库。
3. 常用：
 - 双击文件查看 diff；`暂存所有 / 暂存选中`
 - `Git Flow` 按钮初始化工作流
 - `仓库 → 仓库设置` 配置用户信息、远端

## 六、VS Code 内置 Git

无需额外安装，左侧源代码管理面板即可完成：

- **提交**：暂存（`+`）→ 输入信息 → `√` 提交
- **分支**：状态栏左下角点击分支名切换 / 新建
- **冲突**：打开冲突文件，点击 `Accept Current / Incoming / Both`，然后 `Mark as Resolved`
- **行级暂存**：在 diff 视图选中行 → `Stage Selected Ranges`

推荐配合 **GitLens** 插件：

```jsonc
// settings.json 常用配置
{
  "git.autofetch": true,               // 自动 fetch
  "git.confirmSync": false,
  "git.enableSmartCommit": true,       // 无暂存时直接提交全部
  "gitlens.currentLine.enabled": true  // 行尾显示 blame
}
```

## 七、冲突解决标准流程（通用）

```powershell
git fetch origin
git switch feature/login
git rebase origin/main       # 或 git merge origin/main
# 冲突后客户端内逐块解决
git add <已解决文件>
git rebase --continue        # merge 场景则 git commit
```

原则：**冲突解决后一定要跑一遍测试**，确保合并语义正确。

## 八、选择建议

- 个人开发 / 追求轻快：**Fork** 或 **VS Code 内置 Git**
- 团队可视化协作、要看 PR：**GitKraken**
- 公司统一 Atlassian 生态：**SourceTree**
- 轻度使用、不想装软件：**VS Code + GitLens**
