## 一、产品矩阵

| IDE | 面向语言/技术 | 说明 |
| --- | --- | --- |
| IntelliJ IDEA | Java / Kotlin / Spring | 旗舰产品，分 Community（免费）与 Ultimate（付费） |
| WebStorm | JavaScript / TypeScript / 前端框架 | 前端 IDE 标杆 |
| PyCharm | Python | 含数据科学工具，分 Community / Professional |
| GoLand | Go | 服务端 Go 开发 |
| RustRover | Rust | 相对较新，已取代 CLion 的 Rust 插件路线 |
| PhpStorm / CLion / Rider | PHP / C++ / .NET | 同类产品线 |

共同特点：**开箱即用的深度代码分析**、极强重构、数据库工具、调试器、测试集成。

## 二、安装与激活

1. 官网下载：https://www.jetbrains.com/
2. 用 **Toolbox App** 管理多个 IDE 与版本升级（推荐）；
3. 激活方式：
 - 个人订阅 / 公司授权；
 - 学生与教师免费（凭 edu 邮箱申请）；
 - 开源项目免费授权；
 - Community 版（IDEA / PyCharm）免费。

降低内存占用：`Help → Change Memory Settings` 调整 -Xmx（一般 2048-4096MB）。

## 三、核心优势（相对 VS Code）

| 能力 | JetBrains | VS Code |
| --- | --- | --- |
| 索引与代码理解 | 极强（整项目语义索引） | 依赖 LSP，稍弱 |
| 重构 | 业界最强（安全重命名、抽取、内联） | 基础可用 |
| 调试器 | 强大（条件断点、求值、远程） | 够用 |
| 数据库工具 | 内置（Ultimate 版） | 需扩展 |
| 框架支持 | 深度（Spring、Vue、React） | 靠插件 |
| 启动/内存 | 重（吃内存） | 轻 |
| 价格 | 收费（有免费版） | 免费 |

**结论**：重度工程开发（Java/Go/大型前端）值得付费；轻量场景 VS Code 足够。

## 五、各 IDE 上手要点

### IntelliJ IDEA（Java / Spring）

- 新建项目：`File → New Project` 选 Maven/Gradle + JDK；
- **Run/Debug Configurations** 配置启动项（Spring Boot 可一键识别）；
- 数据库工具（Ultimate）：右侧 Database → 添加数据源 → 直接执行 SQL；
- HTTP Client：`.http` 文件中写请求，点击运行（类似 Postman）；
- **Diagrams**：右键类 → Diagrams 看继承关系；
- 必备插件：Lombok（新版本内置支持）、MyBatisX、SonarLint、Key Promoter X（学快捷键）。

### WebStorm（前端）

- 内置 ESLint / Prettier / Tailwind 支持（无需额外装）；
- 保存时自动修复：`Settings → Languages & Frameworks → JavaScript → Code Quality → ESLint → Run eslint --fix on save`；
- 框架识别：`Settings → Languages → Framework` 开启 Vue/React 支持；
- `Alt+Enter` 对未安装的包可直接 `Install package`；
- 调试：`Run → Edit Configurations` 添加 npm/浏览器配置。

### PyCharm（Python）

- 解释器配置：`Settings → Project → Python Interpreter` 选 venv/conda/uv；
- 虚拟环境创建：`Add Interpreter → New`（自动装依赖）；
- **科学模式**：Jupyter notebook 内置，变量查看器；
- 调试 Django/Flask：Run Configuration 中直接指定框架；
- 重构：`Shift+F6` 重命名跨文件生效。

### GoLand（Go）

- 内置 Go Modules 支持，自动 `go mod tidy` 提示；
- 运行/调试：函数左侧绿色三角直接 Run Test；
- 代码检查：集成 go vet、golangci-lint（配置路径即可）；
- 远程调试：`Run → Edit Configurations → Go Remote`；
- 数据库/HTTP Client 同 IDEA。

### RustRover（Rust）

- 首次打开自动 cargo check 索引；
- 内置 clippy 提示、Cargo 工具窗口（依赖管理 UI）；
- 调试：LLDB 集成；
- 测试：点击左侧 ▶ 运行 #[test]。

## 六、通用效率功能

1. **Live Templates**：`Settings → Editor → Live Templates`，如 `psvm` 展开 main 方法；
2. **多光标**：`Alt+点击` 或用 `Ctrl+Shift+Alt+点击`；
3. **Local History**：右键文件/目录 → Local History，找回未提交的历史版本（救命功能）；
4. **终端与 VCS**：内置 Git 面板 + 冲突解决工具（3 窗格）；
5. **Database 工具**：连接 MySQL/PG/Redis，直接写 SQL 查数据；
6. **Profiler**：运行时可采样 CPU/内存（Ultimate）。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 索引卡住/CPU 高 | `File → Invalidate Caches` 重建索引；排除大目录 |
| 内存占用高 | 调 -Xmx；关掉不用的插件 |
| 快捷键与系统/输入法冲突 | `Settings → Keymap` 修改或换映射方案 |
| 中文注释显示异常 | 字体设置选择支持中文的字库（如微软雅黑） |
| 新建文件默认带版权头 | `Settings → Editor → File and Code Templates` 修改 |
| 恢复误删文件 | 项目右键 → Local History → Show History |
