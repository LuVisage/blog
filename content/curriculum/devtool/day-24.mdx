## 一、bat（带语法高亮的 cat）

### 安装

```powershell
winget install sharkdp.bat
# macOS
brew install bat
# Ubuntu
sudo apt install bat     # 命令名为 batcat，可 alias bat=batcat
```

### 基本用法

```powershell
bat file.ts                    # 带行号 + 语法高亮
bat -p file.ts                 # 纯净输出（无行号/文件头）
bat -n file.ts                 # 只要行号
bat -A file.txt                # 显示不可见字符（排查空白/换行问题）
bat file1.ts file2.ts          # 连续查看多文件
bat -r 10:20 file.ts           # 只看 10-20 行
bat -l json data.txt           # 指定语言高亮
bat --diff file1 file2         # 显示差异
```

### 常用配置

```powershell
# 主题
bat --list-themes
$env:BAT_THEME = "Dracula"

# 与 fzf 联动预览（配置文件写入 FZF_DEFAULT_OPTS）
--preview 'bat --color=always --style=numbers {}'
```

### 替代 cat 的注意点

`bat` 是**给人看的**，脚本中仍用 `cat`（bat 会加装饰、检测 TTY）。想在脚本中用高亮输出需加 `--style=plain`。

## 二、jq（JSON 处理利器）

### 安装

```powershell
winget install jqlang.jq
# macOS
brew install jq
# Ubuntu
sudo apt install jq
```

### 基本用法

```powershell
echo '{"name":"Ada","age":36}' | jq
# 输出格式化 JSON
```

```powershell
jq '.' data.json               # 格式化整个文件
jq '.name' data.json           # 取字段
jq '.user.name' data.json      # 嵌套字段
jq '.items[0]' data.json       # 数组第一项
jq '.items[]' data.json        # 展开数组
jq '.items[].name' data.json   # 取数组每项字段
jq -r '.name' data.json        # 原始字符串（去引号）
```

### 过滤、转换、聚合

```powershell
# 条件过滤
jq '.users[] | select(.age > 30)' data.json
jq '.users[] | select(.city == "上海") | .name' data.json

# 构造新对象
jq '{name: .name, city: .address.city}' data.json
jq '[.users[] | {n: .name}]' data.json

# 数组操作
jq 'sort_by(.age)' data.json
jq '[.users[].age] | add / length' data.json      # 平均年龄
jq '.users | length' data.json
jq '.users | group_by(.city)' data.json

# 修改后再输出
jq '.version = "2.0"' package.json
jq 'del(.devDependencies)' package.json
jq '.scripts.test = "vitest"' package.json
```

### 实战场景

```powershell
# 1. 从接口响应提取字段（配合 curl）
curl.exe -s https://api.github.com/repos/microsoft/vscode | jq '{name, stars: .stargazers_count, lang: .language}'

# 2. 查 package.json 的所有 scripts
jq -r '.scripts | to_entries[] | "\(.key)\t\(.value)"' package.json

# 3. 汇总 npm 依赖版本
jq -r '.dependencies | to_entries[] | "\(.key)@\(.value)"' package.json

# 4. 改 package.json（写回）
jq '.version = "1.0.1"' package.json > tmp.json && mv tmp.json package.json

# 5. 处理 JSON Lines（每行一个 JSON）
jq -s 'map(.level) | group_by(.) | map({level: .[0], count: length})' logs.jsonl

# 6. YAML 互转（需 yq）
yq -p yaml -o json config.yml | jq '.server.port'
```

### 常用选项

| 选项 | 含义 |
| --- | --- |
| `-r` | 原始字符串输出（去引号） |
| `-c` | 紧凑输出（单行） |
| `-s` | 把输入读成数组 |
| `-n` | 不读输入，用于生成 |
| `-e` | 结果为空时返回非零退出码 |
| `--arg k v` | 传入字符串变量 `$k` |
| `--slurpfile` | 读入文件为变量 |

### jq 语法小抄

```jq
.              # 当前值
.field         # 取字段
.[0]           # 数组索引
.[]            # 展开
|              # 管道
select(cond)   # 过滤
map(expr)      # 映射数组
type           # 类型：object/array/string/number/...
keys / values
has("key")
//             # 默认值： .name // "unknown"
```

## 三、tldr（简化版 man 手册）

### 安装

```powershell
winget install tldr
# macOS
brew install tldr
# 或 npm install -g tldr
```

### 用法

```powershell
tldr tar                     # 只显示最常用的几个例子
tldr git rebase
tldr docker compose
tldr --update                # 更新本地缓存
tldr --platform linux tar    # 指定平台
```

对比：

- `man tar`：几十页完整文档，含所有参数；
- `tldr tar`：5-8 条最常用示例，30 秒看完上手。

**推荐习惯**：新命令先 `tldr`，需要细节再 `man`。

## 四、组合实战

```powershell
# 1. 查看并高亮格式化 JSON
bat data.json | jq

# 2. 快速浏览日志中的错误并计数
rg "ERROR" app.log | jq -R 'split(" ") | .[3]' | sort | uniq -c | sort -rn | head

# 3. 交互式选择并查看文件
fd -e json | fzf --preview 'bat --color=always {} | jq'

# 4. 学新命令
tldr jq && tldr xargs

# 5. 检查文件隐藏字符（排查诡异格式问题）
bat -A suspicious.txt
```

## 五、常见问题

| 问题 | 解决 |
| --- | --- |
| bat 输出乱码/颜色缺失 | 终端不支持 256 色；设 `TERM=xterm-256color` |
| `bat` 在脚本中输出多余装饰 | 加 `-p`（plain）或改回 `cat` |
| jq 报 `Cannot iterate over null` | 先用 `jq type` 检查结构；用 `// []` 兜底 |
| jq 中文转义成 \\uXXXX | 加 `-r`；数据源编码问题另查 |
| jq 大文件内存爆 | 用 `--stream` 流式处理 |
| `tldr` 拿不到最新示例 | `tldr --update` 强制更新 |
| Windows 上 jq 引号麻烦 | 用单引号包表达式，或从文件读（`-f filter.jq`） |
