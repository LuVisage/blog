## 学什么

### 1. BFS：网格最短路与多源扩展
```cpp
int dx[4] = {0, 0, 1, -1}, dy[4] = {1, -1, 0, 0};
int step[1005][1005];      // -1 未访问
void bfs(int sx, int sy) {
    memset(step, -1, sizeof(step));
    queue<pair<int,int>> q;
    step[sx][sy] = 0; q.push({sx, sy});
    while (!q.empty()) {
        int x = q.front().first, y = q.front().second; q.pop();
        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i], ny = y + dy[i];
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;  // 越界
            if (a[nx][ny] == 0 || step[nx][ny] != -1) continue;  // 墙/已访问
            step[nx][ny] = step[x][y] + 1;
            q.push({nx, ny});
        }
    }
}
// 多源 BFS：把所有源点 step=0 全部入队
```
**真题：201409-4 最优配餐**（多源 BFS，T4 中难得的可满分题，**必须独立 AC**）、201604-4 游戏（BFS + 危险时刻状态，加时间维度）。

### 2. DFS 剪枝三板斧
1. **可行性剪枝**：当前状态已不可能到达目标 → 立刻返回；
2. **最优性剪枝**：当前代价 ≥ 已知最优解 → 立刻返回；
3. **记忆化**：算过的状态存下来（DFS + 数组）。

### 3. 博弈搜索（极大极小）与迭代加深
- 双方轮流、最终有胜负 → **极大极小搜索**：我方取 max、对方取 min，叶子是胜负判定；
- **真题：201803-4 棋局评估**——井字棋局面评分，直接写极大极小/打表枚举，注意"双方最优"含义；
- 迭代加深：限制 DFS 深度逐层增加（解在浅层时比 BFS 省空间）。
