## 学什么

**T1 的真相：** T1 考的不是算法，是**读题的细心程度**。历年 T1 失分原因排行：

1. 没看到某个条件（如"若相等输出较小者"、"四舍五入保留一位小数"）；
2. 输出格式错（空格、换行、前导零、`%.1f`）；
3. int 溢出（数据 10⁹ 级求和）；
4. 边界情况（n=1、全 0、全相等、首尾元素）。

**限时做题纪律（今天开始严格执行）：**

1. 读题 2 遍：第一遍通读，第二遍用笔划出**每一个**条件；
2. 先写伪代码或注释提纲再编码；
3. 样例过了 ≠ 全对：自造 2 组边界数据；
4. 到 20 分钟没写完 → 标红，看题解，记原因。

**T1 常见考点速查：**
- 纯模拟：按规则一步步翻译（坐标变换、报数、种苹果）；
- 枚举：确定枚举对象和范围（检测点查询、回收站选址）；
- 简单数学：平均数、方差、折扣（注意浮点）；
- 标记数组/桶计数：校门外的树、消除类游戏。

## 今日模板

完整版本见[代码模板速查手册](/learn/csp/templates)。

```cpp
// T1 最常用的就是格式化输出，务必烂熟
printf("%d\n", x);            // int
printf("%lld\n", y);          // long long 必须 %lld
printf("%.1f\n", z);          // 保留一位小数（自动四舍五入）
printf("%02d\n", a);          // 前导零
printf("%.2f%%\n", 25.0);     // 输出百分号要写 %%
```

**浮点小心得：** T1 涉及浮点时（平均数、折扣），能全程用 double 就全程 double；需要"四舍五入到整数"时用 `(int)(x + 0.5)`（正数），或 `round()`（注意包含 `<cmath>`，C++17 下 `std::round` 对 .5 是远离零取整，需验证）。
