1. 限时 90 分钟/题，做 2 道中等难度 T3 真题；
2. 复盘并生成你的"大模拟个人 checklist"。

## 做什么

**上午：201609-3 炉石传说（限时 90 分钟）**
- 考点：随从的召唤/攻击、位置插入删除 → `vector` 的 `insert/erase`；
- 注意：攻击规则细节（先结算对方死亡还是先扣英雄血——**看题！**）、vector 迭代器失效。

**备选替换（若上面做过了）：** 202209-3 防疫大数据（状态模拟，较新）。

## 限时纪律

- 严格按四步法：20 分钟读题划规则 → 10 分钟设计数据结构 → 45 分钟分函数编码 → 15 分钟自测；
- 超时 90 分钟 → 停笔看题解，把"卡住的点"记进错题本；
- **目标是 60+ 分**，不是 100 分——先把主体流程跑通，细节分再抠。

## 复盘（每道题考完必答，写进错题本）

3. 输出格式核对了吗？样例输出和我的是否**逐字符**一致？
4. 如果重做一遍，我会在哪些地方做得更快？

## 今日模板

完整版本见[代码模板速查手册](/learn/csp/templates)（第 2、3 节）。

```cpp
// vector 中插删（炉石传说这类"中间插入/删除"模拟的利器）
vector<int> v;
v.insert(v.begin() + pos, x);   // 在 pos 位置前插入 x
v.erase(v.begin() + pos);       // 删除 pos 位置的元素

// 网格 flood fill（画图填充）
int dx[4] = {0, 0, 1, -1}, dy[4] = {1, -1, 0, 0};
void dfs(int x, int y) {
    g[x][y] = ch;
    for (int i = 0; i < 4; i++) {
        int nx = x + dx[i], ny = y + dy[i];
        if (越界 || g[nx][ny] == 边界字符 || g[nx][ny] == ch) continue;
        dfs(nx, ny);
    }
}
```
