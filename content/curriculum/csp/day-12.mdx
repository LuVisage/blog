## 学什么

**DP 三步（卡住时就回来看）：**
1. **定义状态**：`dp[i]`（或 `dp[i][j]`）表示什么？一句话说清；
2. **转移方程**：当前状态由哪些已知状态推出？
3. **初始化与答案**：边界值是什么？答案在哪个位置取？

### 1. 线性 DP 经典
```cpp
// 最大子段和：dp[i] = max(a[i], dp[i-1] + a[i]); ans = max(dp[i])
// 数字三角形（自底向上免边界判断）：
for (int i = n - 1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        dp[i][j] += max(dp[i+1][j], dp[i+1][j+1]);   // 答案 dp[1][1]
```

### 2. 背包
```cpp
// 01 背包（每件最多一次）：容量倒序
int dp[1005] = {0};
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w[i]; j--)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

// 完全背包（每件无限次）：容量正序
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= W; j++)
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

// 多重背包（每件 c[i] 次）：二进制拆分后跑 01 背包
```

### 3. LIS（O(n log n)）与 LCS
```cpp
// LIS：v 数组是"贪心维护的最小结尾序列"
vector<int> v;
for (int i = 1; i <= n; i++) {
    auto it = lower_bound(v.begin(), v.end(), a[i]);  // 严格上升；非降用 upper_bound
    if (it == v.end()) v.push_back(a[i]);
    else *it = a[i];
}

// LCS：dp[i][j] = a 前 i 个与 b 前 j 个的最长公共子序列
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
        else dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
    }
```

### 4. 真题套路
- **202209-2 何以包邮**：01 背包变体——总价确定，求"和 ≥ x 的最小子集" → 等价于从总价中选若干书"不买"，求 ≤ (sum - x) 的最大值；
- **201312-4 有趣的数**：数位 DP 思想——按位构造，状态机转移（0→1→2→3 的合法顺序），可 DP 或打表找规律。
