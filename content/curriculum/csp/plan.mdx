## 零、考情与分数账（先算清这笔账）

### 0.1 考试形式

| 项目 | 说明 |
|---|---|
| 主办方 | 中国计算机学会（CCF） |
| 题目 | 5 道编程题，每题 100 分，满分 500 分，4 小时 |
| 语言 | C / C++ / Java / Python（**用 C++**） |
| 评测 | 每个测试点独立计分，**部分分是冲高分的重要来源** |
| 官网 | 报名与通知：[CCF认证管理系统](https://csp.ccf.org.cn/csp/show.action?_ack=1&code=exam_plan_seach)；历年真题：[cspro.org](https://www.cspro.org) |

### 0.2 题型规律（历年稳定）

| 题号 | 典型考点 | 冲高分目标 |
|---|---|---|
| T1 | 模拟 / 枚举 / 基础数学（送分） | **100，25 分钟内** |
| T2 | 模拟 + 一个技巧（前缀和/差分/二分/排序/map/贪心） | **100，35 分钟内** |
| T3 | **大模拟**：字符串解析、日期、复杂规则（题面 3~6 页） | **100（必须拿下）** |
| T4 | 图论 / DP / 数据结构（树状数组、线段树）/ 字符串 | **40~100**（中档题争取正解，难题拿部分分） |
| T5 | 极难；2023 年起部分场次改为**函数式/交互式评测**新形式 | **10~30**（子任务、暴力、特殊性质） |

### 0.3 400+ 分数账（这是你的路线图）

```
400 = T1(100) + T2(100) + T3(100) + T4(70) + T5(30)
```

- **300 分地基**：T1/T2/T3 全对。你有基础，这是完全可期的——难点只在 T3 的耐心和 T1/T2 的粗心。
- **T4 是主战场**：历年 T4 有相当一部分是"模板级"图论题（MST、最短路、BFS）和经典 DP，认真做完第 2 周的进阶训练，中档 T4 能正解；难题靠部分分（子任务/暴力）拿 40~60。
- **T5 是附加分**：不指望正解，认真读题拿子任务分。近年 T5 若为函数式交互评测，注意**语言环境与调用接口**（提交前确认评测要求，考试说明会写明）。

### 0.4 你的优劣势与对策

| 现状 | 对策 |
|---|---|
| 会 C++ / STL / 基础算法 | [Day 1](/learn/csp/day-01) 只做一天恢复，不浪费时间在语法上 |
| 手生、代码速度慢 | 前 7 天每天 3 道限时题，逼自己找回"敲键盘节奏" |
| 高阶算法（图论/DP/数据结构）可能薄弱 | 第 2 周系统补，每个模板练到默写 |
| 大模拟没系统练过 | T3 专项 3 天 + 每场模拟必做 T3 |

## 二、每日安排速览（细节在各 Day 文档）

### 第 1 周：恢复与稳分（目标：T1+T2+T3 = 300 到手）

**[Day 01](/learn/csp/day-01) · 恢复训练**：STL 全面复习（vector/string/sort/map/set/priority_queue/stack/queue）+ 基础算法过模板（gcd/快速幂/二分/前缀和），刷 5~6 道热身题找回手感。

**[Day 02](/learn/csp/day-02) · T1 真题限时**：T1 的考点永远只有"模拟+细心"。做 4 套近年 T1（202309/202303/202212/202209 + 备选老题），每题限 20 分钟，练到读题→AC 一气呵成。T1 失分 90% 是"没看到××条件"和"输出格式错"。

**[Day 03](/learn/csp/day-03) · T2 技巧①**：前缀和/差分/双指针 + 对应真题（202104-2 邻域均值、202203-2 出行计划、201809-2 买菜等）。

**[Day 04](/learn/csp/day-04) · T2 技巧②**：二分答案、结构体多关键字排序、贪心模型（区间调度/合并果子/部分背包）+ 真题（202303-2 垦田计划、202012-2 最佳阈值、202009-1 称检测点查询）。

**[Day 05](/learn/csp/day-05) · T2 技巧③ + 模拟考**：map/哈希计数（202305-1 重复局面）、数学类（201812-2 小明放学周期问题、202112-1 序列查询）。下午模拟考：一套真题的 T1+T2 共 2 题限时 60 分钟，目标 200 分。

**[Day 06](/learn/csp/day-06) · 大模拟方法论（上）**：四步法（精读划规则→设计数据结构→分函数实现边写边测→样例+自造数据验证）+ 精做 202212-3 JPEG 解码、201604-3 路径解析。

**[Day 07](/learn/csp/day-07) · 大模拟强化（下）**：限时 90 分钟/题，做 201609-3 炉石传说 + 202209-3 防疫大数据（或 201512-3 画图）。总结你的"大模拟 checklist"。

### 第 2 周：进阶算法（目标：T4 有正解能力）

**[Day 08](/learn/csp/day-08) · 字符串进阶**：KMP（next 数组）、字符串哈希（双哈希防冲突）、Trie（了解）。对应真题：201312-2 回顾 + 哈希练手。

**[Day 09](/learn/csp/day-09) · 并查集 + MST**：并查集模板、Kruskal、次小生成树（了解）。真题：201812-4 数据中心、201412-4 最优灌溉、201703-4 地铁修建。

**[Day 10](/learn/csp/day-10) · 最短路 + 拓扑排序**：Dijkstra（堆优化）、Floyd、SPFA（了解其风险）、拓扑排序（Kahn）。真题：201609-4 交通规划、201403-4 无线网络、201512-4 送货（欧拉路，了解）。

**[Day 11](/learn/csp/day-11) · 树状数组 + 线段树入门**：树状数组（单点改区间查/区间改单点查）、线段树（区间和/区间最值）。真题了解：202303-4 星际网络II（离散化）、202209-4 吉祥物投票。

**[Day 12](/learn/csp/day-12) · DP①**：线性 DP、01/完全/多重背包、LIS（O(nlogn)）、LCS。真题：202209-2 何以包邮、201312-4 有趣的数（数位 DP 思路）。

**[Day 13](/learn/csp/day-13) · DP②**：区间 DP（石子合并、201612-4 压缩编码）、树形 DP（树的直径、最大独立集）、状压 DP（TSP、202012-4 食材运输思路）。

**[Day 14](/learn/csp/day-14) · 搜索进阶**：DFS 剪枝（可行性/最优性/记忆化）、BFS（多源、双端）、迭代加深。真题：201803-4 棋局评估（博弈+搜索）、201604-4 游戏（BFS）、201409-4 最优配餐（多源 BFS）。

### 第 3 周：攻坚与冲刺（目标：模拟 380+）

**[Day 15](/learn/csp/day-15) · T4 图论真题攻坚**：限时 90 分钟做 2 道图论 T4（从 201812-4、201609-4、201403-4、201709-4 通信网络中选），目标每题 60+。

**[Day 16](/learn/csp/day-16) · T4 DP 真题攻坚**：限时做 2 道 DP 类 T4（201612-4 压缩编码、202012-4 食材运输只做子任务），学"先暴力后优化"的实战路径。

**[Day 17](/learn/csp/day-17) · T4 数据结构/字符串 + T5 部分分**：了解 202303-4 等线段树题；T5 策略课：**读题→找子任务→写小规模暴力→特殊性质特判**。做 2 套真题的 T5 只拿部分分。

**[Day 18](/learn/csp/day-18) · 全真模拟①**：最新一套完整真题（优先 2024 年场次），严格 4 小时 + 真实时间分配，考后打分复盘。

**[Day 19](/learn/csp/day-19) · 全真模拟②**：再一套，重点修正 [Day 18](/learn/csp/day-18) 暴露的问题（时间失控/粗心/卡题）。复盘后列出"考前最后检查清单"。

**[Day 20](/learn/csp/day-20) · 考前总复习**：闭卷默写全部模板 → 过错题本 → 背考场策略与时间分配表 → 准备物品。

### 附录 E：高频坑点清单

1. int 溢出 → long long（求和、10⁹ 级别数据、取模乘法）；
2. 浮点输出用 `printf("%.1f")`；浮点比较 `fabs(a-b) < 1e-6`；
3. `cin >> n` 后 `getline` 先 `cin.ignore()`；
4. 下标 1~n 的数组开 n+5；sort 区间 `sort(a+1, a+n+1)`；
5. 多组数据不清零；
6. 输出格式逐字符核对（空格/换行/`%%`/前导零）；
7. 样例过了 ≠ 全对：自造边界数据（n=1、全 0、全相等、空输入）；
8. T3 大模拟：先设计数据结构再编码，一个规则一个函数，写完就测；
9. 交卷前确认保存的代码是最终版本；
10. 若 T5 为函数式交互评测：**严格按题目要求的函数签名/接口提交，输出到 stdout 的调试信息要删掉**。
