## 学什么

### 大模拟四步法（贴在你的显示器上）

```
① 精读题面 2 遍，逐条编号规则（规则①规则②…），划出输入/输出格式
② 设计数据结构：题目让你维护什么？（数组/结构体数组/map/vector…）
   先设计，再编码！边写边改设计 = 时间黑洞
③ 分函数实现：一个规则 = 一个函数，写完一个立即用样例中间结果验证
④ 样例 + 自造数据（n=1、空串、0 值、全相等）全过才算完成
```

### T3 四大高频考点

1. **字符串解析**：分割、查找、类型转换（模板手册第 2、13 节）；
2. **状态机 / 多条规则顺序执行**：把每条规则写成一个函数，主流程像流水线；
3. **日期时间推进**：日期三板斧（模板手册第 6 节）；
4. **输出格式**：逐字符对照输出样例（空格、换行、四舍五入、前导零）。

### 精讲例题：202212-3 JPEG 解码

- **为什么选它**：规则完全给定、无歧义，几乎不考算法，只考"读题 + 翻译"，最适合建立信心。
- **流程**：
  1. 自己读题 20 分钟，把规则 ①②③④… 写在纸上；
  2. 尝试写 30 分钟（写不出不勉强）；
  3. 搜索"202212-3 JPEG 解码 题解"对照学习；
  4. **合上题解，独立重写直到 AC**。
- **本题考点拆解**：Z 字形扫描（按对角线走，注意方向交替）、量化（点乘）、离散余弦变换（照着公式四重循环）。

### 选做：201604-3 路径解析

- 考点：相对路径 → 绝对路径；处理 `.`、`..`、连续 `/`、根目录。
- 核心技巧：用 **vector/stack 存目录层级**，遇 `..` 弹栈，最后按 `/` 拼接输出。

## 今日模板

完整版本见[代码模板速查手册](/learn/csp/templates)（第 2、13 节）。

```cpp
// 字符串流切词
string line;
getline(cin, line);            // 前面若 cin >> n，先 cin.ignore()
stringstream ss(line);
string w;
while (ss >> w) { /* 处理 w */ }

// split：按分隔符切分
vector<string> split(const string &s, char sep) {
    vector<string> res;
    string cur;
    for (char c : s) {
        if (c == sep) { if (!cur.empty()) res.push_back(cur); cur.clear(); }
        else cur += c;
    }
    if (!cur.empty()) res.push_back(cur);
    return res;
}

// 整行读取的坑
cin >> n;
cin.ignore();                  // 吃掉换行符，否则下一行 getline 读到空串
getline(cin, line);
```
