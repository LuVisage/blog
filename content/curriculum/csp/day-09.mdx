## 学什么

### 1. 并查集：维护"分组的连通性"
```cpp
int fa[100005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }  // 路径压缩
void merge(int x, int y) { fa[find(x)] = find(y); }
// 初始化：for (int i = 1; i <= n; i++) fa[i] = i;
// 同组判断：find(x) == find(y)
```
**三大用途：** ① 动态连边判连通；② 判环（连边前已同组 → 成环）；③ 统计组数。

### 2. Kruskal：最小生成树 = 排序 + 并查集
```cpp
struct Edge { int u, v; long long w; } e[200005];
bool cmp(Edge a, Edge b) { return a.w < b.w; }
sort(e + 1, e + m + 1, cmp);
long long ans = 0; int cnt = 0;
for (int i = 1; i <= m; i++) {
    if (find(e[i].u) != find(e[i].v)) {   // 不同组才连（否则成环）
        merge(e[i].u, e[i].v);
        ans += e[i].w; cnt++;
        if (cnt == n - 1) break;
    }
}
// cnt < n-1 → 图不连通；最大生成树：cmp 改成 >
```

### 3. CSP T4 中的 MST 真题套路
历年多次直接/变相考 MST，识别关键词："连通所有节点、代价最小"：
- **201412-4 最优灌溉**：裸最小生成树；
- **201703-4 地铁修建**：问"最小化路径最大边" → 等价于 MST 中最大边（Kruskal 第 n-1 条边的权）；
- **201812-4 数据中心**：求 MST 的最大边权（root 无关，答案 = Kruskal 最后一条边）；
- **201503-4 网络延时**：不是 MST，是**树的直径**（两遍 DFS/BFS，见 [Day 13](/learn/csp/day-13)）。

**关键变式：最小化最大边 / 瓶颈问题 → 排序后逐条加边，首次全连通时的边权即答案。**
