## 今日任务

1. 复习并默写一维/二维前缀和、一维/二维差分；
2. 掌握双指针的两种形态（对撞、同向滑动窗口）；
3. 做 3 道 T2 真题 + 2 道洛谷强化。

## 学什么

**T2 的本质 = 模拟 + 一个技巧。** 今天三个技巧是 T2 出场率最高的。

### 1. 前缀和：把"多次查询区间和"从 O(n) 降到 O(1)
```cpp
// 一维（下标 1~n）：s[i] = s[i-1] + a[i]
// 区间和 [l, r] = s[r] - s[l-1]

// 二维：s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]
// 矩形和 (x1,y1)-(x2,y2) =
//   s[x2][y2] - s[x1-1][y2] - s[x2][y1-1] + s[x1-1][y1-1]
```
**什么时候想到它：** 题目要"多次求区间和 / 矩形和 / 统计某区域内满足条件的个数"。
真题例：**202104-2 邻域均值**（求每个像素邻域的平均值 → 二维前缀和）、**202012-2 期末预测之最佳阈值**（排序后统计两侧个数 → 前缀计数）。

### 2. 差分：把"多次区间整体加"从 O(n) 降到 O(1) 修改
```cpp
// 区间 [l, r] 每个数加 x：
d[l] += x;
d[r+1] -= x;
// 全部修改完，前缀和还原：
for (int i = 1; i <= n; i++) d[i] += d[i-1];   // d[i] 即最终值
// 二维差分：
d[x1][y1] += x; d[x2+1][y1] -= x;
d[x1][y2+1] -= x; d[x2+1][y2+1] += x;
// 还原：d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
```
**什么时候想到它：** "多次区间加减，最后问一次每个位置的值 / 某个位置的值"。
真题例：**202203-2 出行计划**（多次区间加 1，最后单点查询）、**201809-2 买菜**。

### 3. 双指针：O(n²) → O(n)
- **对撞型**：有序数组找两数关系（和大了右指针左移，小了左指针右移）；
- **同向型（滑动窗口）**：维护 [l, r] 满足某性质，r 扩张、l 收缩，各走一遍。
真题例：201809-2 买菜（双指针区间合并）。

## 今日模板

完整版本见[代码模板速查手册](/learn/csp/templates)（第 7 节）。

```cpp
// 一维前缀和
for (int i = 1; i <= n; i++) s[i] = s[i-1] + a[i];

// 二维前缀和
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++)
        s[i][j] = a[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1];

// 一维差分（区间加）
d[l] += x; d[r+1] -= x;          // 修改
for (int i = 1; i <= n; i++) d[i] += d[i-1];   // 还原
```
