## DP 类 T4 实战路径（背下来）

```
① 读题后先写 O(2^n) 或 O(n^2) 的暴力（搜索/枚举），保证小数据正确
② 观察暴力中哪些子问题被重复计算 → 这就是 DP 的状态
③ 定义 dp 数组 → 找转移 → 初始化 → 跑样例
④ 时间不够 / 状态想不出 → 保住①的暴力分，走人
```

**DP 题识别关键词：** 最优（最大/最小/最多/最少）、方案数、恰好/不超过、子序列/子数组/子集。
