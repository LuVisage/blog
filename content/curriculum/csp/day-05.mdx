## 学什么

### 1. map / set / unordered_map：计数与去重
```cpp
map<string, int> cnt;
cnt[s]++;                     // 计数
if (cnt.count(s)) { }         // 存在性判断
for (auto &p : cnt)           // 按 key 字典序遍历
    cout << p.first << " " << p.second << "\n";

set<int> st; st.insert(x); st.count(x); st.erase(x);   // 去重+有序

unordered_map<string, int> mp;   // 哈希表，平均 O(1)，不需要有序时更快
```
**什么时候想到它：** "统计每个键出现的次数 / 判断是否重复出现 / 去重"。
真题例：**202305-1 重复局面**（对局面字符串计数）、**202206-2 寻宝！大冒险！**（把树的坐标存进 map/set，O(1) 判断某点是否有树）、202006-2 稀疏向量（map 存非零项）。

### 2. 周期与取模数学题
"第 x 轮 / 第 x 步 / 无限循环"类问题，找规律落到一个周期内，用取模定位。
真题例：**201812-2 小明放学**——红绿灯周期变化，把到达时刻取模周期即可知道当时灯色。套路：先写"0 时刻灯状态 → 时刻 t 灯状态"的转换函数，再逐个路口推进。
```cpp
// 通用：当前时刻 t，灯周期 T，某状态持续 g 秒 → 时刻 t 的状态
int state = (t % T) 落在哪一段;
```

```cpp
map<string, int> cnt;  cnt[key]++;  cnt.count(key);

// 进制转换
string toK(long long n, int k) {
    string s;
    while (n) { s += char('0' + n % k); n /= k; }
    reverse(s.begin(), s.end());
    return s.empty() ? "0" : s;
}
```
