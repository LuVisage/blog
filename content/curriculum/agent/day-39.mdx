## 39.2 关键设计：知识检索做成"工具"而不是"链"

Day 10 你的知识库机器人是"检索→生成"的固定链。今天的客服 Agent 用另一种经典形态：**把检索器包成工具**，让 Agent 自己决定"要不要查资料"：

```python
@tool
def search_knowledge_base(question: str) -> str:
    """在星尘咖啡知识库中检索。回答会员制度/产品/门店政策前必须先调用。"""
    docs = retriever.invoke(question)
    return "\n\n".join(f"[{d.metadata.get('source')}] {d.page_content}" for d in docs)
```

**两种形态对比**（面试考点）：

| | 固定 RAG 链（Day 10） | Agent + 检索工具（今天） |
|---|---|---|
| 检索时机 | 每个问题都检索 | **模型判断**：闲聊不检索（省钱），专业问题才查 |
| 灵活性 | 固定流程 | 可检索多轮、可与其他工具组合 |
| 成本 | 每次都查 | 按需查 |
| 适用 | 纯问答机器人 | 多功能客服（问答+订单+记忆） |

客服需要"问订单就不查库、问政策才查库"，所以用工具形态。**系统提示词里要写清楚何时检索**，否则模型会偷懒或滥用。

## 39.3 动手：实施步骤

### 第一步：写 Agent 主文件

`capstone_agent.py` 骨架（完整参考见 examples/）：

```python
"""毕业项目：星尘咖啡智能客服 Agent"""
import os
from pathlib import Path
from typing import Any, Annotated
from dotenv import load_dotenv
load_dotenv(Path(__file__).resolve().parents[2] / ".env")

from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain.agents import create_agent
from langchain.agents.middleware import ToolRetryMiddleware, ToolCallLimitMiddleware
from langchain_core.documents import Document
from langchain_core.tools import tool
from langchain_milvus import Milvus
from langchain_classic.retrievers import ContextualCompressionRetriever
from langchain_classic.retrievers.document_compressors import LLMChainFilter
from langchain_core.prompts import ChatPromptTemplate
from langgraph.store.memory import InMemoryStore
from langgraph.prebuilt import InjectedStore

VERSION = "capstone-v1"
model = ChatOpenAI(model=os.environ["LLM_MODEL"], api_key=os.environ["LLM_API_KEY"],
                   base_url=os.environ["LLM_BASE_URL"], temperature=0)
embeddings = OpenAIEmbeddings(model=os.environ["EMBEDDING_MODEL"],
                              base_url=os.environ["EMBEDDING_BASE_URL"],
                              api_key=os.environ["EMBEDDING_API_KEY"],
                              check_embedding_ctx_length=False)

# ── ① 知识库入库 ─────────────────────────────
DOCS = [Document(page_content="会员积分规则：每消费 1 元积 1 分，500 分可兑换中杯，800 分兑换大杯。", metadata={"source": "会员手册"}), ...]
vs = Milvus(embedding_function=embeddings, connection_args={"uri": "./capstone_kb.db"},
            collection_name="stardust_kb", auto_id=True)
if vs.col:
    vs.drop_collection()
    vs = Milvus(...)   # 重建
vs.add_documents(DOCS)

# ── ② 检索器（宽召回 + 相关性过滤）────────────
base = vs.as_retriever(search_kwargs={"k": 4})
_filter = LLMChainFilter.from_llm(llm=model, prompt=...)
retriever = ContextualCompressionRetriever(base_compressor=_filter, base_retriever=base)

# ── ③ 检索工具 ───────────────────────────────
@tool
def search_knowledge_base(question: str) -> str:
    """在星尘咖啡知识库中检索。回答会员制度/产品/门店政策前必须先调用。"""
    ...

# ── ④ 业务工具：订单 + 记忆 ──────────────────
@tool
def check_order(order_id: str) -> str: ...

@tool
def remember_preference(content: str, store: Annotated[Any, InjectedStore()]) -> str: ...

@tool
def recall_preferences(store: Annotated[Any, InjectedStore()]) -> str: ...

# ── ⑤ 组装 Agent ────────────────────────────
store = InMemoryStore()
graph = create_agent(
    model=model,
    tools=[search_knowledge_base, check_order, remember_preference, recall_preferences],
    system_prompt=(
        "你是星尘咖啡客服。规则：\n"
        "1. 会员制度/产品/门店政策问题：必须先调 search_knowledge_base，只按检索结果回答并注明来源；\n"
        "2. 订单问题：调 check_order；\n"
        "3. 用户说'记住'：调 remember_preference；回答用户前先 recall_preferences 看偏好；\n"
        "4. 知识库和工具都没有的信息：明确说'抱歉，这个我还不清楚'，绝不编造。"
    ),
    middleware=[ToolRetryMiddleware(max_retries=2),
                ToolCallLimitMiddleware(run_limit=12)],
    store=store,
)
```
