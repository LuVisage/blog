## 40.2 部署上线：三种选择

### 方案 A：本地 Docker（免费，今天就能做）

```powershell
# 构建镜像（内含你的 Agent + LangGraph Server + 依赖）
cd D:\study\AI\agent\agent-tutorial\week-08-chatui-capstone\examples
D:\study\AI\agent\.venv-tutorial\Scripts\langgraph.exe build -t stardust-agent

# 在 WSL 里运行（复用你的 Docker）
wsl
docker run -p 2024:2024 stardust-agent
```

局域网内其他人访问 `http://你的IP:2024` 即可使用 API（前端另部署或本地跑）。

### 方案 B：LangGraph Platform 云托管（推荐正式部署）

`langgraph deploy` 一键部署到 LangChain 官方云：托管 Server + 持久化 + LangSmith 集成 + 一键分享 URL。**毕业项目的正式归宿**。

### 方案 C：自建（进阶挑战）

FastAPI + 自己的 checkpointer（Postgres）+ Nginx + 云服务器。全套自主可控，适合深入学习部署。

> 部署前必做清单：① checkpointer 换 Sqlite/Postgres（记忆持久化）；② `.env` 密钥用服务器环境变量而非文件；③ LangSmith tracing 打开；④ 评估集跑通（Day 39 的 baseline）。

## 40.6 给毕业生的三句话

1. **模型在变，工程不变**。LangChain 的 API 会升级（本教程已用 1.x 最新版），但 ReAct 循环、图编程、检索-生成、评估闭环这些**心智模型十年内不会过时**。
2. **评估集是你最贵的资产**。代码可以重写，评估集记录着"什么叫好"——从第一天就开始攒。
3. **去写一个真正有人用的 Agent**。教程教你造轮子，用户教你造好车。把你工作/生活里的真实痛点做成 Agent，是比任何教程都快的学习。
