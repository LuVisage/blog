## 15.1 项目需求

把 Day 14 的评估变成**可重复的实验流程**：

```
配置A（k=2，无优化）
配置B（k=5，无优化）
配置C（k=5，MultiQuery）
   │  每个配置：对评估集的每个问题 → 真实走检索 → 真实生成 → 记录
   ▼
RAGAS 打分
   ▼
输出对比表：哪个配置的 faithfulness / recall / precision 最高
```

**功能清单**：

1. 知识库：星尘咖啡 5 份文档（可自拟）；
2. 评估集：5 个问题 + 标准答案（写在代码里的列表）；
3. 三个候选配置：`{"k": 2}`、`{"k": 5}`、`{"k": 5, "multiquery": True}`；
4. 对每个配置：逐问题走完整 RAG 链（检索 → 生成），收集 `retrieved_contexts` 和 `response`；
5. 用 RAGAS 打分，打印对比表；
6. 输出结论："最优配置是 X，因为 Y 指标提升 Z%"。

## 15.2 设计要点（动手前必读）

### ① 评估集怎么造？

```python
EVAL_SET = [
    {"question": "积分怎么兑换饮品？", "reference": "500 分兑换中杯饮品，800 分兑换大杯。"},
    {"question": "生日买咖啡有优惠吗？", "reference": "生日当月消费享双倍积分。"},
    # ...至少 5 条，覆盖不同类型：精确事实、口语化、多信息综合
]
```

**好评估集的三条标准**：① 覆盖你的核心业务问题；② 混合问法（书面/口语/刁钻）；③ reference 可判定（一句话能说清标准答案）。

### ② 配置怎么组织？

```python
CONFIGS = {
    "A-k2":          {"k": 2, "multiquery": False},
    "B-k5":          {"k": 5, "multiquery": False},
    "C-k5-multi":    {"k": 5, "multiquery": True},
}
```

**一次只改一个变量**（对照实验第一原则）。A vs B 比 k；B vs C 比 MultiQuery。

### ③ 收集数据的循环

```python
samples = []
for question, reference in EVAL_SET:
    docs = retrieve(question, config)          # 按配置检索
    answer = generate(question, docs)          # 生成
    samples.append(SingleTurnSample(
        user_input=question,
        retrieved_contexts=[d.page_content for d in docs],
        response=answer,
        reference=reference,
    ))
```

**关键**：评估的输入必须来自**真实跑出来的结果**，不是手填的——否则测的是"你想象的系统"而非"真实的系统"。

## 15.4 参考实现骨架：`day15_experiment.py`

```python
"""Day 15 项目：RAG 实验台 —— 一键对比多配置"""
import os
from pathlib import Path
from operator import itemgetter
from dotenv import load_dotenv
load_dotenv(Path(__file__).resolve().parents[2] / ".env")

from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_milvus import Milvus
from langchain_classic.retrievers import MultiQueryRetriever
from ragas import evaluate, EvaluationDataset, SingleTurnSample
from ragas.metrics.collections import faithfulness, answer_relevancy, context_precision, context_recall
from ragas.llms import LangchainLLMWrapper
from ragas.embeddings import LangchainEmbeddingsWrapper

# ── 0. 基础设施 ─────────────────────────────────
model = ChatOpenAI(model=os.environ["LLM_MODEL"], api_key=os.environ["LLM_API_KEY"],
                   base_url=os.environ["LLM_BASE_URL"], temperature=0)
embeddings = OpenAIEmbeddings(model=os.environ["EMBEDDING_MODEL"],
                              base_url=os.environ["EMBEDDING_BASE_URL"],
                              api_key=os.environ["EMBEDDING_API_KEY"])

DOCS = [
    Document(page_content="会员积分规则：每消费 1 元积 1 分，500 分可兑换任意中杯饮品一杯，800 分兑换大杯。", metadata={"source": "会员手册"}),
    Document(page_content="生日当月消费可享双倍积分。", metadata={"source": "会员手册"}),
    Document(page_content="营业时间：工作日 8:00-22:00，周末 9:00-23:00。", metadata={"source": "门店信息"}),
    Document(page_content="退换货：咖啡豆未拆封 7 天内可退换；饮品制作完成后不支持退换。", metadata={"source": "售后政策"}),
    Document(page_content="手冲咖啡水温 88-93 度，粉水比 1:15 至 1:17。", metadata={"source": "咖啡知识"}),
]

EVAL_SET = [
    ("积分怎么兑换饮品？", "500 分兑换中杯，800 分兑换大杯。"),
    ("生日买咖啡划算吗？", "生日当月消费享双倍积分。"),
    ("你们家几点关门？", "工作日 22:00 关门，周末 23:00。"),
    ("买的豆子能退货吗？", "咖啡豆未拆封 7 天内可退换。"),
    ("有没有买一送一的活动？", "没有买一送一；积分可兑换饮品。"),
]

CONFIGS = {
    "A-k2":       {"k": 2, "multiquery": False},
    "B-k5":       {"k": 5, "multiquery": False},
    "C-k5-multi": {"k": 5, "multiquery": True},
}

# ── 1. 知识库与生成链 ───────────────────────────
vs = Milvus(embedding_function=embeddings, connection_args={"uri": "./milvus_exp.db"},
            collection_name="exp_docs", auto_id=True)
if vs.col:
    vs.drop_collection()
    vs = Milvus(embedding_function=embeddings, connection_args={"uri": "./milvus_exp.db"},
                collection_name="exp_docs", auto_id=True)
vs.add_documents(DOCS)

prompt = ChatPromptTemplate.from_messages([
    ("system", "仅根据资料回答，资料没有就说'资料中未提及'。\n\n{context}"),
    ("human", "{question}"),
])
rag_chain = ({"context": itemgetter("context"), "question": itemgetter("question")}
             | prompt | model | StrOutputParser())

# ── 2. 按配置构建检索器 ─────────────────────────
def make_retriever(config):
    base = vs.as_retriever(search_kwargs={"k": config["k"]})
    if config["multiquery"]:
        return MultiQueryRetriever.from_llm(retriever=base, llm=model)
    return base

# ── 3. 主实验循环 ───────────────────────────────
def run_experiment(config):
    retriever = make_retriever(config)
    samples = []
    for question, reference in EVAL_SET:
        docs = retriever.invoke(question)
        answer = rag_chain.invoke({
            "context": "\n\n".join(d.page_content for d in docs),
            "question": question,
        })
        samples.append(SingleTurnSample(user_input=question, retrieved_contexts=[d.page_content for d in docs],
                                        response=answer, reference=reference))
    result = evaluate(EvaluationDataset(samples=samples),
                      metrics=[faithfulness, answer_relevancy, context_precision, context_recall],
                      llm=LangchainLLMWrapper(model),
                      embeddings=LangchainEmbeddingsWrapper(embeddings))
    return result.to_pandas().mean(numeric_only=True)   # 取四个指标的均值

# ── 4. 跑全部配置 ───────────────────────────────
print("=" * 60)
for name, cfg in CONFIGS.items():
    print(f"\n🧪 配置 {name}（{cfg}）")
    print(run_experiment(cfg).round(2))
```

**骨架要点**：

- `make_retriever(config)` 把配置字典翻译成检索器——**新增配置只需加字典项**，这就是"实验台"的意义；
- `run_experiment` 是纯函数：配置进、分数出，可重复可对比；
- 最后的均值是"总览分"，真正分析时要看**分指标**（某个配置可能召回高但精确低，均值会掩盖）。
