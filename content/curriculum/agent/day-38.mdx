## 38.1 项目需求（一句话版）

> 为"星尘咖啡"做一个**智能客服**：回答会员制度/产品/门店等知识库问题，支持查订单、记偏好，有 Web 聊天界面，带监控评估，能部署给别人用。

展开成**功能清单**（验收标准）：

| # | 功能 | 用户故事 |
|---|---|---|
| F1 | 知识库问答 | 用户问"积分怎么兑换"，客服从文档中准确回答并**给出引用** |
| F2 | 订单查询 | 用户报订单号，客服调订单工具查状态 |
| F3 | 偏好记忆 | 用户说"我喜欢美式"，下次会话客服主动记得 |
| F4 | 诚实边界 | 知识库/工具都没有的信息，明确说不知道，不编造 |
| F5 | Web 界面 | 浏览器聊天、打字机效果、工具调用可视化、多会话 |
| F6 | 监控评估 | LangSmith 全链路追踪 + 回归评估集 |
| F7 | 部署 | 别人能通过 URL 访问（本地 Docker 或云托管） |

## 38.2 架构设计（动手前最重要的半小时）

```
┌────────────────────────── 前端 ──────────────────────────┐
│  agent-chat-ui（React + Next.js）                         │
│  聊天界面 / 工具调用卡片 / 多会话侧边栏 / configurable 传递  │
└──────────────────────────┬──────────────────────────────┘
                           │ HTTP/SSE（经 /api/chat 代理）
┌──────────────────────────▼──────────────────────────────┐
│  LangGraph Server（托管客服 Agent 图）                     │
│  ├─ RAG 链：Milvus 检索（星尘知识库）→ 生成               │
│  ├─ 工具：查订单 / 查天气 / 记偏好（Store 长期记忆）        │
│  ├─ Middleware：工具重试 + 调用上限                        │
│  ├─ Checkpointer：Sqlite 持久化（多轮记忆 + 断点恢复）      │
│  └─ 全部动作自动上报 LangSmith（tracing + metadata）       │
└──────────┬───────────────────────────┬──────────────────┘
           │                           │
     ┌─────▼─────┐              ┌──────▼──────┐
     │  Milvus    │              │   LLM API    │
     │ (Docker 或 │              │ (DeepSeek等) │
     │  Lite 文件) │              └─────────────┘
     └───────────┘
```

**设计决策**（每个决策都来自前 7 周的经验）：

1. **单 Agent + RAG 工具**，不用 Multi-agent——客服场景以检索为主，单 Agent 够用且便宜（**够用原则**）；
2. **检索优化上混合检索**（Day 12：向量+BM25）——客服问法口语化，纯向量召回不稳；
3. **诚实边界靠提示词 + 相关性过滤**（Day 11 的 LLMChainFilter）双保险；
4. **记忆双轨**：会话内用 checkpointer（Day 19），跨会话偏好用 Store（Day 24）；
5. **评估闭环**：LangSmith 评估集 10 条 + 在线反馈（Day 28-29）。

## 38.4 评估集设计（毕业答辩的"考卷"）

10 条测试用例，覆盖四类：

```python
EVAL_SET = [
    # ① 知识库精确问答（4 条）
    ("积分怎么兑换饮品？", "500 分兑换中杯，800 分兑换大杯"),
    ("生日有什么优惠？", "生日当月双倍积分"),
    ("咖啡豆能退货吗？", "未拆封 7 天内可退换"),
    ("营业到几点？", "工作日 22 点，周末 23 点"),
    # ② 工具调用（2 条）
    ("查订单 SF123456", "已发货"),
    ("北京天气怎么样？", "晴 25 度"),
    # ③ 诚实边界（2 条）
    ("你们股票代码多少？", "不知道/未提及"),
    ("推荐一只股票", "拒绝/不知道"),
    # ④ 口语化刁钻问法（2 条）
    ("买一送一有吗？", "没有买一送一；积分可兑换"),
    ("生日那天买咖啡划算不？", "双倍积分"),
]
```
