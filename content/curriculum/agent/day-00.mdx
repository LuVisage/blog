## 0.1 整体架构长什么样？（先建立全局认知）

在学习任何代码之前，先搞清楚你即将搭起来的东西长什么样：

```
┌─────────────────────────── 你的 Agent 应用 ───────────────────────────┐
│                                                                        │
│  ┌────────────┐   ┌─────────────┐   ┌──────────────┐                  │
│  │  LangGraph  │   │  LangChain  │   │   Milvus     │   ← 向量数据库    │
│  │  流程编排    │──▶│  组件(RAG等) │──▶│  (知识库)    │   (第2周装)       │
│  └────────────┘   └─────────────┘   └──────────────┘                  │
│         │                 │                                            │
│         ▼                 ▼                                            │
│  ┌─────────────────────────────────────────┐                          │
│  │         LLM 大模型（DeepSeek/GLM 等）     │  ← 需要 API Key           │
│  │         Embedding 模型（Ollama 本地）     │  ← 免费，本地运行          │
│  └─────────────────────────────────────────┘                          │
│         │                 │                                            │
│         ▼                 ▼                                            │
│  ┌─────────────────────────────────────────┐                          │
│  │      LangSmith 云端监控平台（可选）        │  ← 第 6 周重点            │
│  └─────────────────────────────────────────┘                          │
└────────────────────────────────────────────────────────────────────────┘
```

关键词解释（先混个脸熟，后面每天都会深入）：

- **LangChain**：组件库。给你"聊天模型、提示词模板、向量检索器、工具"这些乐高积木。
- **LangGraph**：编排引擎。把积木按流程图拼起来，支持循环、分支、暂停。
- **Milvus**：向量数据库。存"知识"的地方，RAG 的核心底座。
- **LangSmith**：监控平台。记录你的 Agent 每一步干了什么、花了多少钱、哪里出错。
- **Embedding**：把文字变成"数字向量"的模型，让机器能算两段文字"有多像"。

## 0.2 步骤一：创建 Python 虚拟环境

> **什么是虚拟环境？** 每个项目一个独立的 Python 库安装空间，互不污染。你的 A 项目用 LangChain 1.0，B 项目用旧版 0.3，两者井水不犯河水。

打开 **PowerShell**（Win + X → 终端），逐条执行：

```powershell
# 1. 进入你的学习目录
cd D:\study\AI\agent

# 2. 用 Python 创建虚拟环境，名字叫 .venv-tutorial
python -m venv .venv-tutorial

# 3. 激活虚拟环境（激活后命令行前面会出现 (.venv-tutorial)）
.\.venv-tutorial\Scripts\Activate.ps1
```

> **坑 1：PowerShell 禁止运行脚本。** 如果第 3 步报错"因为在此系统上禁止运行脚本"，先执行：
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```
> 输入 Y 确认，然后重新激活。
>
> **坑 2：每次新开终端都要重新激活。** 虚拟环境只在当前窗口生效，关掉终端就失效。判断方法：命令行开头有 `(.venv-tutorial)` 就是已激活。

## 0.3 步骤二：安装依赖全家桶

激活后执行（**约 3~5 分钟**，耐心等待）：

```powershell

python -m pip install -U pip

# 一次性安装本教程用到的所有库
python -m pip install langchain langchain-openai langchain-community langchain-text-splitters langgraph langchain-milvus "pymilvus[milvus_lite]" langchain-mcp-adapters langsmith ragas python-dotenv jieba
```

> 本机 pip 配置了清华镜像，偶尔会同步失败。指定官方源重试：

> python -m pip install -i https://pypi.org/simple &lt;包名>
> ```

```powershell
python -m pip list | findstr /i "langchain langgraph milvus langsmith ragas"
```

## 0.6 步骤五：跑通 Hello Agent

**这是你人生中第一个 Agent 程序。** 它不只是聊天——它有一个"计算器"工具，当你问数学题时，模型会**自己决定**调用工具、拿到结果、再组织答案。这就是 Agent 的本质：**模型 + 工具 + 决策循环**。

新建文件 `day-00-environment/hello_agent.py`：

```python
"""
Day 0 案例：Hello Agent —— 第一个带工具调用的智能体
运行：python hello_agent.py
"""
import os
from dotenv import load_dotenv

# 1. 读取 .env 文件里的配置（key、模型名等）
load_dotenv()

# 2. 导入 LangChain 1.x 的统一 Agent 入口 create_agent
#    （旧教程里的 create_react_agent / AgentExecutor 已被它取代）
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI

# 3. 创建"大脑"：对话模型。ChatOpenAI 不止能连 OpenAI，
#    任何 OpenAI 兼容协议的服务（DeepSeek/智谱/通义/Ollama）都通过它接入。
llm = ChatOpenAI(
    model=os.environ["LLM_MODEL"],          # 例如 deepseek-chat
    api_key=os.environ["LLM_API_KEY"],      # 你的密钥（DeepSeek 兼容协议）
    base_url=os.environ["LLM_BASE_URL"],    # 例如 https://api.deepseek.com
    temperature=0,                           # 0=每次回答尽量稳定，便于调试
)

# 4. 定义工具：就是一个普通 Python 函数 + @tool 装饰器。
#    docstring（函数说明）会被自动发给模型，模型靠它决定"什么时候该用我"。
from langchain_core.tools import tool

@tool
def multiply(a: float, b: float) -> float:
    """计算两个数的乘积 a * b。当用户需要乘法计算时使用。"""
    return a * b

# 5. 创建 Agent：把大脑和工具绑在一起。
#    system_prompt 定义它的"人设"。
agent = create_agent(
    model=llm,
    tools=[multiply],
    system_prompt="你是一个友好的中文数学助手。优先使用工具计算，不要心算。",
)

# 6. 运行！agent 内部会自动执行 ReAct 循环：
#    思考 → 决定调工具 → 观察结果 → 再思考 → 输出最终答案
result = agent.invoke(
    {"messages": [{"role": "user", "content": "12345 乘以 67890 等于多少？"}]}
)

# 7. 打印最终答案（messages 列表的最后一条）
print("Agent 回答：", result["messages"][-1].content)
```

运行：

```powershell
cd D:\study\AI\agent\agent-tutorial\day-00-environment
python hello_agent.py
```

**预期输出**（能跑通就说明环境 OK）：

```
Agent 回答： 12345 × 67890 = 838,102,050
```

> **如果它直接心算回答、没有调用工具也没关系**——DeepSeek 心算能力强。Day 21 会教你在 LangSmith 里看到它内部每一步的决策。现在只要程序跑通、答案正确就算过关。

### 逐行解剖（建立第一印象，细节后几周展开）

| 代码 | 作用 |
|---|---|
| `load_dotenv()` | 把 `.env` 里的 `LLM_API_KEY` 等读成环境变量 |
| `ChatOpenAI(model=..., base_url=...)` | 创建模型客户端。`base_url` 换成谁就连谁，这是"OpenAI 兼容协议"的好处 |
| `@tool` + docstring | 把普通函数升级成"模型可用工具"；**docstring 就是工具的说明书**，写得好不好直接影响 Agent 水平 |
| `create_agent(model, tools, system_prompt)` | LangChain 1.0 的统一入口，内部自动搭好 ReAct 循环（LangGraph 图） |
| `agent.invoke({"messages": [...]})` | 输入必须是 `messages` 键的消息列表；返回也是 messages 列表 |
| `result["messages"][-1].content` | 最后一条消息 = 模型最终回答；`.content` 取纯文本 |
