## 35.1 项目需求

做一个**研究助理团队**：

```
任务："写一篇关于杭州的小短文，文中要有 123×45 的计算结果"

Supervisor（主管）
   ├─▶ Researcher（研究员）：web_search 查资料 + 【MCP 协议】调 math server 算数
   └─▶ Writer（写手）：整合事实成文
```

**验收标准**：

1. 研究员通过 **MCP 协议**（不是直接 @tool）调用计算工具，算出 123×45=5535；
2. 研究员通过本地工具查资料；
3. 主管调度 researcher → writer，写手产出含计算结果的文章；
4. 全程流程清晰可观测（打印每个节点的动作）。

## 35.2 设计要点（动手前必读）

### ① MCP 接入复用 Day 32 的模式

```python
client = MultiServerMCPClient({"math": {...stdio 配置...}})
async with client.session("math") as session:
    mcp_tools = await load_mcp_tools(session)
```

MCP 工具是异步的 → 整个团队要用 `ainvoke`，主管/研究员/写手全部异步化。

### ② 混合工具清单：研究员 = 本地工具 + MCP 工具

```python
researcher = create_agent(
    model=model,
    tools=[web_search] + mcp_tools,     # ★ 本地 @tool 和 MCP 工具无缝混用！
    system_prompt="你是研究员。查资料用 web_search，算术必须用 multiply/add 工具。",
)
```

**这是 MCP 的杀手锏场景**：你的团队代码不用改，新增能力 = 新增一个 MCP Server 配置。

### ③ Supervisor 复用 Day 33 的双规则兜底

第一轮强制 researcher；writer 已产出就 FINISH。弱模型下这是收敛的保证。

## 35.3 动手：项目验收流程

1. **先自己写**（60~90 分钟），复用 Day 32 的 MCP 连接代码 + Day 33 的 Supervisor 结构；
2. **测试**：
   - 任务输入后，观察：主管 → researcher（查资料 + MCP 算数）→ writer（成文）→ FINISH；
   - 验证文中出现 5535（MCP 计算的结果）；
3. **加分**：给 writer 也配一个 MCP 工具（如字数统计 server）；
4. **自查**：MCP 连接正常（server 日志出现 CallToolRequest）；异步调用无遗漏。

## 35.4 参考实现骨架：`day35_research_team.py`

```python
"""Day 35 项目：多智能体研究助理 —— Supervisor + MCP（第 7 周毕业作品）"""
import asyncio
import os
from pathlib import Path
from typing import Annotated, Literal, TypedDict
from operator import add
from dotenv import load_dotenv
load_dotenv(Path(__file__).resolve().parents[2] / ".env")

from pydantic import BaseModel, Field
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent
from langchain_core.tools import tool
from langgraph.graph import StateGraph, START, END
from langgraph.types import Command
from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain_mcp_adapters.tools import load_mcp_tools

model = ChatOpenAI(model=os.environ["LLM_MODEL"], api_key=os.environ["LLM_API_KEY"],
                   base_url=os.environ["LLM_BASE_URL"], temperature=0)

# ── ① 本地工具：查资料 ──────────────────────────
@tool
def web_search(query: str) -> str:
    """搜索互联网资料。研究事实性问题时使用。"""
    data = {"杭州": "杭州是浙江省会，数字经济发达，有阿里巴巴等企业，西湖闻名天下。"}
    return data.get(query, f"关于'{query}'：经济活跃、文化深厚。")

# ── ② 主管决策结构 ─────────────────────────────
class Decision(BaseModel):
    next: Literal["researcher", "writer", "FINISH"]

def supervisor(state) -> Command:
    if state.get("next", "") == "" and not any(getattr(m, "type", "") == "tool" for m in state["messages"]):
        return Command(goto="researcher", update={"next": "researcher"})
    if state.get("next", "") == "writer":
        return Command(goto=END, update={"next": "FINISH"})
    decision = model.with_structured_output(Decision).invoke(
        state["messages"] + [{"role": "system", "content": "资料不足→researcher；可以写作→writer；完成→FINISH。"}])
    goto = END if decision.next == "FINISH" else decision.next
    return Command(goto=goto, update={"next": decision.next})

class State(TypedDict):
    messages: Annotated[list, add]
    next: str

async def main():
    # ── ③ 连接 MCP Server（数学工具走协议）───────
    client = MultiServerMCPClient({
        "math": {"command": "python",
                 "args": [str(Path(__file__).parent / "mcp_math_server.py")],
                 "transport": "stdio"},
    })
    async with client.session("math") as session:
        mcp_tools = await load_mcp_tools(session)
        print("MCP 工具就绪：", [t.name for t in mcp_tools])

        # ── ④ 研究员（本地工具 + MCP 工具混合）───
        researcher = create_agent(
            model=model, tools=[web_search] + mcp_tools,
            system_prompt="你是研究员。查资料用 web_search；算术必须用 multiply/add 工具，不要心算。")
        writer = create_agent(
            model=model, tools=[],
            system_prompt="你是写手。根据资料写一篇短文，保留其中的数据。")

        # ── ⑤ 组装 Supervisor 图（同 Day 33）────
        graph = StateGraph(State)
        graph.add_node("supervisor", supervisor)
        graph.add_node("researcher", researcher)
        graph.add_node("writer", writer)
        graph.add_edge(START, "supervisor")
        graph.add_edge("researcher", "supervisor")
        graph.add_edge("writer", "supervisor")
        app = graph.compile()

        # ── ⑥ 运行（注意 MCP 工具是异步的 → ainvoke）──
        result = await app.ainvoke(
            {"messages": [{"role": "user", "content":
                "写一篇关于杭州的短文，文中要包含 123 乘以 45 的结果。"}], "next": ""})
        print("\n📄 最终文章：\n", result["messages"][-1].content)

asyncio.run(main())
```

**骨架要点**：

- **① vs ③ 的对比是本项目精髓**：`web_search` 是本地 `@tool`，`multiply/add` 是 MCP 协议工具——在 `tools=[web_search] + mcp_tools` 里**无缝混用**，Agent 感知不到区别；
- **⑥ 必须 `ainvoke`**：MCP 工具异步（Day 32 的坑）；
- 主管逻辑照搬 Day 33（含两条规则兜底）。
