## 一、决策树的基本结构

```
                    色泽 = ?
              ┌───────┼───────┐
           青绿     乌黑     浅白
             │       │        │
        根蒂=?    好瓜      坏瓜
        ┌──┴──┐
      蜷缩   硬挺
        │      │
      好瓜    坏瓜
```

| 术语 | 含义 |
| --- | --- |
| 根结点 | 包含全部样本 |
| 内部结点 | 一个属性的测试 |
| 叶结点 | 决策结果（类别） |
| 分支 | 属性的一个取值 |
| 路径 | 从根到叶的一条判断规则 |

**"分而治之"**：每次选一个属性把数据集切分，递归处理子集，直到子集"足够纯"或无法再分。

## 二、信息熵：怎么度量"纯度"

回忆 Week01 Day5：

$$H(D) = -\sum_{k=1}^{|\mathcal{Y}|} p_k \log_2 p_k$$

其中 $p_k$ 是第 $k$ 类样本在 $D$ 中占的比例。

**性质**：

| 情形 | 熵 |
| --- | --- |
| 全是同一类（最纯） | $H = 0$ |
| 各类均匀（最乱） | $H = \log_2 k$（最大） |

**例**（西瓜书表 4.1 的简化）：
- 数据集 17 个样本：8 个好瓜、9 个坏瓜
- $H(D) = -\frac{8}{17}\log_2\frac{8}{17} - \frac{9}{17}\log_2\frac{9}{17} = 0.998$

**熵越小 ⇒ 纯度越高 ⇒ 越好。**

## 三、信息增益

### 3.1 条件熵

用属性 $a$ 划分后，各子集的熵的**加权平均**：

$$H(D \mid a) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} H(D^v)$$

其中 $V$ 是属性 $a$ 的取值个数，$D^v$ 是 $a$ 取值为 $v$ 的样本子集。

**含义**：知道属性 $a$ 之后，数据集还剩多少不确定性。

### 3.2 信息增益

$$Gain(D, a) = H(D) - H(D\mid a)$$

**含义**：**用属性 $a$ 划分，能带来多少"纯度提升"（不确定性减少）。**

**ID3 的划分准则**：

$$a_* = \arg\max_{a} Gain(D, a)$$

### 3.3 完整手算示例

**数据集 $D$**（简化版）：14 个样本，正例 7、负例 7。

| 属性 | 取值分布 |
| --- | --- |
| 色泽 | 青绿 6、乌黑 5、浅白 3 |
| 根蒂 | 蜷缩 7、稍蜷 4、硬挺 3 |

**第一步：根结点熵**

$$H(D) = -\frac{7}{14}\log_2\frac{7}{14} - \frac{7}{14}\log_2\frac{7}{14} = 1.0$$

**第二步：计算"色泽"的条件熵**

假设划分后：

| 色泽 | 样本数 | 正例 | 负例 | 熵 |
| --- | --- | --- | --- | --- |
| 青绿 | 6 | 5 | 1 | $-\frac{5}{6}\log_2\frac{5}{6}-\frac{1}{6}\log_2\frac{1}{6} = 0.650$ |
| 乌黑 | 5 | 2 | 3 | $-\frac{2}{5}\log_2\frac{2}{5}-\frac{3}{5}\log_2\frac{3}{5} = 0.971$ |
| 浅白 | 3 | 0 | 3 | $0$ |

$$H(D\mid\text{色泽}) = \frac{6}{14}\times0.650 + \frac{5}{14}\times0.971 + \frac{3}{14}\times0 = 0.625$$

$$Gain(D, \text{色泽}) = 1.0 - 0.625 = 0.375$$

**第三步**：对"根蒂"同样计算，假设得到 $Gain = 0.201$。

因为 $0.375 > 0.201$，**选择"色泽"作为第一个划分属性**。然后对每个子集递归重复这个过程。

## 四、信息增益的缺陷

### 4.1 偏好取值多的属性

**极端反例**：假设有一个属性"编号"（14 个样本 14 个不同取值）。

用它划分会得到 14 个子集，每个子集只有一个样本，**每个子集的熵都是 0**：

$$H(D\mid\text{编号}) = \sum_{v=1}^{14}\frac{1}{14}\times 0 = 0$$

$$Gain(D, \text{编号}) = 1.0 - 0 = 1.0 \quad\text{（最大！）}$$

**但这个划分毫无意义**——它只是"记住了每个样本"，对预测新样本毫无帮助。

### 4.2 数学解释

取值越多 ⇒ 每个子集越小 ⇒ 越可能"恰好纯" ⇒ 条件熵越容易小。

$$|D^v| \to 1 \quad\Rightarrow\quad H(D^v) \to 0 \quad\Rightarrow\quad H(D|a) \to 0 \quad\Rightarrow\quad Gain \to H(D)$$

**信息增益天然偏爱"把数据切得很碎"的属性。**

Day2 的 C4.5 用"增益率"修正了这一点。

## 五、递归建树算法

```
ID3(D, A):                          # D: 数据集, A: 候选属性集
    1. 若 D 中样本全属同一类 c        → 返回叶结点 c
    2. 若 A 为空，或 D 在 A 上取值全同  → 返回叶结点(多数类)
    3. 否则:
       对每个 a ∈ A 计算 Gain(D, a)
       a* = argmax Gain
       用 a* 生成结点
       对 a* 的每个取值 v:
           D_v = D 中 a* = v 的子集
           若 D_v 为空 → 接一个叶结点(多数类)
           否则 → 递归 ID3(D_v, A \ {a*})
```

**三个递归终止条件**（缺一不可）：

| 条件 | 处理 |
| --- | --- |
| 子集全部同类 | 叶结点 = 该类 |
| 属性用完了 | 叶结点 = 多数类 |
| 子集为空 | 叶结点 = 父结点多数类（"先验"） |

## 六、代码实践

```python
import numpy as np
from collections import Counter

def entropy(y):
    """信息熵（以 2 为底，单位 bit）"""
    n = len(y)
    if n == 0:
        return 0.0
    counts = Counter(y)
    return -sum((c / n) * np.log2(c / n) for c in counts.values())

def information_gain(X, y, feature_idx):
    """Gain(D, a) = H(D) - sum(|D_v|/|D|) * H(D_v)"""
    parent = entropy(y)
    total = len(y)
    cond = 0.0
    for v in np.unique(X[:, feature_idx]):
        mask = X[:, feature_idx] == v
        cond += (mask.sum() / total) * entropy(y[mask])
    return parent - cond

def majority(y):
    return Counter(y).most_common(1)[0][0]
```

## 七、常见坑

| 坑 | 说明 |
| --- | --- |
| 忘记处理"属性值全部相同"的死循环 | 必须检查"所有样本在某属性上取值相同"，否则无限递归 |
| 用 `log` 还是 `log2` | 底数只影响单位（bit vs nat），不影响 argmax，但要统一 |
| 空子集的熵算成 0 | 空集的熵无定义，应直接跳过（权重为 0） |
| 认为信息增益越大越好 | 它偏好取值多的属性，这是 ID3 的固有缺陷 |
| 连续属性直接用信息增益 | 需先做二分（Day3） |
| 叶子结点存"多数类"但概率全 0/1 | 实际上应存类别分布，便于剪枝与概率输出 |
| 忽略缺失值 | 现实中必遇，Day3 讲处理方法 |

## 八、练习题

**基础**

1. 计算数据集的熵：$D$ 有 10 个样本，3 正 7 负。
2. 某属性把 $D$ 分成两个子集 $D_1$（3 正 0 负）与 $D_2$（0 正 7 负），求条件熵与信息增益。
3. 说明为什么"全同类"时熵为 0。

**进阶**

4. 证明：当各类概率相等时，$H(D)$ 取得最大值 $\log_2 k$。（提示：用拉格朗日乘子或 Jensen 不等式）
5. 证明信息增益等价于**互信息**：$Gain(D,a) = I(D; a)$。
6. 构造一个数据集，使得某个"取值极多"的无意义属性获得最大的信息增益。

**思考题**

7. ID3 只能处理离散属性。如果有一个连续属性"密度"（取实数），直接用信息增益会遇到什么问题？
8. 决策树的"归纳偏好"是什么？为什么说它偏好"用更少的属性做出判断"的树？

<details>
<summary>第 1 题答案</summary>

$$H(D) = -\frac{3}{10}\log_2\frac{3}{10} - \frac{7}{10}\log_2\frac{7}{10} = 0.881 \text{ bit}$$
</details>

<details>
<summary>第 2 题答案</summary>

$H(D_1) = 0$，$H(D_2) = 0$。

$$H(D|a) = \frac{3}{10}\times0 + \frac{7}{10}\times0 = 0$$

$$Gain(D,a) = 0.881 - 0 = 0.881 \text{ bit}$$

这是一个**完美划分**（完全分开了两类）。
</details>

<details>
<summary>第 5 题答案</summary>

$$I(D; a) = H(D) - H(D|a) = Gain(D, a)$$

由 Week01 Day5 中互信息的定义：

$$I(X;Y) = H(X) - H(X|Y)$$

取 $X = D$（类别变量）、$Y = a$（属性变量），即得。**信息增益就是"类别与属性之间的互信息"。**
</details>

## 九、一句话总结

**决策树每一步都在问："用哪个属性划分，能让数据最快变纯？"信息增益给出了这个问题的量化答案，但它偏爱取值多的属性——这是 C4.5 出现的理由。**
