## 本周目标

学完本周，你应该能够：

1. 独立搭好 Python + NumPy + PyTorch 的开发环境，并写出可复用的虚拟环境流程；
2. 熟练使用 NumPy 的 ndarray 完成矩阵/张量运算，理解**广播机制**与**轴（axis）**语义；
3. 掌握线性代数中与机器学习强相关的概念：范数、特征分解、SVD，并说清它们在 PCA、降维中的作用；
4. 掌握概率论的核心工具：常见分布、贝叶斯公式、最大似然估计、最大后验估计；
5. 掌握梯度、链式法则、Jacobian、Hessian 的定义，理解梯度下降的几何含义与凸性；
6. 理解熵、交叉熵、KL 散度，并推导出"**最大似然 = 最小化交叉熵**"这一关键等价关系；
7. 能解释数值计算中的上溢/下溢问题，并写出数值稳定的 softmax 与 log-sum-exp。

## 核心符号约定（全课程统一）

从本周起，这套符号贯穿 12 周，请务必记住：

| 符号 | 含义 | 维度示例 |
| --- | --- | --- |
| $x$ | 标量 | $\mathbb{R}$ |
| $\boldsymbol{x}$ | 列向量（样本/特征向量） | $\mathbb{R}^n$ |
| $\mathbf{X}$ | 矩阵（数据集） | $\mathbb{R}^{m \times n}$（m 样本，n 特征） |
| $\mathbf{A}$ | 张量 / 权重张量 | $\mathbb{R}^{C \times H \times W}$ |
| $n$ | 特征维度 | — |
| $m$ | 样本数量 | — |
| $d$ | 通用维度（常指特征/隐层维度） | — |
| $\boldsymbol{w}, b$ | 权重向量与偏置 | $\mathbb{R}^n$, $\mathbb{R}$ |
| $\boldsymbol{\theta}$ | 全部可学习参数的集合 | — |
| $L$ 或 $J$ | 损失函数 / 目标函数 | 标量 |
| $\nabla_{\boldsymbol{\theta}} L$ | 对参数的梯度 | 与 $\boldsymbol{\theta}$ 同形 |
| $\odot$ | 逐元素（Hadamard）乘积 | — |
| $\|\boldsymbol{x}\|_p$ | $L_p$ 范数 | 标量 |

**约定**：本课程所有向量默认是**列向量**，$\frac{\partial \boldsymbol{y}}{\partial \boldsymbol{x}}$ 表示 Jacobian 矩阵，其第 $i$ 行第 $j$ 列为 $\frac{\partial y_i}{\partial x_j}$。
