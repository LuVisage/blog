## 2.2 池化层：不用学习的降采样

### 2.2.1 定义

在一个 $k\times k$ 的窗口内做聚合，然后按步长滑动：

$$\text{MaxPool}:\quad y_{i,j} = \max_{u,v\in\mathcal{W}} x_{i+u,j+v}$$
$$\text{AvgPool}:\quad y_{i,j} = \frac{1}{k^2}\sum_{u,v\in\mathcal{W}} x_{i+u,j+v}$$

**与卷积的三个区别**：

| | 卷积 | 池化 |
| --- | --- | --- |
| 可学习参数 | 有 | **无** |
| 通道变化 | $C_{in}\to C_{out}$ | **通道数不变** |
| 计算方式 | 内积（加权求和） | 取最大 / 求平均 |

**参数量为 0** 意味着池化不增加任何需要训练的东西 —— 它纯粹是一个固定的降采样操作。

### 2.2.2 输出尺寸

**同样的公式**，只是 $P$ 通常为 0：

$$H_{out} = \left\lfloor\frac{H + 2P - k}{S}\right\rfloor + 1$$

最常见的配置：$k=2, S=2$ → 尺寸**精确减半**（$28\to14\to7$）。

### 2.2.3 三大作用

| 作用 | 说明 |
| --- | --- |
| **降采样** | 特征图变小，后续计算量与显存下降 |
| **扩大感受野** | 同样深度的网络，能"看到"更大的区域 |
| **带来平移不变性** | 局部区域内的微小位移，池化后的输出不变（见下） |

**平移不变性的机制**：$2\times2$ 最大池化下，输入在窗口内平移 1 像素，只要最大值仍在同一窗口内，输出就完全一样。这给 CNN 带来对小幅位移的鲁棒性。

> **严格地说**：池化带来的是"局部平移不变"，大幅位移仍会改变输出。真正的全局不变性要靠全局平均池化（GAP）。

### 2.2.4 反向传播：max 的"路由"特性

**最大池化没有梯度**（$\max$ 不是光滑函数），它的反向传播是一个**路由**操作：

- 前向时记录**最大值所在的位置**（argmax）；
- 反向时把梯度**只传给那个位置**，其余位置梯度为 0。

$$x_k \text{ 是窗口最大值} \Rightarrow \frac{\partial y}{\partial x_k} = 1,\quad \frac{\partial y}{\partial x_j} = 0\ (j\ne k)$$

**平均池化**则是把梯度**平均分配**给窗口内所有位置，每个位置得到 $\frac{1}{k^2}$。

```
最大池化反向                        平均池化反向
前向: [1, 5, 2, 3] -> 5            前向: [1, 5, 2, 3] -> 2.75
反向: [0, g, 0, 0]                 反向: [g/4, g/4, g/4, g/4]
```

## 2.3 池化的现代替代方案

现代网络中，池化正在被**步长卷积**取代：

| 方案 | 做法 | 特点 |
| --- | --- | --- |
| 池化 | `Conv(S=1) + MaxPool(2,2)` | 参数少，但信息被硬性丢弃 |
| **步长卷积** | `Conv(S=2)` | **可学习**的降采样，信息利用更充分 |

**为什么现代网络偏好步长卷积**：

1. 降采样过程**可学习**（池化是固定的）；
2. 可以用 `dilation` 或 `stride` 精细控制；
3. 在一些任务上精度更高。

**但池化仍有价值**：参数为零、计算简单、在小数据集上不易过拟合。经典网络（LeNet、AlexNet、VGG）全都用池化。

**全局平均池化（GAP）** 是另一个重要变体：

```python
gap = nn.AdaptiveAvgPool2d(1)     # (N, C, H, W) -> (N, C, 1, 1)
```

它把每个通道的整张特征图平均成一个数，**彻底替代了最后的全连接层**。好处：

- 参数量从"$C\times H\times W\times\text{类别数}$"降到 0；
- 天然支持任意输入尺寸；
- 减少过拟合（ResNet、MobileNet 都用它）。

## 2.4 LeNet-5：第一个真正可用的 CNN

LeCun 等 1998 年提出，用于手写数字识别，是美国邮政和银行支票识别系统的核心。**它是现代 CNN 的祖师爷。**

### 2.4.1 原始结构（输入 $32\times32$）

| 层 | 类型 | 配置 | 输出尺寸 | 参数量 |
| --- | --- | --- | --- | --- |
| 输入 | — | — | $1\times32\times32$ | — |
| C1 | 卷积 | $6$ 个 $5\times5$，S=1，P=0 | $6\times28\times28$ | $6\times(1\times25+1)=156$ |
| S2 | 平均池化 | $2\times2$，S=2 | $6\times14\times14$ | 0 |
| C3 | 卷积 | $16$ 个 $5\times5$ | $16\times10\times10$ | $16\times(6\times25+1)=2416$ |
| S4 | 平均池化 | $2\times2$，S=2 | $16\times5\times5$ | 0 |
| C5 | 卷积 | $120$ 个 $5\times5$ | $120\times1\times1$ | $120\times(16\times25+1)=48120$ |
| F6 | 全连接 | 84 | 84 | $120\times84+84=10164$ |
| 输出 | 全连接 | 10 | 10 | $84\times10+10=850$ |
| **合计** | | | | **约 61,706** |

**注意 C5**：$5\times5$ 的卷积作用在 $5\times5$ 的输入上，输出 $1\times1$ —— **它其实就是一个全连接层**，只是用卷积的写法。这是"用卷积代替全连接"的早期实践。

### 2.4.2 三个历史细节（有意思但常被忽略）

1. **输入是 $32\times32$**，而 MNIST 是 $28\times28$ —— 原论文把数字放在 $32\times32$ 画布中央，让边缘笔画不贴边；
2. **S2/S4 用的是平均池化**，而且带一个可学习的缩放系数和偏置（现代池化都没有）；
3. **C3 用了稀疏连接**（只连接部分 S2 通道），目的是打破对称性、减少参数 —— 现代网络改用 Dropout 和随机初始化达到同样目的。

### 2.4.3 现代简化版

实际写代码时，通常用 ReLU + 最大池化：

```python
class LeNet(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 6, 5), nn.ReLU(), nn.MaxPool2d(2),      # 28->24->12
            nn.Conv2d(6, 16, 5), nn.ReLU(), nn.MaxPool2d(2),     # 12->8->4
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),                                        # 16*4*4 = 256
            nn.Linear(256, 120), nn.ReLU(),
            nn.Linear(120, 84), nn.ReLU(),
            nn.Linear(84, num_classes),
        )

    def forward(self, x):
        return self.classifier(self.features(x))
```

**形状追踪**（输入 $1\times28\times28$）：

```
Conv2d(1,6,5)      ->  6 x 24 x 24     (28-5+1 = 24)
MaxPool2d(2)       ->  6 x 12 x 12
Conv2d(6,16,5)     -> 16 x  8 x  8     (12-5+1 = 8)
MaxPool2d(2)       -> 16 x  4 x  4
Flatten            -> 256
Linear(256,120)    -> 120
Linear(120,84)     ->  84
Linear(84,10)      ->  10
```

**每次写 CNN 都要这样追踪一遍形状** —— 这是最容易出错的地方。Day3 会给出自动化方法。

## 2.5 池化 vs 全连接：为什么不在前面就展平

一个常见疑问：既然最后都要展平，为什么不一开始就展平？

| 阶段 | 用卷积/池化 | 用全连接 |
| --- | --- | --- |
| 参数量 | $k^2 C_{in}C_{out}$ | $HWC_{in}\times HWC_{out}$ |
| 空间信息 | 保留 | 丢失 |
| 平移等变 | 有 | 无 |
| 可处理任意尺寸 | 是 | 否（需固定输入） |

**在特征图还很大的时候展平，参数量会爆炸**。以 $28\times28$ 为例：

```
展平后 -> 全连接 128 维:   784 x 128      = 100,352 参数
卷积     -> 128 通道 3x3:  128 x 1 x 9    = 1,152 参数
```

**池化的作用就是"把特征图降到足够小、同时又保留空间结构"**，等到 $4\times4$ 或 $1\times1$ 时才展平，参数量才可控。

## 2.6 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 展平维度算错 | 卷积/池化后尺寸变化没追踪 | 逐层手算，或用 `x.shape` 打印 |
| `MaxPool2d(2)` 后尺寸奇数 | $k=2,S=2$ 遇奇数输入会向下取整 | 用 `AdaptiveMaxPool2d` 或补边 |
| 以为池化有参数 | 混淆池化与卷积 | 池化参数量恒为 0 |
| 池化后通道数变了 | 记错规则 | **池化不改变通道数** |
| 训练不收敛 | 池化接在全连接之后 | 池化只用于特征图（3D 数据） |
| GAP 后维度对不上 | 忘了 `flatten` 或 `squeeze` | `AdaptiveAvgPool2d(1)` 后接 `flatten(1)` |
