## 4.2 任务设计：图像 → token 序列

**Transformer 需要 token 序列**，所以要把 $28\times28$ 的 MNIST 图像转成序列。

**方案：把每一行当作一个 token。**

```
28x28 图像
┌──────────┐
│ 行 0     │  ->  token 0: 28 维向量
│ 行 1     │  ->  token 1
│  ...     │
│ 行 27    │  ->  token 27
└──────────┘
序列长度 T = 28，每个 token 的维度 d = 28
```

**这与 Day5 的 ViT 思路不同**（ViT 用 patch），但更容易实现，也便于与 Week13 的 RNN 结果直接对比（**同样的输入形式**）。

**关键**：因为自注意力是置换等变的（Day1），所以**必须加位置编码** —— 这里用可学习的位置嵌入。

## 4.3 模型结构

```python
class TransformerClassifier(nn.Module):
    def __init__(self, d_model=64, num_heads=4, num_layers=2,
                 d_ff=256, max_len=28, num_classes=10):
        super().__init__()
        self.token_proj = nn.Linear(28, d_model)        # 28维行向量 -> d_model
        self.pos_emb = nn.Parameter(torch.zeros(max_len, d_model))
        self.blocks = nn.ModuleList([
            EncoderBlock(d_model, num_heads, d_ff) for _ in range(num_layers)])
        self.ln_f = nn.LayerNorm(d_model)
        self.head = nn.Linear(d_model, num_classes)

    def forward(self, x):                     # x: (B, 28, 28)
        x = self.token_proj(x)                # (B, 28, d_model)
        x = x + self.pos_emb.unsqueeze(0)     # 加位置编码
        for blk in self.blocks:
            x = blk(x)
        x = self.ln_f(x)
        return self.head(x.mean(dim=1))       # 平均池化 -> 分类
```

**三个设计选择**：

| 选择 | 理由 |
| --- | --- |
| **平均池化**取序列特征 | 分类任务，不需要保留序列结构；比取最后位置更稳定 |
| **可学习位置编码** | 序列长度固定（28），简单有效 |
| **2 层、d_model=64** | 小数据，避免过拟合 |

**预期结果**：

1. 数据量小（Transformer 需要更多数据，Day5 会详述）；

## 4.6 一个关键观察：注意力学到了什么

训练后，可以可视化第一层注意力的模式：

| 可能的模式 | 含义 |
| --- | --- |
| 关注**相邻行** | 学到"局部笔画连续性" |
| 关注**特定行范围** | 学到"数字的关键部位"（如 8 的中间） |
| 关注**相同位置的所有行** | 学到"垂直方向的信息" |
| 近乎均匀 | 这一层没学到东西 |

**对比 CNN 的第一层卷积核**（Week11 Day4 可看出边缘检测器）：

- **CNN 的先验是"局部"** → 第一层学边缘；
- **Transformer 没有空间先验** → 第一层学到的模式更加"全局、多样、难解释"。

**这正是 ViT 需要大规模预训练的原因**（Day5 详述）：**没有先验，就得靠数据补。**

## 4.7 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 精度很低（接近随机） | 忘加位置编码 | 加上位置嵌入 |
| 训练极慢 | Transformer 在小序列上不划算 | 用更大的 batch |
| 过拟合严重 | 参数量相对数据过多 | 加 dropout / 减层数 |
| loss 震荡 | 学习率太大 | 降 lr 或加 warmup |
| 结果比 RNN 差 | 数据量不足（缺先验） | 这本身是可报告的结论 |
