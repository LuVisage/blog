## 3.2 核心思想：用"造假者 vs 鉴定师"来训练

**类比**：

- **生成器 G** = 造假币的人，目标是造出能骗过鉴定师的假币；
- **判别器 D** = 鉴定师，目标是分辨真币和假币。

**两者的水平在博弈中共同提升**：造假者越来越像，鉴定师越来越严 —— 最终造假者能造出以假乱真的币。

**极小极大博弈**：

$$\min_G\max_D\ V(D,G) = \mathbb{E}_{x\sim p_{data}}\left[\log D(x)\right] + \mathbb{E}_{z\sim p_z}\left[\log\left(1 - D(G(z))\right)\right]$$

| 项 | 含义 |
| --- | --- |
| $\mathbb{E}_{x\sim p_{data}}[\log D(x)]$ | **真图被判为真** —— D 想最大化 |
| $\mathbb{E}_{z}[\log(1-D(G(z)))]$ | **假图被判为假** —— D 想最大化 |

**理论最优解**：当生成分布完全等于真实分布时，$D(x) = 0.5$（分不出来），此时达到纳什均衡。

## 3.3 两个损失函数（代码里怎么写）

### 判别器的损失

```python
# D 的目标: 真图 -> 1，假图 -> 0
d_real = D(real_img)
d_fake = D(fake_img.detach())        # ★ detach: 不回传到 G

loss_D = BCE(d_real, ones) + BCE(d_fake, zeros)
```

### 生成器的损失

**关键差异**：G 的损失有两种常见写法。

| 写法 | 公式 | 特点 |
| --- | --- | --- |
| **原始（minimax）** | $\min_G \log(1-D(G(z)))$ | 训练初期**梯度消失**（D 很容易识破，$D(G(z))\approx 0$，梯度趋近 0） |
| **非饱和（推荐）** | $\max_G \log D(G(z))$ | 训练初期梯度充足，**实践更稳定** |

**代码**：

```python
# 原始写法 —— 不推荐
loss_G = BCE(D(fake), zeros)

# 非饱和写法 —— 推荐（原论文也推荐这个）
g_fake = D(fake_img)                 # 注意: 【不 detach】，要回传到 G
loss_G = BCE(g_fake, ones)
```

> **为什么"让 D 认为假图是真的"比"让 D 认为假图是假的"更好**：
> 前者在 D 强的时候仍能提供足够梯度；后者在 D 强时梯度趋近 0，G 学不动。

### 两个 `detach` 的区别（最容易出错的地方）

| 位置 | 是否 detach | 原因 |
| --- | --- | --- |
| **更新 D 时**，假图要 `detach()` | 要 | 只更新 D，不能让梯度流回 G |
| **更新 G 时**，假图**不能** `detach()` | 不要 | 梯度必须传到 G 才能更新它 |

**记法**：**谁要更新，就不 detach 谁。**

## 3.4 交替训练的流程

```python
for epoch:
    for real_img, _ in loader:
        # ---------- ① 更新判别器 D ----------
        z = randn(batch, latent)
        fake = G(z)
        loss_D = BCE(D(real), 1) + BCE(D(fake.detach()), 0)
        opt_D.zero_grad(); loss_D.backward(); opt_D.step()

        # ---------- ② 更新生成器 G ----------
        z = randn(batch, latent)
        fake = G(z)
        loss_G = BCE(D(fake), 1)          # ★ 不 detach
        opt_G.zero_grad(); loss_G.backward(); opt_G.step()
```

**为什么必须交替**：

- 如果只训 G，D 不变 → G 会"钻 D 的空子"（生成能骗过当前 D 但完全不像真图的样本）；
- 如果只训 D，G 不变 → D 会完美识破，G 得不到有效梯度。

**"轮流进步"是 GAN 的核心，也是最难调的部分。**

### D 与 G 的平衡

| 情况 | 现象 | 处理 |
| --- | --- | --- |
| **D 太强** | G 的损失不降、生成全一样 → 梯度消失 | 降低 D 的学习率 / 减少 D 的更新次数 |
| **G 太强** | D 的准确率掉到 0.5 以下、生成质量崩 | 提高 D 的学习率 |
| **理想** | D 的准确率在 **0.5~0.8** 之间波动 | —— |

**实践配置**：`opt_D = lr=2e-4, betas=(0.5, 0.999)`，`opt_G = lr=2e-4, betas=(0.5, 0.999)`

**注意 `beta1=0.5`**（而非常用的 0.9）：这是 GAN 的经典技巧。动量太大会让 D 的梯度方向变化滞后，加剧训练不稳定。

## 3.5 模式崩塌（Mode Collapse）

**现象**：G 只生成少数几种样本，即使真实数据有 10 个类别，它可能只生成 1~2 种。

**为什么发生**：

```
假设真实数据有 10 种模式。
G 发现"生成数字 1"能骗过 D -> 它就一直生成 1
D 逐渐学会"这些是 1，判为假"
G 转而生成数字 7 -> 又只生成 7
...
两者在少数模式上反复拉锯，其他模式被完全忽略
```

**根本原因**：**G 的目标是"骗过当前 D"，而不是"覆盖整个数据分布"。** 只要能骗过 D，生成一种就够了。

**与 VAE 的对比**：

| | VAE | GAN |
| --- | --- | --- |
| 倾向 | 覆盖所有模式（因为要重构每个样本） | **容易丢掉模式** |
| 表现 | 生成的图模糊但多样 | 清晰但可能重复 |

**缓解方法**：

| 方法 | 思路 |
| --- | --- |
| **Minibatch Discrimination** | 让 D 同时看一批样本，惩罚"批次内太相似" |
| **Unrolled GAN** | G 预测 D 未来几步的反应 |
| **WGAN** | 换用 Wasserstein 距离，梯度更平滑 |
| **Feature Matching** | G 不直接骗 D，而是匹配 D 中间层的特征统计 |
| **Experience Replay** | 保留历史生成的样本，防止 G "忘记"曾经的模式 |

### 实测：一个反直觉的发现

案例代码用辅助分类器统计了生成样本的类别分布（500 张图）：

| 配置 | 覆盖类别数 | 最大类占比 | D 对假图的准确率 |
| --- | --- | --- | --- |
| 平衡（lr_D = lr_G） | 7 | **78.6%** | 82.65% |
| D 更强（lr_D 5×） | 8 | 31.2% | 88.65% |
| D 极强（lr_D 20×） | 9 | 30.8% | 83.05% |

**结果与"常识"相反**：**"平衡配置"反而出现了明显的模式崩塌**（近 80% 集中在同一个数字），而 D 更强时类别覆盖反而更分散。

**为什么**：

- **D 较弱时**：G 只要生成"一种能骗过 D"的图就够了，没有压力去覆盖所有模式 → 容易崩塌；
- **D 较强时**：单一模式会被 D 识破，G 被迫探索更多模式。

> **这才是最有价值的一课**：**GAN 的训练动力学没有简单规则。**
>
> 教科书上的"经验法则"（如"D 不能太强"）是在特定设定下的观察。换一组超参、换一个数据集，**结论可能完全反过来**。
>
> 所以 GAN 的调试必须：
>
> 1. **固定种子，多次运行**（单次结果不能作为结论）；
> 2. **定期可视化生成样本**（不能只看 loss）；
> 3. **统计生成样本的分布**（辅助分类器是个实用手段）；
> 4. **用消融实验验证每条"经验法则"在本任务上是否成立**。

## 3.6 让 GAN 稳定训练的六个技巧

**这是 GAN 最实用的部分**（也是它被称为"炼丹"的原因）。

| # | 技巧 | 说明 |
| --- | --- | --- |
| 1 | **用非饱和损失** | G 用 `BCE(D(fake), 1)` 而非 `BCE(D(fake), 0)` |
| 2 | **`beta1=0.5`** | Adam 的动量参数调低 |
| 3 | **标签平滑** | 真图标签用 0.9 而不是 1.0（防止 D 过于自信） |
| 4 | **D 用 LeakyReLU** | 避免负半轴梯度为 0（D 需要梯度信号） |
| 5 | **G 输出用 `Tanh`** | 配合输入归一化到 $[-1,1]$ |
| 6 | **G 中用 BatchNorm，D 中不用** | D 用 BN 会让同批次样本互相"泄漏"信息 |

**额外技巧**：

- **加噪声**：给 D 的输入加微小噪声，降低它过拟合的能力；
- **别用 momentum 太高的优化器**；
- **先让 D 训几步再训 G**（如果 D 明显偏弱）。

**这些技巧为什么重要**：它们不是"锦上添花"，而是**能不能训出东西的前提**。GAN 的原始实现（不加这些）在多数任务上根本训不起来。

## 3.7 GAN 的变体家族

| 变体 | 关键改进 |
| --- | --- |
| **DCGAN** | 用卷积替代全连接，确立了现代 GAN 的基本架构规范 |
| **WGAN / WGAN-GP** | 换用 Wasserstein 距离 + 梯度惩罚，训练稳定得多 |
| **cGAN** | 加条件（类别标签），可控制生成内容 |
| **Pix2Pix** | 图像到图像的翻译（草图→照片） |
| **CycleGAN** | **无需配对数据**的域转换（马↔斑马） |
| **StyleGAN** | 风格与内容解耦，能生成以假乱真的人脸 |
| **BigGAN** | 大规模训练 + 类别条件 |

**WGAN 的核心改进**（值得单独记住）：

$$\max_{w}\ \mathbb{E}_{x\sim p_{data}}[f_w(x)] - \mathbb{E}_{z}[f_w(G(z))]$$

**用"判别器输出的差值"代替"对数概率"**，并加梯度惩罚让 $f_w$ 满足 Lipschitz 约束。

**为什么更好**：即使两个分布完全不重叠，Wasserstein 距离仍能提供**有意义的梯度**（而 JS 散度在此时梯度为 0）。

## 3.8 GAN 的现状

**2014–2020 是 GAN 的黄金期**（StyleGAN 的人脸生成震惊世界）。**2021 年后，扩散模型逐渐成为主流。**

**为什么被取代**：

| | GAN | 扩散模型 |
| --- | --- | --- |
| 训练稳定性 | **差**（需要精心调参） | 好（就是回归任务） |
| 模式覆盖 | 容易崩塌 | **好** |
| 生成质量 | 高 | **更高** |
| 采样速度 | **快**（一次前向） | 慢（需要几十步） |
| 理论清晰度 | 博弈论，较复杂 | **简单**（去噪） |

**但 GAN 并没有死**：

- **实时生成**：GAN 一次前向就能出图，扩散要几十步 —— 在实时场景（视频会议背景替换、游戏）仍有优势；
- **感知损失**：GAN 的判别器被广泛用作**训练其他模型的损失函数**（如超分、修复）；
- **数据增强**：用 GAN 生成合成数据补充训练集。

> **工程判断**：**要质量用扩散，要速度用 GAN，要稳定用扩散。**

## 3.9 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 生成的图全一样 | 模式崩塌 | 见 3.5 的缓解方法 |
| G 的 loss 一直不降 | D 太强，梯度消失 | 用非饱和损失、降 D 的 lr |
| D 的 loss 变成 0 | D 太强 | 降 D 的 lr，或给 D 加噪声/标签平滑 |
| 生成的图是噪声 | G 输出没加 Tanh / 归一化不匹配 | G 最后一层 Tanh + 输入归一化到 [-1,1] |
| 训练崩溃（loss 突然爆） | 某一步 D 或 G 梯度爆炸 | 加梯度裁剪；降 lr |
| 更新 G 时报错 | 忘了 `detach()` 或忘了不 detach | 见 3.3 的表格 |
| D 和 G 用同一个 optimizer | 参数被一起更新 | **必须两个独立的 optimizer** |
| 用 BN 在 D 里 | 批次内信息泄漏 | D 用 InstanceNorm 或不用 |

## 3.11 一句话总结

**GAN 用"生成器 vs 判别器"的对抗博弈换来锐利的生成结果，代价是训练极不稳定（D/G 失衡、模式崩塌）；六个稳定技巧不是优化项而是前提，而 2021 年后扩散模型因"训练稳定 + 模式覆盖好"成为主流 —— 但 GAN 在实时生成和感知损失上仍不可替代。**
