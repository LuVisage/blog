> CYC 工具课件 03–07（Numpy / Pandas / Matplotlib / jieba+NLTK / 数据预处理）+ 导学

前 7 周我们一直在"用 NumPy 造轮子"。但从真实项目角度看，**80% 的时间花在数据上，而不是模型上**。这一周补齐数据侧的完整工具链：用 Pandas 处理表格、用 Matplotlib 看图、用 jieba/NLTK 处理文本、用标准流程做特征工程。

---

## 本周目标

学完本周，你应该能够：

1. 熟练使用 Pandas 的 `Series` / `DataFrame` 完成读写、筛选、排序、分组聚合、缺失值处理；
2. 会用 Matplotlib 画出折线/散点/柱状/直方/箱线图，并掌握"容器层 / 辅助显示层 / 图像层"的三层结构；
3. 完整掌握 7 种数据预处理方法：均值移除、范围缩放、归一化、二值化、独热编码、标签编码、缺失值处理；
4. 会用 jieba 做中文分词、用 NLTK 做英文分词与词频统计；
5. 能搭建一个**可复用的特征工程 Pipeline**（`sklearn.pipeline.Pipeline` + `ColumnTransformer`）；
6. 知道特征工程的常见陷阱（数据泄漏、量纲、类别编码顺序）。

## 本周检查清单

- [ ] 我能用一行代码读入 CSV 并查看 `head()` / `info()` / `describe()`
- [ ] 我能用布尔索引、`loc` / `iloc` 精确取数，并说清两者的区别
- [ ] 我能用 `groupby` + `agg` 完成"按类别统计多个指标"
- [ ] 我能处理缺失值：判断缺失比例、选择删除或填充、填充时只用训练集统计量
- [ ] 我能画出带标题、轴标签、图例、网格的完整图，并解决中文显示问题
- [ ] 我能说清**标准化**与**归一化**的区别，并知道各自适用场景
- [ ] 我能解释**为什么独热编码优于标签编码**（对无序类别特征）
- [ ] 我能用 jieba 分词 + 停用词过滤 + 词频统计做一个简单的文本特征
- [ ] 我能用 `Pipeline` + `ColumnTransformer` 把预处理与模型串成一条链
- [ ] 我知道"先划分再拟合预处理器"是避免数据泄漏的铁律
