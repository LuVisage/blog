## 5.2 ViT 的核心思想

**论文标题就是全部思想**：《An Image is Worth 16x16 Words》。

**做法**：

```
一张 224x224x3 的图像
        ↓  切成 16x16 的 patch（共 196 个）
   ┌──┬──┬──┬─┐
   │P1│P2│P3│…│   每个 patch: 16*16*3 = 768 维
   ├──┼──┼──┼─┤
   │P4│P5│P6│…│   展平后线性投影到 d_model
   └──┴──┴──┴─┘
        ↓
  序列: [CLS] + P1 + P2 + ... + P196   (长度 197)
        ↓
  加位置编码 → 标准 Transformer 编码器
        ↓
  用 [CLS] 位置的输出做分类
```

**与 Day4 的对比**：

| | Day4 的做法 | **ViT 的做法** |
| --- | --- | --- |
| token 单位 | 一整行（28 维） | 一个 patch（$16\times16\times3$） |
| token 数量 | 28 | 196（$224/16 = 14$，$14^2$） |
| 每个 token 的信息 | 少（一行像素） | 多（一个小图像块） |
| 是否有 CLS token | 无（用平均池化） | **有** |

**为什么用 patch 而不是像素**：$224\times224 = 50176$ 个像素当 token，注意力矩阵会是 $50176^2 \approx 2.5\times10^9$ —— 完全不可行。patch 把序列长度降到 196，才让注意力可算。

> **patch 的大小是一个权衡**：
>
> - patch 小 → 序列长 → 计算量大，但细节保留多；
> - patch 大 → 序列短 → 计算量小，但细节丢失多。
>
> 主流是 16×16（或 14×14）。

## 5.3 CLS token：为什么要多一个 token

**问题**：分类需要一个"整张图的表示"，但 Transformer 输出的是**每个位置的表示**。怎么聚合？

**两种方案**：

| 方案 | 做法 | 使用者 |
| --- | --- | --- |
| **平均池化** | 对所有位置的输出取平均 | Day4 的做法、部分 ViT 变体 |
| **CLS token** | 在序列最前面加一个可学习的 token，用它的输出分类 | **原版 ViT、BERT** |

**CLS token 的工作原理**：

1. 它是一个**可学习的向量**，初始随机；
2. 它不对应任何真实的图像块，唯一的作用是"收集全局信息"；
3. 因为自注意力让每个位置都能看到所有位置，CLS 在每一层都在**从所有 patch 里汇聚信息**；
4. 经过多层之后，CLS 的输出就成了"整张图的摘要"。

**实验证据**：如果把 CLS token 的注意力可视化，会发现它**在深层几乎均匀地关注所有 patch** —— 正是因为它在做全局聚合。

## 5.4 ViT 为什么必须大规模预训练

**这是本周最重要的一个结论。**

**论文中的关键实验**：

| 训练数据规模 | ViT 表现 |
| --- | --- |
| ImageNet-1k（128 万张） | **打不过 ResNet**（精度低几个点） |
| ImageNet-21k（1400 万张） | 追平 ResNet |
| **JFT-300M（3 亿张）** | **显著超越 ResNet** |

**原因分析**：

CNN 内建了三个强先验：

| 先验 | CNN 的体现 | ViT 的情况 |
| --- | --- | --- |
| **局部性** | 卷积核只看 $k\times k$ 邻域 | 无（注意力是全局的） |
| **平移等变** | 权重共享 | 无（只有位置编码，不是等变的） |
| **层次结构** | 逐层降采样 + 通道翻倍 | 无（所有层同维度） |

**这些先验在数据少时极其宝贵**（Week11 的核心洞察：结构先验比参数量更重要）。

**ViT 放弃这些先验，换来了通用性和可扩展性** —— 但代价是**必须用数据把先验"学回来"**。

> **一句话总结**：**ViT 不是"更好的 CNN"，它是"用数据替代先验"的路线。** 数据充足时它更强，数据不足时它更弱。

## 5.5 预训练 + 微调：现代范式

既然 ViT 需要海量数据，实践中不会从头训练它。**标准流程**：

```python
# ① 加载在 ImageNet-21k 上预训练的 ViT
from torchvision.models import vit_b_16, ViT_B_16_Weights
model = vit_b_16(weights=ViT_B_16_Weights.IMAGENET1K_V1)

# ② 替换分类头以适配新任务的类别数
model.heads.head = nn.Linear(768, num_classes)

# ③ 微调（全部或部分层）
for p in model.parameters():
    p.requires_grad = True
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-5)   # 小学习率
```

**三个阶段**：

| 阶段 | 数据量 | 学习率 | 说明 |
| --- | --- | --- | --- |
| **预训练** | 海量（千万~亿级） | 大 | 学通用表示（只有大厂做） |
| **微调** | 中等（万级） | 小（1e-5） | 适配下游任务 |
| **线性探测** | 很少（千级） | 只训分类头 | 评估预训练特征的质量 |

**这已经是视觉和 NLP 的统一范式**：

```
Week11 的 CNN:   从头训练（数据少时的正确选择）
Week14 的 ViT:   预训练 + 微调（数据多时的正确选择）
```

## 5.6 ViT 与 CNN 的对比总结

| 维度 | CNN | ViT |
| --- | --- | --- |
| 核心先验 | 局部性 + 平移等变 | **无**（靠位置编码提供顺序） |
| 感受野 | 逐层扩大 | **第一层就是全局** |
| 参数量（同精度） | 较少 | 较多 |
| 小数据表现 | **更好** | 更差 |
| 大数据表现 | 好 | **更好** |
| 可扩展性 | 一般 | **优秀**（Scaling Law 明显） |
| 可解释性 | 较好（卷积核可视化） | 较差（注意力图可看但不直观） |
| 训练成本 | 低 | 高（需大规模预训练） |

**现代实践的融合**：

- **ConvNeXt**：把 CNN 改造成 ViT 风格（大核、GELU、LN），证明 CNN 也能达到 ViT 的性能；
- **Swin Transformer**：给注意力加"局部窗口"，把 CNN 的局部性先验还给 Transformer；
- **混合架构**：浅层用卷积（提取局部特征），深层用注意力（建模全局关系）。

> **结论**：两者的界限正在模糊。**理解"先验 vs 数据"这个权衡，比记住"谁更好"更重要。**

## 5.7 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| ViT 从头训练精度很低 | 数据不足（缺先验） | 用预训练权重，或换 CNN |
| 显存爆 | patch 太小导致序列太长 | 增大 patch，或减 batch |
| 微调后精度下降 | 学习率太大（破坏了预训练特征） | lr 降到 1e-5 |
| 位置编码长度不够 | 输入分辨率变了 | 插值位置编码或重新初始化 |
| 忽略图像尺寸 | ViT 要求输入是 patch 大小的整数倍 | resize 到标准尺寸 |
| 训练极慢 | 注意力 $O(T^2)$ | 减小分辨率或用 Swin |

## 5.9 一句话总结

**ViT 把图像切成 patch 当作 token，用纯 Transformer 处理 —— 它放弃了 CNN 的所有空间先验，因此在小数据上更弱、在大数据上更强；"预训练 + 微调"就是从这条路走出来的现代范式。**
