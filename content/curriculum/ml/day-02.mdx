## 2.2 比较与逻辑：一切判断的基础

```python
age = 18

age >= 18          # True   比较运算返回 bool（True/False）
age == 18          # True   ★ 相等是两个等号！一个等号是赋值
age != 18          # False  不等于
age > 100          # False
```

** 0 基础第一杀手**：`=` 是赋值，`==` 才是比较。`if age = 18:` 直接 SyntaxError。

**逻辑运算符**（把多个条件组合起来）：

| 写法 | 意思 | 例子 |
| --- | --- | --- |
| `A and B` | A **并且** B 都成立 | `age >= 18 and has_id` |
| `A or B` | A **或者** B 有一个成立 | `is_vip or balance > 100` |
| `not A` | 取反 | `not is_banned` |

**易错点**：`0.1 + 0.2 == 0.3` 是 **False**！
（浮点数有精度误差，`0.1 + 0.2` 得 `0.30000000000000004`）。
比较小数用 `abs(a - b) < 1e-9`，这个坑 Week02 讲评估指标时还会再见。

## 2.3 if / elif / else：做决定

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")          # ← 85 走到这里
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

**四条铁律**：

1. `if 条件:` **末尾有冒号**；
2. 下一行**缩进 4 个空格**——缩进的行才属于 if（缩进就是 Python 的"大括号"）；
3. `elif` / `else` 与 `if` **对齐**；
4. **从上往下**逐个检查，命中一个就跳过其余（85 不会同时打印"良好"和"及格"）。

**嵌套（能不用就不用）**：

```python
if is_login:
    if is_vip:
        print("欢迎 VIP")     # 两个条件都满足才执行
```

等价于 `if is_login and is_vip:` —— **用 and 合并条件比嵌套清晰得多**。

## 2.4 for 循环 + range：重复 N 次

```python
for i in range(5):
    print(i)              # 0 1 2 3 4    ← 从 0 开始，不含 5

for i in range(2, 6):     # 从 2 到 5（不含 6）
    print(i)              # 2 3 4 5

for i in range(0, 10, 2): # 步长 2
    print(i)              # 0 2 4 6 8
```

**`range(a, b)` 永远"含头不含尾"**——像 Week02 会讲的"左闭右开区间"，Python 全家统一这个习惯。

**循环累加（最重要的模式）**：

```python
total = 0
for i in range(1, 101):       # 1 到 100
    total = total + i         # 每轮把 i 加进 total
print(total)                  # 5050
```

**记住这个三件套**：`循环前定义累计变量` → `循环里更新它` → `循环后使用它`。

**遍历字符串**：

```python
for ch in "abc":
    print(ch)             # a b c —— 字符串就是"字符的序列"
```

## 2.5 while：满足条件就一直做

```python
count = 3
while count > 0:
    print(count)
    count = count - 1     # ★ 每轮必须让条件"趋向不成立"，否则死循环
print("发射！")
```

**for 和 while 怎么选**：

| 场景 | 用哪个 |
| --- | --- |
| 知道要重复几次（或遍历一个序列） | **for** |
| 不知道几次，只知道"直到什么时候停" | **while** |

**死循环急救**：终端里按 `Ctrl + C` 强制停止。

## 2.6 break 与 continue

```python
for i in range(10):
    if i == 3:
        continue          # 跳过本轮，直接进入下一轮（3 不会被打印）
    if i == 6:
        break             # 整个循环到此为止（6 及以后都不执行）
    print(i)              # 0 1 2 4 5
```

**典型用法**——"找到就退出"：

```python
for n in range(2, 100):
    if n * n > 500:
        print(f"第一个平方超过 500 的数是 {n}")
        break
```

## 2.7 综合：FizzBuzz（自测区的核心题）

经典面试题：打印 1~15，3 的倍数打印 Fizz，5 的倍数打印 Buzz，
15 的倍数打印 FizzBuzz，其余打印数字本身。

```python
for n in range(1, 16):
    if n % 15 == 0:               # ★ 必须先判断 15（最特殊的）
        print("FizzBuzz")
    elif n % 3 == 0:
        print("Fizz")
    elif n % 5 == 0:
        print("Buzz")
    else:
        print(n)
```

**两个新知识**：

- `%` 是**取余数**：`15 % 3 == 0` 表示"15 能被 3 整除"；
- **先判最特殊的条件**——如果先判 `n % 3`，15 会打印 Fizz 而不是 FizzBuzz。
 这个"条件顺序"思维在 Week03 的分段计价、Week04 的决策树里反复出现。

## 2.8 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `SyntaxError` 指向 if 行 | 少了冒号 | 补 `:` |
| if 里的代码没生效 | 忘了缩进 / 缩进不一致 | 统一 4 空格（不要用 Tab 混搭） |
| `=` 在 if 里报错 | 赋值当比较 | 用 `==` |
| 循环不执行 | `range(5, 1)` 起点比终点大 | range 含头不含尾，起点要小 |
| 死循环 | while 条件永远成立 | 确保循环体内改变条件；Ctrl+C 急停 |
| 差一错误（少循环一次） | 忘了 range 不含尾 | `range(1, 101)` 才是 1~100 |
| `0.1+0.2 == 0.3` 为 False | 浮点精度 | `abs(a-b) < 1e-9` |
