## 一、流形假设

### 1.1 什么是流形

**$d$ 维流形**：一个局部与 $\mathbb{R}^d$ 同胚的拓扑空间（"局部看起来像平面"）。

**经典例子**：

- 瑞士卷（Swiss Roll）：二维平面卷成三维螺旋；
- "S 曲线"：二维平面在三维中弯折；
- 地球表面：三维空间中的二维流形。

### 1.2 流形假设

> **高维数据实际上生成自低维流形，只是被嵌入到高维观测空间中。**

**含义**：

- MNIST 图片有 784 维，但"真正变化的方向"（笔画粗细、倾斜、位置）可能只有几十维；
- 人脸图片的高维像素由少数几个因素（姿态、光照、表情）决定。

**流形学习的任务**：找出这个低维坐标（即"展开"这个流形）。

### 1.3 为什么 PCA 不够

PCA 找的是**线性子空间**。对瑞士卷：

- PCA 给出的"最重要方向"会直接穿过卷层，把不同层混在一起；
- 真正的流形结构（沿着卷面展开）是非线性的。

**图示**：

```
瑞士卷（3D）:                   PCA 投影:          Isomap 展开:
   ╭──────╮                     ▒▒▒▒▒▒            ████████
   │ ▒▒▒▒ │  ← 卷起的平面        ▒▒▒▒▒▒  ← 层混在一起  ████████ ← 正确展开
   ╰──────╯                     ▒▒▒▒▒▒            ████████
```

## 二、MDS（多维缩放）

**目标**：给定样本间的距离矩阵 $\mathbf{D}$，在低维空间中找一组点，使**距离尽可能保持不变**。

**经典 MDS（cMDS）的解法**：

**（1）双中心化距离矩阵**

$$\mathbf{B} = -\frac{1}{2}\mathbf{H}\mathbf{D}^{(2)}\mathbf{H}, \qquad \mathbf{H} = \mathbf{I} - \frac{1}{m}\mathbf{1}\mathbf{1}^\top$$

其中 $\mathbf{D}^{(2)}$ 是距离平方矩阵。

**（2）特征分解**

$$\mathbf{B} = \sum_j \lambda_j \boldsymbol{v}_j\boldsymbol{v}_j^\top$$

**（3）低维坐标**

$$\mathbf{Z} = [\sqrt{\lambda_1}\boldsymbol{v}_1,\ \dots,\ \sqrt{\lambda_k}\boldsymbol{v}_k]$$

**关键结论**：**若距离是欧氏距离，经典 MDS 与 PCA 给出完全相同的结果**（$\mathbf{B}$ 正是中心化后的格拉姆矩阵）。

所以 MDS 的价值在于：**可以用任意距离（不限于欧氏）**，例如社交网络上的最短路径、文本的余弦距离。

## 三、Isomap

### 3.1 核心思想

**用"沿着流形表面的距离"（测地距离）代替欧氏距离。**

**瑞士卷上两点**：

- 欧氏距离：直线穿过卷层的距离（很短，但"绕近路"了）；
- 测地距离：沿着卷面爬行的距离（较长，但反映真实相似度）。

### 3.2 算法

```
1. 构建邻接图:
   对每个样本，连接它的 k 个最近邻（或半径 epsilon 内的所有点）
   边的权重 = 欧氏距离
2. 计算最短路径:
   用 Dijkstra 或 Floyd-Warshall 求出所有点对的【图上最短路径】
   作为"测地距离"的近似  -> 得到矩阵 D_G
3. 对 D_G 做经典 MDS:
   双中心化 -> 特征分解 -> 取前 d 维坐标
```

### 3.3 关键点与局限

| 项目 | 说明 |
| --- | --- |
| 邻域大小 $k$ | 太小 → 图不连通；太大 → "短路"（把不该连的点连上） |
| 复杂度 | $O(m^2\log m)$ 到 $O(m^3)$，不适合大数据 |
| 局限 | 要求流形是**凸的、等距嵌入**的；有"洞"或有噪声时失效 |
| 局限 | 无法处理新的测试样本（**没有 out-of-sample 扩展**） |

**补齐 out-of-sample 的方法**：训练一个回归模型把 $\boldsymbol{x}$ 映射到 Isomap 坐标（sklearn 的 `Isomap.transform` 就是这么做的）。

## 四、LLE（局部线性嵌入）

### 4.1 核心思想

> **每个样本都可以用它的邻居线性表示；这种局部线性关系在降维后应该保持。**

### 4.2 两步

**第一步：在原始空间求重构权重**

$$\min_{\mathbf{W}}\ \sum_{i=1}^{m}\left\|\boldsymbol{x}_i - \sum_{j\in N(i)}w_{ij}\boldsymbol{x}_j\right\|^2$$
$$\text{s.t.}\quad \sum_{j}w_{ij} = 1$$

（对每个样本独立求解一个带约束的最小二乘；$N(i)$ 是 $k$ 近邻集合。）

**第二步：在低维空间保持权重不变，求坐标**

$$\min_{\{\boldsymbol{z}_i\}}\ \sum_{i=1}^{m}\left\|\boldsymbol{z}_i - \sum_{j}w_{ij}\boldsymbol{z}_j\right\|^2 \quad\text{s.t.}\quad \sum_i\boldsymbol{z}_i = \boldsymbol{0},\ \frac{1}{m}\sum_i\boldsymbol{z}_i\boldsymbol{z}_i^\top = \mathbf{I}$$

**解**：令 $\mathbf{M} = (\mathbf{I}-\mathbf{W})^\top(\mathbf{I}-\mathbf{W})$，取 $\mathbf{M}$ 的**最小若干非零特征值**对应的特征向量（最小的那个特征值恒为 0，对应常向量，需跳过）。

### 4.3 LLE vs Isomap

| 维度 | Isomap | LLE |
| --- | --- | --- |
| 保持的性质 | **全局**测地距离 | **局部**线性权重 |
| 计算 | 最短路 + MDS | 两次最小二乘/特征分解 |
| 对噪声 | 较敏感（最短路会被噪声"短路"） | 较敏感 |
| 不适合 | 非凸流形 | 邻域内样本共线（权重解不唯一）|

## 五、t-SNE

### 5.1 核心思想

**把"高维中的相似性"转成概率，再在低维中匹配这个概率分布。**

**第一步：高维中的相似度**

对每个点 $i$，以它为中心构造高斯分布：

$$p_{j|i} = \frac{\exp(-\|\boldsymbol{x}_i-\boldsymbol{x}_j\|^2/2\sigma_i^2)}{\sum_{k\ne i}\exp(-\|\boldsymbol{x}_i-\boldsymbol{x}_k\|^2/2\sigma_i^2)}$$

对称化：$p_{ij} = \frac{p_{j|i}+p_{i|j}}{2m}$。

**注意**：$\sigma_i$ 由**困惑度（perplexity）**自动确定：

$$\text{Perp}(P_i) = 2^{H(P_i)}$$

其中 $H$ 是 $P_i$ 的熵。困惑度可理解为"有效邻居数"，典型取 5–50。

**第二步：低维中的相似度**（用**重尾的 t 分布**，自由度 1，即柯西分布）

$$q_{ij} = \frac{(1+\|\boldsymbol{z}_i-\boldsymbol{z}_j\|^2)^{-1}}{\sum_{k\ne l}(1+\|\boldsymbol{z}_k-\boldsymbol{z}_l\|^2)^{-1}}$$

**为什么用 t 分布**：低维空间会被压缩（"拥挤问题"）。重尾分布让**中等距离的点在低维中能推得更远**，缓解拥挤。

**第三步：最小化 KL 散度**

$$\min_{Z}\ D_{KL}(P\|Q) = \sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$$

用梯度下降求解：

$$\frac{\partial D_{KL}}{\partial\boldsymbol{z}_i} = 4\sum_j(p_{ij}-q_{ij})(\boldsymbol{z}_i-\boldsymbol{z}_j)(1+\|\boldsymbol{z}_i-\boldsymbol{z}_j\|^2)^{-1}$$

### 5.2 t-SNE 的三个使用禁忌

| 禁忌 | 说明 |
| --- | --- |
| **不要解读簇间距离** | t-SNE 只保持局部结构。两个簇看起来"离得远"不代表真的不相似 |
| **不要解读簇的大小** | 簇的密度和大小在高维与低维间不成比例 |
| **不要用于下游任务特征** | t-SNE 结果不稳定（随机初始化、困惑度敏感），不具可复现性 |

**正确的用法**：**仅用于二维/三维可视化探索**。

**t-SNE 的替代**：**UMAP** 更快、更好地保持全局结构，也支持 out-of-sample 扩展，近年在工业界更流行。

## 六、自编码器（Autoencoder）

### 6.1 结构

```
   输入 x ∈ R^d
        ↓  编码器 f_θ
   隐表示 z ∈ R^k   (k << d)     <- 这就是降维后的表示
        ↓  解码器 g_φ
   重构 x̂ ∈ R^d
```

**目标**：

$$\min_{\boldsymbol{\theta},\boldsymbol{\phi}}\ \sum_{i=1}^{m}\left\|\boldsymbol{x}_i - g_{\boldsymbol{\phi}}(f_{\boldsymbol{\theta}}(\boldsymbol{x}_i))\right\|^2$$

### 6.2 与 PCA 的关系

**结论**：**若编码器与解码器都是线性的、且隐层维度为 $k$，则自编码器的最优解张成的子空间与 PCA 相同。**

**证明思路**：此时模型就是 $\hat{\boldsymbol{x}} = \mathbf{W}_2\mathbf{W}_1\boldsymbol{x}$，最小化重构误差等价于找最优的秩 $k$ 线性投影，而由 Eckart–Young 定理，最优解就是前 $k$ 个主成分。

**自编码器的价值**：**加入非线性激活后，它能学习非线性流形**。

### 6.3 常见变体

| 变体 | 关键改动 | 作用 |
| --- | --- | --- |
| **去噪自编码器（DAE）** | 输入加噪，目标仍是恢复原图 | 学到更鲁棒的表征 |
| **稀疏自编码器** | 对隐层加 $L_1$ 惩罚 | 学稀疏特征（类似 V1 视觉皮层） |
| **收缩自编码器（CAE）** | 惩罚编码器 Jacobian 的 Frobenius 范数 | 对输入扰动不敏感 |
| **欠完备 vs 过完备** | $k<d$ vs $k>d$ | 过完备需加正则（否则学恒等映射）|
| **VAE** | 隐层是概率分布 | 生成模型（Week12） |

### 6.4 自编码器 vs PCA vs 流形学习

| 方法 | 表达能力 | 能否处理新样本 | 是否需要调参 |
| --- | --- | --- | --- |
| PCA | 线性 | （乘 $\mathbf{W}$） | 少 |
| 核 PCA | 非线性 | （需核函数） | 中 |
| Isomap / LLE | 非线性 | （需额外回归） | 中 |
| t-SNE | 非线性 | | 多 |
| **自编码器** | **任意非线性** | （前向传播） | **多** |

**自编码器是唯一同时具备"强表达能力"与"天然支持新样本"的方法**，这也是它成为深度学习表征学习基础的原因。

## 七、代码实践

```python
def isomap(X, n_neighbors=10, n_components=2):
    """Isomap: 邻接图 + 最短路径 + 经典 MDS"""
    m = len(X)
    D = np.sqrt(((X[:, None, :] - X[None, :, :]) ** 2).sum(axis=2))

    # 1. k 近邻图
    G = np.full((m, m), np.inf)
    np.fill_diagonal(G, 0)
    for i in range(m):
        idx = np.argsort(D[i])[1:n_neighbors + 1]
        G[i, idx] = D[i, idx]
        G[idx, i] = D[i, idx]           # 无向图

    # 2. Floyd-Warshall 最短路
    for k in range(m):
        G = np.minimum(G, G[:, k:k + 1] + G[k:k + 1, :])

    # 3. 经典 MDS
    D2 = G ** 2
    H = np.eye(m) - np.ones((m, m)) / m
    B = -0.5 * H @ D2 @ H
    vals, vecs = np.linalg.eigh(B)
    order = np.argsort(vals)[::-1][:n_components]
    return vecs[:, order] * np.sqrt(np.maximum(vals[order], 0))
```

## 八、常见坑

| 坑 | 说明 |
| --- | --- |
| 用 t-SNE 解释簇间距离 | t-SNE 只保局部结构 |
| 用 t-SNE 结果做下游特征 | 不稳定、不可复现 |
| Isomap 的 $k$ 设得太大 | "短路"，测地距离失真 |
| Isomap 的 $k$ 设得太小 | 图不连通，无穷距离 |
| 认为 LLE 一定能展开任何流形 | 对非凸流形与噪声敏感 |
| 自编码器不加正则且 $k>d$ | 会学到恒等映射（无意义）|
| 用重构误差评估一切降维 | 不同方法的目标不同，不能只用重构误差 |
| 忘记标准化 | 所有基于距离的方法都受影响 |

<details>
<summary>第 8 题答案要点</summary>

**拥挤问题**：高维空间中，能"容纳"很多彼此适度的距离；低维空间（2–3 维）容积有限，若用高斯分布建模，中等距离的点会被迫挤在一起，导致簇之间的空隙消失。

**t 分布（重尾）的特性**：

$$q_{ij}\propto (1+\|\boldsymbol{z}_i-\boldsymbol{z}_j\|^2)^{-1}$$

对大距离，$q_{ij}\sim 1/d^2$，衰减慢得多（高斯是 $e^{-d^2}$）。

**效果**：在优化中，为了让 $q_{ij}$ 匹配 $p_{ij}$，**中等距离的点必须被推得更远**，从而在低维中形成清晰的簇间空隙。

**代价**：这种"过度分离"正是 t-SNE 不能解读簇间距离的原因。
</details>

<details>
<summary>第 10 题答案要点</summary>

**选自编码器的场景**：

- 数据有非线性结构（图像、语音、文本）；
- 数据量大（PCA 的线性假设太强）；
- 需要可迁移的表征（作为下游任务的初始化）；
- 需要 out-of-sample 扩展同时又要非线性（Isomap/LLE 做不到）；
- 有 GPU 与调参预算。

**选 PCA 的场景**：

- 需要极快、可解释、确定性结果；
- 数据量小或维度不高；
- 作为 baseline 与数据探察；
- 后续模型对白化/正交性有要求；
- 计算资源受限。

**实践策略**：**先跑 PCA 看能解释多少方差**。若前 10 个主成分就能解释 95% 的方差，说明数据近似线性，自编码器的收益有限。
</details>
