## 一、SVM 的调参路线图

### 1.1 两个核心超参数

| 参数 | 作用 | 增大时 |
| --- | --- | --- |
| `C` | 惩罚违规样本的强度 | 间隔变窄、偏置↓方差↑（过拟合） |
| `gamma` | RBF 核的作用半径倒数 | 决策边界更弯曲（过拟合） |
| `kernel` | 映射方式 | 先试 linear，再试 rbf |

### 1.2 调参顺序（重要）

```
1. 先做标准化（StandardScaler）——SVM 对尺度极敏感
2. kernel='rbf'，C 与 gamma 做对数网格搜索
   典型网格: C ∈ {2^-5, 2^-3, ..., 2^15}
             gamma ∈ {2^-15, 2^-13, ..., 2^3}
   这是 scikit-learn 官方文档推荐的网格
3. 若数据维度 >> 样本数（文本）→ 改用 linear 核
4. 若类别不平衡 → class_weight='balanced'
5. 用【分层交叉验证】评估，不要用单次留出
```

### 1.3 为什么必须做对数网格

$C$ 与 $\gamma$ 的**有效范围跨越多个数量级**（$10^{-5}$ 到 $10^{5}$）。线性均匀采样会几乎全部落在同一量级，浪费搜索。

## 二、支持向量与泛化

### 2.1 支持向量比例

由统计学习理论，泛化误差界与支持向量比例相关（粗略地）：

$$\text{期望泛化误差} \lesssim \frac{\text{支持向量数}}{m}$$

**经验规则**：

| 支持向量占比 | 诊断 |
| --- | --- |
| &lt; 20% | 正常，模型简洁 |
| 30%–50% | 一般 |
| > 60% | 可能 $C$ 过大 / 过拟合，或数据本身难分 |

### 2.2 支持向量的可解释性

SVM 的决策只由支持向量决定 ⇒ 可以在**支持向量**上做解释分析：

- 哪些训练样本是"关键样本"（对抗攻击的常见目标）；
- 新增一个样本时，只需判断它是否成为支持向量（增量 SVM 的基础）。

## 三、从决策值到概率：Platt Scaling

### 3.1 问题

SVM 输出的是决策函数值 $f(\boldsymbol{x})$，范围 $(-\infty,+\infty)$，**不是概率**。

直接把 $f$ 归一化到 $[0,1]$ 是错的（它不是校准过的概率）。

### 3.2 Platt Scaling

在验证集上拟合一个 sigmoid：

$$\boxed{\ P(y=1\mid f) = \frac{1}{1+\exp(Af + B)}\ }$$

**参数 $A, B$ 的拟合**：用最大似然（注意要用带标签平滑的目标，避免过拟合）：

$$\min_{A,B}\ -\sum_{i=1}^{m}\left[t_i\log p_i + (1-t_i)\log(1-p_i)\right]$$

其中 $t_i$ 是**目标概率**（Platt 建议用平滑值）：

$$t_i = \begin{cases}\frac{N_+ + 1}{N_+ + 2}, & y_i = +1\\[4pt] \frac{1}{N_- + 2}, & y_i = -1\end{cases}$$

**为什么需要标签平滑**：避免 $f$ 很极端时 sigmoid 参数被推往无穷。

### 3.3 实践提示

- **不要用训练集拟合 $A,B$**（会过拟合）；必须用独立验证集或交叉验证；
- sklearn 中 `SVC(probability=True)` 内部就用 Platt Scaling（并要求 `random_state` 以保证交叉验证可复现）；
- Platt Scaling 也会**改变预测结果**（阈值变了），如需保持原决策，可只在输出概率时使用。

### 3.4 其他校准方法

| 方法 | 特点 |
| --- | --- |
| Platt Scaling | 参数化，样本少时更好 |
| Isotonic Regression | 非参数，样本多时更好，但会过拟合小样本 |
| Temperature Scaling | 神经网络常用，只调一个温度 |

## 四、SVM 的工程适用边界

| 场景 | 建议 |
| --- | --- |
| 样本数 $m < 10^4$，维度中等 | **SVM（RBF）非常好** |
| $m$ 很大（$>10^5$） | 用线性 SVM（LIBLINEAR）或改用 GBDT/神经网络 |
| 维度极高且稀疏（文本） | 线性 SVM / 逻辑回归 |
| 需要概率输出 | SVM + Platt，或直接用逻辑回归 |
| 需要解释性 | 树模型或线性模型 |
| 类别极不平衡 | SVM + 类别权重，或改用 PR-AUC 评估的树模型 |

**复杂度提醒**：

| 求解器 | 复杂度 | 适用 |
| --- | --- | --- |
| libsvm（核 SVM） | $O(m^2)\sim O(m^3)$ | $m \lesssim 10^4$ |
| liblinear（线性 SVM） | $O(mn)$ 左右 | $m$ 大、$n$ 大 |

## 五、代码实践

```python
import numpy as np

def platt_scaling(scores, y, n_plus, n_minus, epochs=3000, lr=0.1):
    """
    在验证集上拟合 P(y=1|f) = sigmoid(A f + B)
    y ∈ {+1, -1}
    """
    t = np.where(y > 0, (n_plus + 1) / (n_plus + 2), 1.0 / (n_minus + 2))
    A, B = 0.0, 0.0
    for _ in range(epochs):
        p = 1.0 / (1.0 + np.exp(-(A * scores + B)))
        gA = float(((p - t) * scores).sum())
        gB = float((p - t).sum())
        A -= lr * gA / len(y)
        B -= lr * gB / len(y)
    return A, B
```

## 六、常见坑

| 坑 | 说明 |
| --- | --- |
| 不标准化 | SVM 对特征尺度极敏感，必须 `StandardScaler` |
| 用线性网格搜 $C,\gamma$ | 必须对数网格 |
| 在训练集上拟合 Platt 参数 | 过拟合，概率不可信 |
| `probability=True` 却不设随机种子 | Platt 的内部交叉验证不可复现 |
| 大数据集用核 SVM | 训练时间爆炸 |
| 只看准确率 | SAP 类不平衡数据要用 PR-AUC / F1 |
| 认为支持向量越多越好 | 支持向量多说明间隔被"撑满"，通常不是好事 |
| 忽略 `cache_size` | 默认缓存小，大数据集训练慢；可调到 500–1000MB |

<details>
<summary>第 7 题答案要点</summary>

**方向相反**。

软间隔 SVM 的目标：

$$\min\ \frac{1}{2}\|\boldsymbol{w}\|^2 + C\sum_i\max(0, 1-y_if(\boldsymbol{x}_i))$$

除以 $C$：

$$\min\ \frac{1}{2C}\|\boldsymbol{w}\|^2 + \sum_i\text{hinge}_i$$

即 L2 正则系数 $\lambda = \frac{1}{2C}$。

因此：

- $C$ 大 → $\lambda$ 小 → **正则弱**；
- $C$ 小 → $\lambda$ 大 → **正则强**。

**注意**：只在"只看正则项权重"的意义上可比；两者的损失函数不同（合页 vs 交叉熵），因此最优参数不对应同一数值。
</details>

<details>
<summary>第 9 题答案要点</summary>

**方案一：线性模型 + SGD**

用 `SGDClassifier(loss='hinge')` 或 `LinearSVC`（LIBLINEAR），复杂度近似线性于样本数。

**方案二：换用 GBDT / LightGBM**

LightGBM 用直方图 + GOSS 采样，在亿级样本上训练时间可控，且精度通常优于线性模型。

**方案三：先用欠采样 / 分层抽样训练，再在全量上校准**

**方案四：改为在线学习**

用 `partial_fit` 做增量训练，避免一次性载入全部数据。

**结论**：核 SVM 的 $O(m^3)$ 复杂度在这个量级完全不可行。
</details>
