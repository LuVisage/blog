> 西瓜书第 3 章 · 南瓜书第 3 章

线性模型是所有机器学习算法的"原型"。SVM 是它的最大间隔版本，神经网络是它的多层堆叠版本，逻辑回归至今仍是工业界最常用的分类器之一。**把这一周吃透，后面 9 周都会轻松很多。**

---

## 本周目标

学完本周，你应该能够：

1. 推导最小二乘的闭式解，理解正规方程与几何投影的两种视角；
2. 分清批量梯度下降、随机梯度下降、小批量梯度下降的取舍，并解释 SGD 为什么能"逃出"鞍点；
3. 独立推导逻辑回归的梯度，并说清它与广义线性模型（GLM）的关系；
4. 掌握线性判别分析 LDA 的 Fisher 视角与广义特征值解法；
5. 会用 OvO / OvR / 多分类软最大化处理多分类问题；
6. 掌握类别不平衡的三种处理手段：重采样、类别权重、阈值调整。

- [ ] 我能说明逻辑回归的损失函数是凸的，为什么
- [ ] 我能写出 LDA 的广义特征值问题 $\mathbf{S}_w^{-1}\mathbf{S}_b\boldsymbol{w} = \lambda\boldsymbol{w}$
- [ ] 我知道 OvR 训练 $k$ 个分类器，OvO 训练 $k(k-1)/2$ 个
- [ ] 我能实现类别权重加权的逻辑回归

## 一条主线

```
            线性回归 (回归)
              │
              │ 把输出通过 sigmoid 映射到 (0,1)
              ↓
            对数几率回归 (二分类)
              │
              │ softmax / OvO / OvR
              ↓
            多分类
              │
              │ 换成"最大间隔"的损失
              ↓
            SVM (Week05)
              │
              │ 堆叠多层 + 非线性激活
              ↓
            神经网络 (Week07)
```

**线性模型是这条主线的起点。**
