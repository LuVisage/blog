## 一、模型形式

### 1.1 一元线性回归

$$f(x) = wx + b$$

**几何意义**：用一条直线去拟合散点。

### 1.2 多元线性回归

$$f(\boldsymbol{x}) = \boldsymbol{w}^\top\boldsymbol{x} + b = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$$

**技巧：把偏置吸收进权重**。令 $\boldsymbol{x}' = (1, x_1, \dots, x_n)^\top$，$\boldsymbol{w}' = (b, w_1, \dots, w_n)^\top$，则

$$f(\boldsymbol{x}') = \boldsymbol{w}'^\top\boldsymbol{x}'$$

**所以后文一律省略 $b$，视为权重的一个分量。**

### 1.3 数据集表示

$$\mathbf{X} = \begin{bmatrix} 1 & x_{11} & \cdots & x_{1n} \\ 1 & x_{21} & \cdots & x_{2n} \\ \vdots & & & \vdots \\ 1 & x_{m1} & \cdots & x_{mn}\end{bmatrix} \in \mathbb{R}^{m\times (n+1)}, \qquad \boldsymbol{y} = \begin{bmatrix}y_1\\ \vdots \\ y_m\end{bmatrix} \in \mathbb{R}^m$$

**预测向量**：

$$\hat{\boldsymbol{y}} = \mathbf{X}\boldsymbol{w} \in \mathbb{R}^m$$

**残差**：

$$\boldsymbol{r} = \boldsymbol{y} - \mathbf{X}\boldsymbol{w}$$

## 二、损失函数：为什么是平方误差

### 2.1 高斯噪声假设

设真实关系为

$$y = \boldsymbol{w}^\top\boldsymbol{x} + \epsilon, \qquad \epsilon \sim \mathcal{N}(0, \sigma^2)$$

则

$$p(y \mid \boldsymbol{x}; \boldsymbol{w}) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(y - \boldsymbol{w}^\top\boldsymbol{x})^2}{2\sigma^2}\right)$$

### 2.2 最大似然 → 最小二乘

对 $m$ 个 i.i.d. 样本，对数似然：

$$\ell(\boldsymbol{w}) = \sum_{i=1}^m \log p(y_i|\boldsymbol{x}_i;\boldsymbol{w}) = -\frac{m}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^m (y_i - \boldsymbol{w}^\top\boldsymbol{x}_i)^2$$

第一项与 $\boldsymbol{w}$ 无关。最大化 $\ell$ 等价于：

$$\min_{\boldsymbol{w}} \sum_{i=1}^m (y_i - \boldsymbol{w}^\top\boldsymbol{x}_i)^2 = \|\mathbf{X}\boldsymbol{w} - \boldsymbol{y}\|_2^2$$

> **结论**：**平方损失 = 高斯噪声假设下的最大似然。** 若噪声是拉普拉斯分布，MLE 会给出绝对值损失（MAE）。

### 2.3 损失函数

$$L(\boldsymbol{w}) = \frac{1}{2}\|\mathbf{X}\boldsymbol{w} - \boldsymbol{y}\|_2^2 = \frac{1}{2}(\mathbf{X}\boldsymbol{w}-\boldsymbol{y})^\top(\mathbf{X}\boldsymbol{w}-\boldsymbol{y})$$
（乘 $1/2$ 只是为了求导时消掉系数 2。）

---

## 三、解法一：矩阵求导

展开：

$$L(\boldsymbol{w}) = \frac{1}{2}\left[\boldsymbol{w}^\top\mathbf{X}^\top\mathbf{X}\boldsymbol{w} - 2\boldsymbol{y}^\top\mathbf{X}\boldsymbol{w} + \boldsymbol{y}^\top\boldsymbol{y}\right]$$

利用两条矩阵求导公式（$\mathbf{A}$ 对称）：

$$\nabla_{\boldsymbol{w}}\left[\boldsymbol{w}^\top\mathbf{A}\boldsymbol{w}\right] = 2\mathbf{A}\boldsymbol{w}, \qquad \nabla_{\boldsymbol{w}}\left[\boldsymbol{b}^\top\boldsymbol{w}\right] = \boldsymbol{b}$$

得到：

$$\nabla_{\boldsymbol{w}} L = \mathbf{X}^\top\mathbf{X}\boldsymbol{w} - \mathbf{X}^\top\boldsymbol{y}$$

令梯度为零：

$$\boxed{\ \mathbf{X}^\top\mathbf{X}\boldsymbol{w} = \mathbf{X}^\top\boldsymbol{y} \quad\text{（正规方程）}\ }$$

若 $\mathbf{X}^\top\mathbf{X}$ 可逆：

$$\boxed{\ \hat{\boldsymbol{w}} = (\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\boldsymbol{y}\ }$$

> **凸性说明**：$\mathbf{X}^\top\mathbf{X}$ 半正定 ⇒ Hessian $= \mathbf{X}^\top\mathbf{X} \succeq 0$ ⇒ $L$ 是凸函数 ⇒ 令梯度为零得到的必是**全局最小**。

---

## 四、解法二：几何投影（更直观）

把 $\mathbf{X}$ 的每一列看作一个向量，所有可能的预测 $\mathbf{X}\boldsymbol{w}$ 构成 $\mathbf{X}$ 的**列空间** $\mathcal{C}(\mathbf{X})$。

我们要在 $\mathcal{C}(\mathbf{X})$ 中找一个向量 $\hat{\boldsymbol{y}}$，使它离 $\boldsymbol{y}$ 最近：

$$\hat{\boldsymbol{y}} = \arg\min_{\boldsymbol{v}\in\mathcal{C}(\mathbf{X})}\|\boldsymbol{v} - \boldsymbol{y}\|$$

**几何结论**：最近点就是**正交投影**，即残差 $\boldsymbol{y}-\hat{\boldsymbol{y}}$ 必须垂直于列空间：

$$\mathbf{X}^\top(\boldsymbol{y} - \mathbf{X}\hat{\boldsymbol{w}}) = \boldsymbol{0} \quad\Rightarrow\quad \mathbf{X}^\top\mathbf{X}\hat{\boldsymbol{w}} = \mathbf{X}^\top\boldsymbol{y}$$

**同一个正规方程，两种完全不同的推导方式。** 投影视角在理解 PCA、最小二乘、岭回归时都非常有用。

```
        y
        ●
        |\
        | \  残差 r = y - Xŵ  (垂直于列空间)
        |  \
        |   ●  ŷ = Xŵ  ← 投影点
        |  /
        | /
        |/
  ──────┴──────────→  C(X)  (X 的列空间)
```

**推论**：

1. $\hat{\boldsymbol{y}} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\boldsymbol{y} = \mathbf{H}\boldsymbol{y}$，其中 $\mathbf{H}$ 是**投影矩阵**（帽子矩阵），满足 $\mathbf{H}^2 = \mathbf{H}$、$\mathbf{H}^\top = \mathbf{H}$；
2. $\operatorname{tr}(\mathbf{H}) = n+1$ ⇒ **线性回归的有效参数个数**（也是 Week08 讲自由度、AIC/BIC 的基础）。

## 五、不可逆时怎么办

$\mathbf{X}^\top\mathbf{X}$ 不可逆的常见原因：

1. **特征数 > 样本数**（$n > m$）：欠定问题，有无穷多解；
2. **多重共线性**：某些列线性相关（例如"身高(cm)"与"身高(m)"）。

### 解决方案对照

| 方法 | 公式 | 特点 |
| --- | --- | --- |
| 伪逆 | $\mathbf{X}^+\boldsymbol{y}$ | 给出**最小范数解** |
| 岭回归（L2） | $(\mathbf{X}^\top\mathbf{X}+\lambda\mathbf{I})^{-1}\mathbf{X}^\top\boldsymbol{y}$ | 加 $\lambda\mathbf{I}$ 保证可逆，且缩小权重 |
| Lasso（L1） | 无闭式解，用坐标下降 | 产生稀疏解，可做特征选择 |
| 降维 | 先 PCA 再回归 | 消除共线性 |
| 特征选择 | 去掉相关特征 | 简单直接 |

### 岭回归为什么一定可逆

$$\mathbf{X}^\top\mathbf{X} + \lambda\mathbf{I}$$

若 $\lambda>0$，则对任意非零 $\boldsymbol{v}$：

$$\boldsymbol{v}^\top(\mathbf{X}^\top\mathbf{X}+\lambda\mathbf{I})\boldsymbol{v} = \underbrace{\|\mathbf{X}\boldsymbol{v}\|^2}_{\ge 0} + \lambda\underbrace{\|\boldsymbol{v}\|^2}_{>0} > 0$$

所以矩阵**正定 ⇒ 可逆**。这是岭回归最重要的性质。

## 六、线性模型如何做非线性拟合

**核心思想**：**对特征做非线性变换，模型对参数仍然是线性的。**

$$f(\boldsymbol{x}) = \boldsymbol{w}^\top\phi(\boldsymbol{x})$$

常用的 $\phi$：

| 名称 | 形式 |
| --- | --- |
| 多项式 | $\phi(x) = (1, x, x^2, \dots, x^d)$ |
| 高斯径向基（RBF） | $\phi_j(x) = \exp\left(-\frac{(x-\mu_j)^2}{2\sigma^2}\right)$ |
| 傅里叶基 | $\phi_j(x) = \cos(jx), \sin(jx)$ |
| Sigmoid 基 | $\phi_j(x) = \sigma(a_j x + b_j)$ |

**关键区分**：

- **对参数线性**：仍可用最小二乘闭式解 ；
- **对原始输入非线性**：表达能力大大增强 。

> 神经网络就是"把 $\phi$ 也变成可学习的"——这才是深度学习与非深度学习的本质差别。

## 七、代码实践

```python
import numpy as np

def fit_linear_regression(X, y, lam=0.0):
    """最小二乘 / 岭回归的统一实现"""
    A = X.T @ X + lam * np.eye(X.shape[1])
    return np.linalg.solve(A, X.T @ y)      # 比显式求逆数值更稳定

def r2_score(y, y_pred):
    ss_res = ((y - y_pred) ** 2).sum()
    ss_tot = ((y - y.mean()) ** 2).sum()
    return 1 - ss_res / ss_tot

def soft_threshold(z, gamma):
    """软阈值算子：Lasso 坐标下降的核心"""
    return np.sign(z) * max(abs(z) - gamma, 0.0)
```

## 八、常见坑

| 坑 | 说明 |
| --- | --- |
| 用 `inv(X.T @ X)` | 条件数被平方，数值不稳定；用 `np.linalg.solve` 或 `lstsq` |
| 忘记加截距列 | 拟合直线强制过原点，偏差极大 |
| 用 $R^2$ 比较不同数据集的模型 | $R^2$ 依赖于该数据集的方差，跨数据集不可比 |
| 特征未标准化就做岭回归 | 罚项对尺度敏感，量纲大的特征被压得更多 |
| 认为线性模型不能拟合曲线 | 加多项式/RBF 基即可 |
| 认为 Lasso 一定能选对特征 | 高度相关特征中 Lasso 会随机保留一个，不稳定 |
| 用训练集 $R^2$ 评估 | 高维下训练 $R^2$ 必然接近 1 |

## 九、练习题

**基础**

1. 对 $L(\boldsymbol{w}) = \frac{1}{2}\|\mathbf{X}\boldsymbol{w}-\boldsymbol{y}\|^2$ 求梯度，写出完整过程。
2. 用数据 $(1,2),(2,3),(3,5),(4,8)$ 手算一元线性回归的 $w$ 与 $b$。
3. 解释投影矩阵 $\mathbf{H} = \mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top$ 为什么满足 $\mathbf{H}^2=\mathbf{H}$。

**进阶**

4. 推导岭回归的闭式解，并说明当 $\lambda\to 0$ 与 $\lambda\to\infty$ 时解分别趋于什么。
5. 证明 $\operatorname{tr}(\mathbf{H}) = n+1$（$n$ 为特征数）。（提示：利用迹的轮换性）
6. 对 $d$ 阶多项式回归，若训练样本数为 $m$，什么时候会出现欠定问题？

**思考题**

7. 为什么说"线性回归的 $R^2$ 在训练集上会随特征数单调不减"？这对模型选择意味着什么？
8. Lasso 用 $L_1$ 惩罚能产生稀疏解，但它对高度相关的特征不稳定（组内只随机保留一个）。请解释原因，并说明 Elastic Net（$L_1+L_2$）如何缓解。

<details>
<summary>第 2 题答案</summary>

$$\bar x = 2.5,\ \bar y = 4.5$$

$$w = \frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2} = \frac{(-1.5)(-2.5)+(-0.5)(-1.5)+(0.5)(0.5)+(1.5)(3.5)}{2.25+0.25+0.25+2.25} = \frac{9.5}{5} = 1.9$$

$$b = \bar y - w\bar x = 4.5 - 1.9\times 2.5 = -0.25$$
</details>

<details>
<summary>第 5 题提示</summary>

$\operatorname{tr}(\mathbf{H}) = \operatorname{tr}(\mathbf{X}(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top) = \operatorname{tr}((\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{X}) = \operatorname{tr}(\mathbf{I}_{n+1}) = n+1$

（用迹的轮换性 $\operatorname{tr}(\mathbf{AB}) = \operatorname{tr}(\mathbf{BA})$。）

**含义**：线性回归消耗了 $n+1$ 个自由度，这正是 AIC/BIC 中"参数惩罚项"的来源。
</details>
