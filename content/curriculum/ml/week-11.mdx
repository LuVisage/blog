Week10 结尾的消融实验里，全连接网络在 MNIST 上的天花板停在 98.3% 左右。这一周换掉"拍平"的做法，用**局部感受野 + 权重共享**，让精度首次突破 99%。

**卷积是深度学习里最重要的结构性先验**：它把"图像相邻像素相关"和"同一模式出现在不同位置"这两条常识，直接编码进了网络结构。

## 本周核心公式

**输出尺寸**（最常用的一个公式，务必记牢）：

$$H_{out} = \left\lfloor \frac{H_{in} + 2P - K}{S} \right\rfloor + 1$$

其中 $K$ 是卷积核大小，$P$ 是填充，$S$ 是步长。

**"same" 填充**（输出与输入同尺寸，$S=1$ 时）：$P = (K-1)/2$

**参数量**（不含偏置）：

$$\text{Params} = K \times K \times C_{in} \times C_{out}$$

**计算量**（FLOPs，乘加各算一次）：

$$\text{FLOPs} = H_{out} \times W_{out} \times K^2 \times C_{in} \times C_{out}$$

## 为什么卷积是"先验"而不是"技巧"

```
全连接层的假设：每个输入像素对每个输出都有独立影响   -> 参数量 784×128 = 100,352
卷积层的假设：  局部相关 + 模式平移不变           -> 参数量 3×3×1×32 = 288
```

**同样连到 32 个输出通道，参数量差了 348 倍。** 这个差距不是"省参数"这么简单，而是：

- 参数少 → 需要的数据少 → 小数据集也能训好；
- 结构先验正确 → 学到的特征更符合图像的物理规律；
- **平移等变** → 同一模式无论出现在图像哪个位置，都会被同一个卷积核检测到。

在数据有限时，**正确的先验比更大的模型更值钱**。
