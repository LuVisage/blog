## 1.1 命令行：只需要会这五个动作

命令行（终端）就是"用打字的方式指挥电脑"。本教程只需要 5 个动作：

| 动作 | Windows (cmd/PowerShell) | macOS / Linux | 意思 |
| --- | --- | --- | --- |
| 看当前在哪个文件夹 | `cd` | `pwd` | print working directory |
| 看文件夹里有什么 | `dir` | `ls` | list |
| 进入某文件夹 | `cd 文件夹名` | `cd 文件夹名` | change directory |
| 退回上一级 | `cd ..` | `cd ..` | |
| 运行 Python | `python 脚本.py` | `python3 脚本.py` | |

**今天就练这一个流程**：

```bash
# 1. 建一个文件夹放代码（比如叫 ai_tutorial）
# 2. 进入它
cd ai_tutorial
# 3. 把 Day1 的 day1_first_run.py 放进去（或自己新建）
# 4. 运行它
python day1_first_run.py
```

> **VS Code 用户**：`终端 → 新建终端` 会自动打开在当前文件夹，`cd` 都省了。
> 后文所有"在命令行运行"都默认你已 cd 到代码所在目录。

## 1.2 第一个程序：它到底做了什么

```python
print("hello, world")
```

**逐个部分拆开**：

| 部分 | 是什么 |
| --- | --- |
| `print` | 一个**函数**——Python 自带的"做某件事的工具"，这里是"打印" |
| `( )` | 括号表示"调用"这个函数——"开始干活" |
| `"hello, world"` | 一个**字符串**（一段文字），是传给函数的**参数**（原料） |

**试这三个变体**（先猜输出，再运行）：

```python
print("hello")              # 打印文字
print(1 + 2)                # 打印计算结果：3
print("1 + 2")              # 打印文字本身：1 + 2   ← 注意区别！
```

**`"1 + 2"` 和 `1 + 2` 的区别**是编程的第一课：**带引号的是"文字"，不带引号的是"数据"**。
引号里的内容 Python 只当字符处理，不会计算。

## 1.4 今日重点：读懂报错（Traceback）

**报错是 Python 在大声告诉你哪里出了问题。** 学会读它，你就不再怕它。

### 1.4.1 一个完整的报错长这样

假设你写了：

```python
print("hello)
```

运行后会看到：

```
  File "day1_first_run.py", line 3
    print("hello)
          ^
SyntaxError: unterminated string literal (detected at line 3)
```

**从下往上读，四步定位**：

| 步骤 | 读什么 | 这个例子里 |
| --- | --- | --- |
| ① **最后一行**：错误类型 + 说明 | `SyntaxError`（语法错误）+ 引号没闭合 |
| ② **中间的箭头 `^`** | 指向出问题的位置 | 指向字符串开头附近 |
| ③ **`line 3`** | 出错的行号 | 第 3 行 |
| ④ **`File "..."`** | 出错的文件 | day1_first_run.py |

> **90% 的报错，只看最后一行 + 行号就够了。**

### 1.4.2 0 基础最常遇到的 6 种报错（背下来）

| 报错（最后一行） | 意思 | 典型原因 |
| --- | --- | --- |
| `SyntaxError: invalid syntax` | 语法写错了 | 少了冒号 `:`、括号没闭合。**注意：真正的错可能在这行的上一行** |
| `NameError: name 'xxx' is not defined` | 用了不存在的名字 | 变量名拼写错误；或在使用前没赋值 |
| `IndentationError: expected an indented block` | 缩进不对 | `if/for/def` 后面的行忘了缩进（4 个空格） |
| `TypeError: can only concatenate str ...` | 类型用错了 | `"age:" + 18` —— 文字和数字不能直接相加，要 `str(18)` |
| `ModuleNotFoundError: No module named 'xxx'` | 找不到包 | 包没装：`pip install xxx` |
| `FileNotFoundError` | 文件不存在 | 文件名/路径写错，或不在当前目录 |

**练习方法**：把 `code/day1_first_run.py` 运行一遍（它会故意演示 6 种错误），
每看到一种，**合上教程**说出它是哪类、怎么修。

### 1.4.3 修错的正确姿势

```
报错了 ✗
  ├─ 读最后一行 → 知道错误类型
  ├─ 看行号 → 跳到那一行
  ├─ 看箭头 → 定位到具体位置
  ├─ 修好 → 再运行
  └─ 还有错 → 重复（这不是失败，这就是写程序的日常）
```

**坏习惯**（0 基础最容易养成）：
- 报错了就从头重敲一遍
- 报错了就问"为什么我的是错的"（不贴报错信息）
- 看到长报错就慌（长报错 = 调用链，只看最后一行）

## 1.5 变量：给数据起名字

```python
name = "小明"          # 把字符串 "小明" 存进名叫 name 的变量
age = 18               # 把整数 18 存进 age

print(name)            # 小明
print(age)             # 18
print(name, age)       # 小明 18    ← print 可以一次打多个，逗号隔开

age = age + 1          # 右边先算出 19，再存回 age（现在 age 是 19）
print(age)             # 19
```

**三个要点**：

1. `=` 是"**把右边的值存进左边**"，不是数学的"相等"；
2. 变量名用**小写英文 + 下划线**：`user_name` ，`UserName` / `a1` / `xing-ming` ；
3. 变量**先赋值再使用**，否则 `NameError`。

**常见类型**（Day2 展开）：

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| `int` | `18` | 整数 |
| `float` | `3.14` | 小数 |
| `str` | `"hello"` | 文字（必须带引号） |
| `bool` | `True` / `False` | 真假（注意大写开头） |

## 1.6 f-string：把变量嵌进文字里

```python
name = "小明"
age = 19
print(f"{name} 今年 {age} 岁")        # 小明 今年 19 岁
print(f"明年 {age + 1} 岁")           # 引号里能直接做计算
print(f"圆周率约 {3.14159:.2f}")      # .2f = 保留两位小数 → 3.14
```

**规则**：字符串**前面加 `f`**，内部用 `{}` 包住变量或表达式。

这是本教程输出信息的标准写法，比 `"名字是" + name` 这种拼接干净得多
（而且后者对数字会直接报 `TypeError`——见 1.4.2 的表）。

## 1.7 交互模式：即敲即得的练习场

在命令行直接输入 `python`（不带文件名）回车，会进入**交互模式**（提示符变成 `>>>`）：

```python
>>> 2 + 3
5
>>> name = "test"
>>> name.upper()
'TEST'
>>> exit()          # 或按 Ctrl+Z 再回车（mac 是 Ctrl+D）退出
```

**用途**：想快速验证"这个函数怎么用"时，先在这里试，再写进文件。
**注意**：交互模式里的代码**不会保存**，正式代码一定要写到 `.py` 文件里。
