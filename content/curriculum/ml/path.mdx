## 五、怎么用这套教程

0. **0 基础从 Week00 开始**：完全没写过代码的同学，先完成
 [Week00 零基础起步](/learn/ml/week-00)（一周），再进入 Week01。
 已会 Python 的可直接跳到 Week01。
1. **按周推进，一天一篇**：每天 2–3 小时，先读文档再跑 `code/` 里的脚本，最后做练习题。
2. **代码必须亲手跑**：所有脚本都保证 CPU 可运行，`python dayX_xxx.py` 即可。
3. **公式要动笔**：西瓜书/南瓜书类的推导，建议在纸上各推一遍。
4. **不要跳周**：Week10 之后的内容强依赖 Week01–09 的符号体系与代码直觉。
5. **每周末做一次复盘**：用每周 README 里的"检查清单"自测。

## 六、运行环境

```bash
# Week00（零基础起步）只需要这两个
pip install numpy matplotlib

# 核心依赖（Week01-08 逐步用到）
pip install pandas scikit-learn scipy

# 深度学习与视觉（Week09 起）
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

# 文本处理（Week08 Day4）
pip install jieba nltk

# 图像处理（Week15）
pip install opencv-python pillow

# 国内加速
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

**所有代码均支持 CPU 运行**，没有显卡不影响学习。

## 八、接下来学什么

16 周基础教程覆盖了「模型是怎么工作的」。但**能训练模型 ≠ 能交付产品**。
如果你的目标是「AI 应用工程师 / Agent 开发工程师」，还需要补**软件工程**：

| 缺口 | 内容 | 教程位置 | 状态 |
| --- | --- | --- | --- |
| Python 工程化 | async/await、类型注解、装饰器、pytest、logging、项目结构 | `Python工程化与后端实战/Week1` | 完整（82 个测试通过） |
| 后端开发 | FastAPI、HTTP/SSE、JWT、限流、统一错误处理 | `Python工程化与后端实战/Week2` | 完整（48 个测试通过） |
| 数据库 | Postgres 参数化查询/索引/N+1、Redis 限流/缓存、事务 | `Python工程化与后端实战/Week3` | 完整（72 个测试通过） |
| 部署运维 | Docker 多阶段构建、compose、Nginx（SSE 配置）、CI/CD | `Python工程化与后端实战/Week4` | 配置齐全（需 Docker 环境验证） |
| 向量检索与 RAG | 切分/HNSW/重排/引用来源、RAGAS 评估、毕业项目 | `Python工程化与后端实战/Week5` | 完整（23 个测试通过） |

**推荐顺序**：16 周基础 → `Python工程化与后端实战/`（Week1-2 可直接上手跑）→ Agent 开发

所以它**可以与 16 周基础教程并行学**，不必等基础全部学完。
