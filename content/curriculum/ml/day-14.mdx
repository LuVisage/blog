> 西瓜书第 2 章 2.5 节 · 南瓜书 2.40–2.46

今天推导全课程最重要的一个公式：

$$\mathbb{E}\left[(y - \hat f(\boldsymbol{x}))^2\right] = \underbrace{\left(\mathbb{E}[\hat f] - f\right)^2}_{\text{偏置}^2} + \underbrace{\mathbb{E}\left[(\hat f - \mathbb{E}[\hat f])^2\right]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{噪声}}$$

它解释了：**为什么更复杂的模型不一定更好**，以及**为什么集成学习有效**。

## 一、问题的设定

假设真实的数据生成过程：

$$y = f(\boldsymbol{x}) + \epsilon, \qquad \mathbb{E}[\epsilon] = 0, \qquad \operatorname{Var}(\epsilon) = \sigma^2$$

- $f(\boldsymbol{x})$：真实（未知）的目标函数；
- $\epsilon$：噪声，与 $\boldsymbol{x}$ 独立，不可通过任何模型消除。

我们用**不同的训练集** $\mathcal{D}_1, \mathcal{D}_2, \dots$（都来自同一个分布 $\mathcal{P}$）训练，得到一组模型 $\hat f_1, \hat f_2, \dots$。

**关注量**：在固定测试点 $\boldsymbol{x}$ 上的**期望测试误差**：

$$\mathbb{E}_{\mathcal{D}, \epsilon}\left[\left(y - \hat f_{\mathcal{D}}(\boldsymbol{x})\right)^2\right]$$

注意这里的期望**同时对所有可能的训练集 $\mathcal{D}$ 和噪声 $\epsilon$ 取**。

---

## 二、完整推导

为了书写简洁，记 $\hat f = \hat f_{\mathcal{D}}(\boldsymbol{x})$，$f = f(\boldsymbol{x})$，$\bar f = \mathbb{E}_{\mathcal{D}}[\hat f]$（对训练集求平均得到的"平均模型"）。

**推导**：

$$y - \hat f = (f + \epsilon) - \hat f = (f - \bar f) + (\bar f - \hat f) + \epsilon$$

记三项：$A = f - \bar f$（常数，与 $\mathcal{D}, \epsilon$ 无关）、$B = \bar f - \hat f$、$C = \epsilon$。

平方期望展开：

$$\mathbb{E}[(A+B+C)^2] = \mathbb{E}[A^2] + \mathbb{E}[B^2] + \mathbb{E}[C^2] + 2\mathbb{E}[AB] + 2\mathbb{E}[AC] + 2\mathbb{E}[BC]$$

**逐项处理交叉项**：

1. $\mathbb{E}[AB] = A\,\mathbb{E}[\bar f - \hat f] = A(\bar f - \bar f) = 0$；
2. $\mathbb{E}[AC] = A\,\mathbb{E}[\epsilon] = 0$（噪声均值为 0 且与 $\mathcal{D}$ 独立）；
3. $\mathbb{E}[BC] = \mathbb{E}[(\bar f - \hat f)\epsilon] = \mathbb{E}[\bar f - \hat f]\,\mathbb{E}[\epsilon] = 0$（独立性）。

所以交叉项全为 0：

$$\boxed{\ \mathbb{E}[(y-\hat f)^2] = \underbrace{(f - \bar f)^2}_{\text{偏置}^2\ \text{Bias}^2} + \underbrace{\mathbb{E}[(\hat f - \bar f)^2]}_{\text{方差}\ \text{Variance}} + \underbrace{\sigma^2}_{\text{噪声}}\ }$$

**推导核心技巧**：把 $y - \hat f$ 拆成"真实值偏离平均模型" + "平均模型偏离当前模型" + "噪声"三部分，交叉项因独立性全部消失。

---

## 三、三项的含义

### 3.1 偏置 $^2$（Bias²）

$$\text{Bias}^2 = (f - \mathbb{E}[\hat f])^2$$

**含义**：**模型族的平均预测与真实函数的偏离程度**。

- 由**模型假设**决定（模型容量不足 → 高偏置）；
- 与训练集无关，只对模型族取平均。

**高偏置的例子**：

- 用线性模型拟合 $y = \sin(x)$（模型无法表达周期模式）；
- 用线性模型拟合 $y = x^2$；
- 决策树深度限制为 1（只能做单特征阈值切分）。

### 3.2 方差（Variance）

$$\text{Variance} = \mathbb{E}_{\mathcal{D}}\left[(\hat f_{\mathcal{D}} - \mathbb{E}[\hat f])^2\right]$$

**含义**：**不同训练集训练出的模型，预测的波动有多大**。

- 由**模型对数据扰动的敏感度**决定；
- 模型越复杂/越灵活 → 方差越大。

**高方差的例子**：

- 高次多项式拟合少量数据（换个训练集曲线就完全不同）；
- $k=1$ 的 kNN（只看最近的一个点）；
- 深度无限制的决策树（能记住每个样本）。

### 3.3 噪声 $\sigma^2$

$$\sigma^2 = \operatorname{Var}(\epsilon)$$

**含义**：**数据本身的内在随机性**。

- 无论用什么模型都**无法降低**（不可约误差，irreducible error）；
- 它给出了泛化误差的**下界**。

**噪声来源**：测量误差、标注错误、缺失特征、未观测的变量。

> **重要推论**：**如果再好的模型的平方误差也只能降到 $\sigma^2$，那么"训练集误差 = 0"永远不是目标，而是过拟合的信号。**

## 四、偏差-方差窘境（Tradeoff）

### 4.1 图示

```
误差
 ↑
 |‾‾‾‾\                              /‾‾‾‾
 |     \          总误差            /
 |      \        ↙      ↘         /
 |       \      /         \     /
 |        \    /            \ /
 |   Bias² \  /  Variance    X   ← 最优复杂度
 |         \/                 \
 |         /\                  \
 +--------/--\--------------------→ 模型复杂度
         简单                     复杂
```

- **复杂度低**：Bias² 高、Variance 低（模型太死板，对数据不敏感）；
- **复杂度高**：Bias² 低、Variance 高（模型太灵活，记住了噪声）；
- **总误差**：U 形曲线，最低点在两者平衡处。

### 4.2 各种算法的偏差-方差特性

| 算法 | 偏差 | 方差 | 说明 |
| --- | --- | --- | --- |
| 线性回归 | 高 | 低 | 假设太强 |
| 决策树（深） | 低 | 高 | 完全拟合训练集 |
| kNN（$k=1$） | 低 | 极高 | 只看最近点 |
| kNN（$k$ 大） | 高 | 低 | 变大范围平滑 |
| 随机森林 | 低 | 中 | Bagging 降方差 |
| GBDT | 低 | 中 | Boosting 降偏差 |
| 深层神经网络 | 低 | 高（需正则化） | 参数量巨大 |

> **Bagging 与 Boosting 的核心区别**（Week04 详解）：
> - **Bagging**：对多个**高方差**模型取平均 → **降方差**（如随机森林）；
> - **Boosting**：串行地让新模型专注纠正前一个模型的错误 → **降偏差**（如 AdaBoost、GBDT）。

### 4.3 数学直觉：为什么取平均能降方差

设 $M$ 个**独立**的模型，各自方差为 $\sigma^2_{\text{model}}$，则平均模型的方差：

$$\operatorname{Var}\left(\frac{1}{M}\sum_{i=1}^M \hat f_i\right) = \frac{\sigma^2_{\text{model}}}{M}$$

方差降为原来的 $1/M$，而偏差不变。

**现实中各模型不独立**（都用同一份数据训练），若两两相关系数为 $\rho$：

$$\operatorname{Var} = \rho\,\sigma^2_{\text{model}} + \frac{1-\rho}{M}\sigma^2_{\text{model}}$$

- $M \to \infty$ 时方差趋于 $\rho\,\sigma^2_{\text{model}}$；
- **所以降低模型间的相关性（$\rho$）比单纯增加模型数量更重要**——这正是随机森林"随机选特征"的动机。

## 五、用学习曲线诊断

**学习曲线**：横轴为训练样本数（或迭代轮数），纵轴为误差，同时画训练误差与验证误差。

### 情形 A：欠拟合（高偏置）

```
误差
 ↑
 |  ────────────────────────  训练误差（高）
 |  ────────────────────────  验证误差（高，与训练误差接近）
 |
 +────────────────────────→ 样本数
```

**特征**：两条曲线都高，且**几乎重合**。
**对策**：增加模型复杂度、增加特征、减小正则化。

### 情形 B：过拟合（高方差）

```
误差
 ↑
 |  ────────────────          验证误差（高）
 |          ╱‾‾‾‾‾‾
 |  ───────╱──────            训练误差（很低）
 |
 +────────────────────────→ 样本数
```

**特征**：训练误差很低，验证误差高，**两者 gap 大**。
**对策**：增加数据、正则化、简化模型、早停、集成。

### 情形 C：良好拟合

```
误差
 ↑
 |  ────\                    验证误差
 |       \____
 |  ──────\______            训练误差
 |          ‾‾‾‾‾ ≈ 验证误差
 +────────────────────────→ 样本数
```

**特征**：两者都收敛到较低水平，gap 小。
**对策**：增加数据可能还能提升，但收益递减。

## 六、代码实践：实验验证偏差-方差

```python
import numpy as np

def true_f(x):
    return np.sin(x)

def experiment(degree, n_train=30, n_repeat=300, noise=0.2, seed=0):
    """重复多次采样训练集，估计给定复杂度的 Bias^2 与 Variance"""
    rng = np.random.default_rng(seed)
    x_test = np.linspace(-3, 3, 100)          # 固定测试点
    preds = np.zeros((n_repeat, len(x_test)))

    for r in range(n_repeat):
        x_tr = rng.uniform(-3, 3, n_train)
        y_tr = true_f(x_tr) + rng.normal(0, noise, n_train)
        coef = np.polyfit(x_tr, y_tr, degree)   # 最小二乘多项式拟合
        preds[r] = np.polyval(coef, x_test)

    mean_pred = preds.mean(axis=0)
    bias2 = ((mean_pred - true_f(x_test)) ** 2).mean()
    var = preds.var(axis=0).mean()
    return bias2, var, noise ** 2
```

完整版本见 `code/day4_bias_variance.py`，它会：

1. 对 degree = 1, 3, 5, 9, 15 分别估计 Bias²、Variance 与总误差，打印成表格；
2. 验证 `Bias² + Var + σ² ≈ 真实测试 MSE`；
3. 画出单次运行的不同复杂度拟合曲线（直观展示过拟合/欠拟合）。

**预期输出**（大致趋势）：

```
degree  Bias^2    Variance   Noise    Total      真实验证MSE
1       0.46      0.01       0.04     0.51       0.51
3       0.01      0.02       0.04     0.07       0.07
5       0.01      0.05       0.04     0.10       0.10
9       0.02      0.30       0.04     0.36       0.36
15      0.05      2.10       0.04     2.19       2.20
```

**结论**：degree=3 时总误差最小；更大的 degree 方差急剧上升，总误差反超。

## 七、常见坑

| 坑 | 说明 |
| --- | --- |
| 认为"增加数据能解决所有问题" | 高偏置（模型太简单）时增加数据无用，必须提升模型容量 |
| 追求训练误差最小 | 训练误差可以到 0，但泛化误差有下界 $\sigma^2$ |
| 把验证误差直接当作泛化误差 | 验证误差本身有随机性，需多次重复或交叉验证 |
| 忽略噪声的下界 | 若噪声 $\sigma^2$ 很大，任何模型都无法达到高精度 |
| 认为偏差-方差分解对 0-1 损失也成立 | 该分解是**平方损失**下的结论；分类的 0-1 损失有类似但更复杂的分解 |
| 只看单次实验结论 | 偏差/方差的估计需要重复多次采样 |

> **重要边界条件**：上面的分解严格成立于**平方损失**。对 0-1 损失（分类准确率），分解形式更复杂（Domínguez-Conde 等，2020），但"模型复杂度 → 偏差降、方差升"的定性结论依然成立。

## 八、练习题

**基础**

1. 用自己的话解释：什么是"偏置"？什么是"方差"？为什么二者难以同时最小？
2. 一个模型的训练误差 0.02，验证误差 0.35，判断它是过拟合还是欠拟合，给出两种对策。
3. 训练误差 0.30，验证误差 0.32，判断状态并给出对策。

**进阶**

4. 完整推导偏差-方差分解，说明为什么三个交叉项都为零。
5. 设有 $M$ 个两两相关系数为 $\rho$、方差为 $\sigma^2$ 的模型。证明平均模型的方差为
   $$\operatorname{Var} = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$$
6. 若噪声标准差 $\sigma = 0.5$，一个完美模型（$\hat f = f$）的期望平方误差是多少？这说明了什么？

**思考题**

7. 为什么 kNN 的 $k$ 增大时偏差上升、方差下降？请从"邻居平均的范围"角度解释。
8. 随机森林（Bagging）能降低方差但不能显著降低偏差，而 GBDT（Boosting）能降低偏差。请从"模型组合方式"的角度解释为什么。（提示：Bagging 是**并行平均**，Boosting 是**串行修正残差**。）
9. 有学者指出"偏差-方差分解在深度学习中可能误导人"（Belkin 等的"双下降"现象）。请简单说明：为什么在过参数化区间，测试误差会先上升再下降？

<details>
<summary>第 5 题答案</summary>

$$\operatorname{Var}\left(\frac{1}{M}\sum_i \hat f_i\right) = \frac{1}{M^2}\left[\sum_i \operatorname{Var}(\hat f_i) + \sum_{i\ne j}\operatorname{Cov}(\hat f_i,\hat f_j)\right]$$

$$= \frac{1}{M^2}\left[M\sigma^2 + M(M-1)\rho\sigma^2\right] = \frac{\sigma^2}{M}\left[1 + (M-1)\rho\right] = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$$
</details>

<details>
<summary>第 6 题答案</summary>

$$\mathbb{E}[(y-\hat f)^2] = 0 + 0 + \sigma^2 = \sigma^2 = 0.25$$

**说明**：即使模型完全学出真实函数 $f$，误差仍有 0.25。**这是不可约误差下界**。训练误差接近 0 而验证误差始终 > 0.25 时，说明模型已经开始拟合噪声。
</details>

<details>
<summary>第 9 题提示</summary>

**双下降（Double Descent）**：随着模型参数增加，测试误差先下降（经典区间）、再上升（过参数化前的"插值阈值"附近）、再下降（过参数化区间）。

一种解释：在过参数化区间，模型有很多组解能完美拟合训练数据。**SGD 的隐式正则化会倾向于找到范数小、泛化好的那些解**，因此误差重新下降。"偏差-方差分解只描述了单一下降区间"，因此看似矛盾。
</details>

## 九、一句话总结

**泛化误差 = 偏置² + 方差 + 不可约噪声。模型选择就是在这三项之间找平衡；理解这一点，你就理解了机器学习中最核心的取舍。**
