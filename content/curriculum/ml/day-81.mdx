## 1.2 判别模型 vs 生成模型

| | 判别模型（前 15 周） | 生成模型（本周） |
| --- | --- | --- |
| 学什么 | $P(y\mid x)$ | $P(x)$ |
| 输入 | $x$ | 无（或条件 $c$） |
| 输出 | 标签 $y$ | **一个新样本** |
| 例子 | 分类、检测 | 图像生成、文本生成 |
| 评估 | accuracy / mAP（客观） | FID / 人眼（主观，见 1.7） |

**自编码器（Autoencoder, AE）不是严格的生成模型** —— 它能重构，但**不能凭空生成新样本**（这是 Day2 的 VAE 要解决的问题）。

但它是理解生成模型的**最好入口**：结构简单，训练稳定，且三个实际应用都非常有用。

## 1.3 结构：编码 - 瓶颈 - 解码

```
输入 x (784)
   ↓
┌─────────────┐
│   Encoder   │  784 -> 256 -> 64
└─────────────┘
   ↓
潜表示 z (64)     ← ★ 瓶颈层（bottleneck）
   ↓
┌─────────────┐
│   Decoder   │  64 -> 256 -> 784
└─────────────┘
   ↓
重构 x̂ (784)
```

**损失函数**就是重构误差：

$$\mathcal{L} = \|x - \hat{x}\|^2 \quad\text{或}\quad \text{BCE}(x, \hat{x})$$

### 关键：瓶颈层为什么有用

**如果潜表示 $z$ 的维度 ≥ 输入维度**，网络可以学出一个**恒等映射**（$z = x$，$\hat{x} = z$）—— 什么都没学到。

**瓶颈强迫压缩**：

$$784 \to 64 \quad\Rightarrow\quad \text{压缩比 } 12:1$$

网络必须**放弃不重要的信息，只保留最能代表数据的主干结构**。

**这与 Week01 的 PCA 是同一个目标**：

| | PCA | 自编码器 |
| --- | --- | --- |
| 降维方式 | **线性**投影 | **非线性**（有激活函数） |
| 求解 | 特征分解（闭式解） | 梯度下降 |
| 表达能力 | 线性子空间 | 任意流形 |

> **关键区别**：如果去掉所有激活函数，自编码器会**退化成 PCA**（各主成分张成的子空间）。激活函数是它比 PCA 强的地方。

## 1.4 三个实际应用

### 1.4.1 降维与可视化

把 784 维压到 **2 维**，就可以直接画散点图看数据结构。

**与 t-SNE / PCA 的对比**：

| 方法 | 特点 |
| --- | --- |
| PCA | 线性、快、可解释（主成分方向） |
| t-SNE | 非线性、慢、**只适合可视化**（不能用于新样本） |
| **AE** | 非线性、**可编码新样本**、可嵌入模型 |

**AE 的独特优势**：训练好后，`encoder` 是一个**可复用的特征提取器** —— 可以直接接到下游分类器上。

### 1.4.2 去噪自编码器（Denoising AE）

**做法**：

- **输入**：加噪的图 $x + \epsilon$
- **目标**：干净的图 $x$

$$\mathcal{L} = \|x - D(E(x+\epsilon))\|^2$$

**为什么这能提升表示质量**：

要让"带噪输入"输出"干净图像"，网络必须学到**噪声不变的本质特征**，而不能简单地记住像素。

> **这是"自监督学习"的早期范式**：不需要人工标注，用"加噪-去噪"这个任务本身来构造监督信号。

**与 Week15 Day2 的对比**：中值/高斯滤波是**人工设计的**去噪算子；DAE 是**从数据学出来的**去噪器。

### 1.4.3 异常检测（最实用）

**核心假设**：正常样本常见 → AE 学得好 → 重构误差小；异常样本罕见 → AE 没见过 → 重构误差大。

**流程**：

```
① 只用【正常样本】训练 AE
② 在验证集上统计重构误差的分布，取分位数作为阈值
③ 推理时: 重构误差 > 阈值 -> 判为异常
```

**为什么这个方法在工业界非常流行**：

| 优点 | 说明 |
| --- | --- |
| **只需正常样本** | 异常样本本来就少且难收集 |
| 无监督 | 不需要标注 |
| 可解释 | 能定位到"哪个区域重构得差"（像素级热力图） |
| 训练快 | 小模型即可 |

**典型应用**：工业质检、服务器异常检测、医学影像筛查。

## 1.5 完整实现

```python
class Autoencoder(nn.Module):
    def __init__(self, latent=32):
        super().__init__()
        self.encoder = nn.Sequential(
            nn.Flatten(),
            nn.Linear(784, 256), nn.ReLU(),
            nn.Linear(256, 64), nn.ReLU(),
            nn.Linear(64, latent),
        )
        self.decoder = nn.Sequential(
            nn.Linear(latent, 64), nn.ReLU(),
            nn.Linear(64, 256), nn.ReLU(),
            nn.Linear(256, 784), nn.Sigmoid(),   # 输出归一化到 [0,1]
        )

    def forward(self, x):
        z = self.encoder(x)
        return self.decoder(z), z
```

**四个工程细节**：

| 细节 | 理由 |
| --- | --- |
| 最后一层用 `Sigmoid` | 输入已被归一化到 $[0,1]$，输出也要匹配 |
| 损失用 `MSELoss` 或 `BCELoss` | 前者适合 $[0,1]$ 连续值，后者适合二值 |
| 不用 `BatchNorm` 在瓶颈层 | 会破坏潜空间的连续性（对 VAE 尤其重要） |
| 潜维度是**超参数** | 太小 → 重构糊；太大 → 学不到压缩表示 |

**潜维度怎么选**：从 2 到 128 扫一遍，看重构损失与下游任务精度。

## 1.6 自编码器的局限：为什么需要 VAE

**问题**：AE 的潜空间是**不连续的、不规则的**。

```
AE 的潜空间                         VAE 的潜空间
┌──────────────────────┐          ┌──────────────────────┐
│  ●   ●               │          │     ╭──────╮          │
│    ●     ●           │          │   ╭─╯      ╰─╮        │
│  ●        ●  ●       │          │  │  ● ●  ●   │        │
│      ●               │          │   ╰─╮  ●  ╭─╯        │
│   ●              ●   │          │     ╰──────╯          │
└──────────────────────┘          └──────────────────────┘
  训练样本的 z 散落在各处            近似标准正态分布
  中间的空白区域 → 解码出垃圾        处处都能解码出合理图像
```

**具体表现**：

1. **采样生成不了有意义的东西** —— 随机取一个 $z$，解码器可能输出噪声（因为那个区域训练时没见过）；
2. **潜空间有"空洞"** —— 两个样本的 $z$ 之间插值，中间的解码结果可能毫无意义；
3. **没有概率解释** —— 无法算 $P(x)$，也无法做贝叶斯推断。

**VAE 的解法**：**强制潜空间服从标准正态分布**（用 KL 散度约束），让潜空间**处处连续、处处可解码**。

这就是 Day2 的内容。

## 1.7 生成模型的评估难题（提前认知）

**分类任务的评估是客观的**：准确率、F1，一个数字说明问题。

**生成任务的评估困难得多**：

| 指标 | 做法 | 局限 |
| --- | --- | --- |
| **重构误差** | MSE / PSNR / SSIM | 只对 AE 类有效；与人类感知不总一致 |
| **IS**（Inception Score） | 用分类器评判生成图的"清晰度"与"多样性" | 偏向 ImageNet 类别，且不反映真实分布 |
| **FID** | 真实图与生成图在特征空间的分布距离 | **最常用**，但对样本量敏感，且依赖特征提取器 |
| **人眼评估** | 人工打分 | 昂贵、主观、不可复现 |

**核心困难**：**"像不像"这件事没有唯一正确答案。**

一张生成的猫图，像素级 MSE 可能很差（因为位置偏移了几像素），但人眼觉得非常像。反之，MSE 很低但人眼看着糊。

> **工程建议**：生成任务上，**指标只用于横向比较同类模型**，不能当作绝对标准。最终一定要**人眼看**。

## 1.8 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 重构结果全是平均色 | 瓶颈太小/训练不足 | 增大潜维度、多训几轮 |
| 重构完全等于输入 | 潜维度 ≥ 输入维度 | 减小瓶颈（否则什么都没学） |
| 随机采样得到噪声 | AE **不支持**采样生成 | 用 VAE（Day2） |
| 损失不降 | 忘了 `Sigmoid` / 归一化不匹配 | 检查输入输出范围一致 |
| 异常检测阈值难定 | 没在验证集上统计 | 用正常样本的误差分位数定阈值 |
| 潜空间可视化一团糊 | 用 2 维潜空间但数据太复杂 | 先用 2 维确认结构，实际用 32+ 维 |

## 1.10 一句话总结

**自编码器用"瓶颈"强迫网络学习压缩表示，在降维、去噪、异常检测上都非常实用；但它的潜空间是散乱不规则的，无法用于采样生成 —— 这正是 VAE 要解决的问题。**

**明日预告**：VAE 用一个 KL 散度约束把潜空间"整形成标准正态分布"，配合重参数化技巧让采样可导，从此可以真正地"生成"新样本。
