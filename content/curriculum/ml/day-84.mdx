## 4.2 核心思想：把"生成"变成"去噪"

**两个过程**：

```
前向（固定，无需学习）:        x_0 -> x_1 -> ... -> x_T ≈ 纯噪声
                              逐步加入高斯噪声

反向（需要学习）:              x_T -> x_{T-1} -> ... -> x_0
                              逐步去除噪声，最终得到图像
```

**关键洞察**：**加噪是确定性的、简单的；去噪是困难的、需要学习的。**

**为什么这个框架能工作**：

- 如果能把任意噪声图**减去一点点噪声**，那重复很多次就能从纯噪声"雕刻"出一张图；
- 每一步只需要"去一点点"，这个任务比"一步从噪声生成图像"简单得多；
- 所以用一个小网络反复调用即可。

**与 GAN 的对比**：

| | GAN | 扩散 |
| --- | --- | --- |
| 生成方式 | **一步**（一次前向） | **多步**（几十到上千次） |
| 每步难度 | 极高（要一步到位） | 低（只需去一点噪声） |
| 训练目标 | 对抗博弈（不稳定） | **回归**（稳定） |

> **这就是扩散模型的核心 trade-off**：用"多次迭代"换取"每步简单"。简单 ⇒ 训练稳定；多次 ⇒ 采样慢。

## 4.3 前向过程：逐步加噪

**定义**：每一步加入少量高斯噪声。

$$q(x_t \mid x_{t-1}) = \mathcal{N}\left(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t\mathbf{I}\right)$$

其中 $\beta_t$ 是噪声调度（noise schedule），从 $\beta_1 = 10^{-4}$ 线性增加到 $\beta_T = 0.02$。

**注意那个 $\sqrt{1-\beta_t}$**：为什么要乘它？

为了让**方差保持稳定**。如果不乘，每一步加噪声后方差会不断累积增长，$T$ 步后方差会爆炸。

$$x_t = \sqrt{1-\beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\epsilon, \qquad \epsilon\sim\mathcal{N}(0,\mathbf{I})$$

验证：若 $\text{Var}(x_{t-1}) = 1$，则 $\text{Var}(x_t) = (1-\beta_t) + \beta_t = 1$

### 闭式解（最重要的公式）

**好消息**：不需要一步步迭代，可以直接算出任意 $t$ 时刻的 $x_t$。

设 $\alpha_t = 1-\beta_t$，$\bar\alpha_t = \prod_{s=1}^{t}\alpha_s$：

$$\boxed{x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon, \qquad \epsilon\sim\mathcal{N}(0,\mathbf{I})}$$

**推导**（用高斯相加的性质）：

$$\text{Var}(a\epsilon_1 + b\epsilon_2) = a^2 + b^2 \quad\text{（当 }\epsilon_i\sim\mathcal{N}(0,1)\text{ 独立）}$$

两步合并：

$$x_t = \sqrt{\alpha_t}\left(\sqrt{\alpha_{t-1}}x_{t-2} + \sqrt{1-\alpha_{t-1}}\epsilon_1\right) + \sqrt{1-\alpha_t}\epsilon_2$$
$$= \sqrt{\alpha_t\alpha_{t-1}}\,x_{t-2} + \underbrace{\sqrt{\alpha_t(1-\alpha_{t-1})}\epsilon_1 + \sqrt{1-\alpha_t}\epsilon_2}_{\text{方差} = \alpha_t(1-\alpha_{t-1}) + (1-\alpha_t) = 1-\alpha_t\alpha_{t-1}}$$

归纳即得闭式解。

**这个性质极其重要**：训练时可以**随机采一个 $t$，一步算出 $x_t$**，不需要跑 $t$ 步。

**$\bar\alpha_t$ 的物理意义**：

| $t$ | $\bar\alpha_t$ | $x_t$ 的样子 |
| --- | --- | --- |
| 0 | 1.0 | 原图 |
| $T/4$ | ~0.7 | 轻微噪声 |
| $T/2$ | ~0.3 | 明显噪声 |
| $T$ | ~0.0001 | **纯噪声** |

## 4.4 训练目标：预测噪声

**理论上的目标**（最大化对数似然的下界）经过一系列推导，可以简化到一个极其简单的形式：

$$\mathcal{L}_{\text{simple}} = \mathbb{E}_{t,\,x_0,\,\epsilon}\left[\left\|\epsilon - \epsilon_\theta(x_t, t)\right\|^2\right]$$

**翻译成人话**：

```
① 从训练集取一张图 x_0
② 随机采一个时间步 t
③ 随机采一个噪声 eps
④ 用闭式解算出 x_t = sqrt(alpha_bar_t)*x_0 + sqrt(1-alpha_bar_t)*eps
⑤ 让网络预测: 我加的噪声是什么？
⑥ 损失 = (预测的噪声 - 真实噪声)^2
```

**这个训练目标为什么这么简洁**：

- 原来要预测 $q(x_{t-1}|x_t)$ 的均值与方差（两个输出）；
- 但由于高斯性质，**均值可以完全由"预测的噪声"推出**；
- 所以网络只需要预测一个东西：**噪声**。

### 网络怎么知道当前是第几步

**时间步 $t$ 必须作为输入喂给网络**，否则它无法判断"该去多少噪声"。

**做法**：位置编码（Week14 Day2 的正弦编码）→ 过 MLP → 加到网络每一层的偏置上。

```python
class SinusoidalPosEmb(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):
        half = self.dim // 2
        freqs = torch.exp(-math.log(10000) * torch.arange(half, device=t.device) / half)
        emb = t[:, None].float() * freqs[None] * 1000
        return torch.cat([emb.sin(), emb.cos()], dim=-1)
```

> **注意**：这里复用了 Week14 Day2 的位置编码思想 —— **Transformer 用它编码"序列位置"，扩散用它编码"时间步"**。同一个技巧在不同场景的迁移，是深度学习里反复出现的模式。

## 4.5 采样：迭代去噪

训练好后，生成流程是从纯噪声开始，逐步去噪：

```python
x = torch.randn(shape)                      # 从纯噪声开始
for t in reversed(range(T)):
    eps_pred = model(x, t)                  # 预测噪声
    # 按 DDPM 的公式反推一步
    x = (x - (beta_t / sqrt(1 - alpha_bar_t)) * eps_pred) / sqrt(alpha_t)
    if t > 0:
        x = x + sqrt(beta_t) * torch.randn_like(x)    # 加一点随机扰动
return x
```

**三个要点**：

| 要点 | 说明 |
| --- | --- |
| **每一步都加一点噪声** | 除了 $t=0$，否则生成会过于确定、结果单一 |
| **步数可以加速** | DDIM 可以把 1000 步压缩到 20~50 步，质量损失很小 |
| **起点是纯噪声** | 所以每次生成的样本都不同 |

**采样速度的演进**：

| 方法 | 步数 |
| --- | --- |
| DDPM（原始） | 1000 |
| DDIM | 50~100 |
| Latent Diffusion | 20~50（且在潜空间操作，每步更便宜） |
| 一致性模型 / 蒸馏 | 1~4 |

## 4.6 为什么扩散比 GAN 稳定

**核心原因：训练目标是"回归"而不是"博弈"。**

| 维度 | GAN | 扩散 |
| --- | --- | --- |
| 损失 | 对抗损失（D 在变） | **MSE（目标固定）** |
| 训练目标稳定性 | 目标随对手变化 | **目标始终是"预测噪声"** |
| 是否会模式崩塌 | 会 | **不会**（每个训练样本都被重构） |
| 超参数敏感度 | 极高（lr/beta1/更新比例） | 低 |
| loss 是否有意义 | **没有**（无法从 loss 判断质量） | **有**（loss 下降 ≈ 生成变好） |

**最重要的一条**：**扩散模型的 loss 是有意义的**。你可以从训练曲线上判断进度，这在 GAN 上完全做不到。

**代价**：

| 维度 | 代价 |
| --- | --- |
| 采样速度 | 慢（几十~上千步） |
| 训练成本 | 高（每次要跑一次完整前向去噪网络） |
| 计算量 | 比 GAN 大得多 |

## 4.7 Latent Diffusion：让扩散可实用

**问题**：在 $512\times512\times3$ 像素空间做扩散，计算量太大。

**Stable Diffusion 的解法**（Rombach et al., 2022）：

```
① 先用 VAE（Day2！）把图像压到潜空间
   512x512x3  ->  64x64x4     （压缩 48 倍）

② 在潜空间上做扩散
   （计算量降低 48 倍）

③ 用 VAE 的解码器还原成图像
```

**这就是 Day2 的 VAE 在现代生成模型里的核心用途** —— 不是用它生成，而是用它**压缩**。

**三个组件**：

| 组件 | 作用 |
| --- | --- |
| **VAE 编码器/解码器** | 图像 ↔ 潜表示 |
| **U-Net** | 在潜空间上做去噪（Week11 的卷积 + 残差 + 注意力） |
| **文本编码器**（CLIP） | 把提示词变成条件向量，通过交叉注意力注入（Week14 Day3） |

> **注意**：Stable Diffusion 把前 15 周的知识全用上了 —— CNN（U-Net）、注意力（Week12/14）、VAE（Day2）、残差（Week10）。这就是为什么它是本课程的收官案例。

## 4.8 怎么判断扩散模型训得够不够（一个实测经验）

**先说结论：不要只看"锐利度"这一个指标。**

### 一个会骗人的指标

案例代码里可以观察到这个现象（100 epoch，12000 张图）：

| 来源 | 梯度幅值（锐利度） | 笔画占比 | 背景占比 | **中间灰占比** |
| --- | --- | --- | --- | --- |
| **真实样本** | 0.128 | 0.095 | 0.857 | **0.049** |
| **扩散生成** | 0.246 | 0.111 | 0.733 | **0.156** |

**单看"梯度幅值"**：生成图 0.246 是真实图 0.128 的 **1.9 倍** —— 会得出"比真实还锐利"的错误结论。

**真相是**：那部分高梯度来自**噪声**，不是笔画锐利。一个纯随机噪声图的梯度幅值会非常高。

### 更可靠的指标：中间灰占比

**MNIST 是干净的黑白图**，所以真实样本里 95% 的像素都落在两端（0.857 黑 + 0.095 白），中间灰只占 **0.049**。

$$\text{中间灰占比} = 1 - \text{笔画占比} - \text{背景占比}$$

**它高说明两件事之一**：

- 生成噪声/伪影（像素值乱跳）；
- 训练不足导致模糊（像素值取平均）。

### 实测：训练预算与中间灰占比的关系

| 训练配置 | 中间灰占比 |
| --- | --- |
| 25 epoch，12000 张（严重欠训练） | **0.533** |
| 60 epoch，12000 张 | 0.300 |
| 100 epoch，12000 张（案例默认） | 0.156 |
| 150 epoch，20000 张 | 0.086 |
| 真实样本（参考值） | 0.049 |

**训练越充分，中间灰占比越低**，逐步逼近真实样本的水平（但达不到 —— 小模型有天花板）。

> **通用教训**：**无参考的图像质量指标，单看任何一个都会误判。**
>
> - 锐利度高不一定是好事（噪声也"锐利"）；
> - 模糊度低不一定是好事（可能就是没训练好或者全输出平均值）。
>
> **必须多个指标交叉验证 + 人眼看图。** 这和 Week15 Day5 讲的"生成模型评估困难"是同一件事。

## 4.9 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 生成的图是噪声 | 训练不足 / 网络太小 | 多训；确认 loss 在降 |
| 生成的图完全一样 | 采样时忘了加随机扰动 | 补上 `+ sqrt(beta)*randn` |
| 网络学不会 | 忘了把 $t$ 喂给网络 | 加入时间步编码 |
| 前向方差爆炸 | 忘了乘 $\sqrt{1-\beta}$ | 检查公式 |
| 采样极慢 | 用了 1000 步 | 换 DDIM（50 步） |
| loss 很低但生成差 | 过拟合了训练集 | 加数据 / 减模型 |
| 训练 loss 波动大 | $t$ 采样不均匀 | 用均匀采样即可，属正常 |
| 生成结果偏暗/偏亮 | 数据归一化范围与预测目标不匹配 | 确认 $x_0\in[-1,1]$ |

## 4.9 今日自测

1. 推导闭式解 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\epsilon$。
2. 验证加了 $\sqrt{1-\beta}$ 后方差保持不变，不加会怎样。
3. 画出 $\bar\alpha_t$ 随 $t$ 的曲线，标出"图像完全变成噪声"的临界点。
4. 可视化前向过程：把同一张图在不同 $t$ 下的样子排成一行。
5. 把采样步数从 1000 降到 50、20，对比生成质量与时间。

## 4.10 一句话总结

**扩散模型把"生成"拆成"逐步去噪"：前向加噪有闭式解（训练时一步到位），反向去噪只需预测噪声（简单的回归任务）；用"多次迭代"换来了"每步简单"，从而同时拿到高质量与训练稳定性 —— 这就是它取代 GAN 的原因。**
