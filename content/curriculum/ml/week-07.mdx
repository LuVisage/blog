> 鱼书《深度学习入门》第 1–5 章 · 花书第 6 章 · 苹果书第 1–3 讲

从这一周开始进入深度学习。**本周的唯一目标：把反向传播彻底搞懂，并亲手写出来。** 后面所有网络（CNN、RNN、Transformer）都只是前向传播的结构不同，反向传播的方法完全一致。

---

## 本周目标

学完本周，你应该能够：

1. 说清"感知机为什么无法解决 XOR"，以及多层网络如何解决；
2. 掌握 5 种常用激活函数的性质与导数；
3. 理解输出层设计：回归用恒等、二分类用 sigmoid、多分类用 softmax；
4. 用**计算图**解释反向传播，并掌握"加法结点传递梯度、乘法结点交换输入"两条规则；
5. **从零实现**两层全连接网络（含前向、反向、训练、评估），仅用 NumPy；
6. 掌握训练流程规范：数据划分、标准化、权重初始化、超参搜索；
7. 会用数值微分验证反向传播的正确性（**梯度检查**）。

## 本课程的统一记号

从本周开始，符号统一为：

| 记号 | 含义 |
| --- | --- |
| $\boldsymbol{x}$ | 输入向量（一个样本） |
| $\mathbf{X}$ | 一批输入（batch） |
| $\boldsymbol{z}^{(l)}$ | 第 $l$ 层的**加权和**（pre-activation） |
| $\boldsymbol{a}^{(l)}$ | 第 $l$ 层的**激活输出**（post-activation） |
| $\mathbf{W}^{(l)}, \boldsymbol{b}^{(l)}$ | 第 $l$ 层权重与偏置 |
| $\boldsymbol{\delta}^{(l)}$ | 第 $l$ 层的**误差项** $\frac{\partial L}{\partial \boldsymbol{z}^{(l)}}$ |
| $L$ | 损失（标量） |

**前向**：

$$\boldsymbol{z}^{(l)} = \mathbf{W}^{(l)}\boldsymbol{a}^{(l-1)} + \boldsymbol{b}^{(l)}, \qquad \boldsymbol{a}^{(l)} = \sigma(\boldsymbol{z}^{(l)})$$

**反向**（核心公式，Day3/Day4 会详细推导）：

$$\boldsymbol{\delta}^{(l)} = \left(\mathbf{W}^{(l+1)\top}\boldsymbol{\delta}^{(l+1)}\right)\odot \sigma'(\boldsymbol{z}^{(l)})$$

$$\frac{\partial L}{\partial \mathbf{W}^{(l)}} = \boldsymbol{\delta}^{(l)}\boldsymbol{a}^{(l-1)\top}, \qquad \frac{\partial L}{\partial \boldsymbol{b}^{(l)}} = \boldsymbol{\delta}^{(l)}$$
