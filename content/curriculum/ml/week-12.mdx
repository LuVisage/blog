Week11 的 ResNet 解决了"能不能更深"。这一周解决下一个问题：**在精度不变的前提下，能不能更小、更快？**

## 本周目标

学完本周，你应该能够：

1. 说清 1×1 卷积的三种作用（跨通道融合、升降维、增加非线性），并会算它省下的参数量；
2. 手写深度可分离卷积，说清它与标准卷积的参数量/计算量比值；

4. 说清 EfficientNet 的复合缩放（compound scaling）为什么比单独调深度/宽度更优；
5. 在 Fashion-MNIST 上完成标准卷积 / 深度可分离 / SE 三种结构的完整对比；
6. 建立"精度-参数量-FLOPs-延迟"四维评估的工程习惯。

## 本周核心公式

**标准卷积的计算量**：

$$\text{FLOPs}_{\text{std}} = H_{out}W_{out}\cdot C_{out}\cdot C_{in}\cdot k^2$$

**深度可分离卷积的计算量**：

$$\text{FLOPs}_{\text{dw}} = \underbrace{H_{out}W_{out}\cdot C_{in}\cdot k^2}_{\text{逐通道卷积}} + \underbrace{H_{out}W_{out}\cdot C_{in}\cdot C_{out}}_{\text{逐点卷积}}$$

**两者的比值**：

$$\frac{\text{FLOPs}_{\text{dw}}}{\text{FLOPs}_{\text{std}}} = \frac{1}{C_{out}} + \frac{1}{k^2}$$

> **这是本周最重要的一个公式**。$k=3$ 时比值约 $\frac{1}{C_{out}} + \frac{1}{9}$。当 $C_{out}=256$ 时，深度可分离卷积的计算量只有标准卷积的 **11.5%**。

**SE 模块的参数量**：

$$\text{Params}_{SE} = C \cdot \frac{C}{r} + \frac{C}{r}\cdot C = \frac{2C^2}{r}$$

其中 $r$ 是压缩比（通常取 16）。

**复合缩放**：

$$\text{depth}: \alpha^\phi, \quad \text{width}: \beta^\phi, \quad \text{resolution}: \gamma^\phi$$
$$\text{s.t.}\quad \alpha\cdot\beta^2\cdot\gamma^2 \approx 2, \quad \alpha,\beta,\gamma \ge 1$$

## 为什么这一周是"工业化"的转折点

```
Week11  ResNet            「能不能更深」        —— 学术问题
Week12  MobileNet / SE    「能不能更小更快」    —— 工程问题
        EfficientNet
```

**真实项目里的约束**（按重要性排序）：

1. **能不能跑得动**（显存 / 延迟）；
2. **精度够不够**（业务指标）；
3. 训练成本；
4. 模型大小（部署体积）。

Week11 的网络精度很高但动辄上亿参数。本周的技术让同样的精度可以用 **1/10 的参数**达到。
