## 一、C4.5：增益率

### 1.1 固有值（Intrinsic Value）

ID3 的缺陷是偏爱取值多的属性。C4.5 的思路是：**给"把数据切碎"这件事本身计费。**

定义属性 $a$ 的**固有值**：

$$IV(a) = -\sum_{v=1}^{V}\frac{|D^v|}{|D|}\log_2\frac{|D^v|}{|D|}$$

**注意**：这个式子的形式与熵完全一样，只不过"概率"换成了**各子集样本比例**。

**性质**：

- 取值越多，各 $\frac{|D^v|}{|D|}$ 越接近 $1/V$，$IV(a)$ 越接近 $\log_2 V$；
- **所以 $IV$ 度量的是"属性把数据切得多碎"**。

| 属性 | 取值数 | $IV$ |
| --- | --- | --- |
| 二值属性（均衡） | 2 | 1.0 |
| 三值属性（均衡） | 3 | 1.585 |
| 编号（14 值） | 14 | 3.807（最大） |

### 1.2 增益率

$$\boxed{\ Gain\_ratio(D, a) = \frac{Gain(D, a)}{IV(a)}\ }$$

**效果**：

| 属性 | Gain | IV | 增益率 |
| --- | --- | --- | --- |
| 色泽（3 值） | 0.375 | 1.545 | **0.243** |
| 编号（14 值） | 1.000 | 3.807 | **0.263** |

编号的增益率虽然仍偏大，但差距被大幅压缩。

### 1.3 C4.5 的启发式规则

**问题**：增益率也有反向偏好——它可能**偏爱取值很少的属性**。

**极端例子**：某属性只有一个取值（常数属性）。则 $IV = 0$，增益率无定义或趋于无穷。

**C4.5 的解决办法**（两步法）：

```
1. 先在所有属性中，挑出 Gain 高于【平均水平】的候选
2. 在候选中，选 Gain_ratio 最高的
```

**伪代码**：

```python
gains = {a: gain(D, a) for a in A}
mean_gain = np.mean(list(gains.values()))
candidates = [a for a in A if gains[a] >= mean_gain]
a_star = max(candidates, key=lambda a: gain_ratio(D, a))
```

> **这本质上是一个"先过滤、再排序"的启发式**，没有理论最优性保证，但实践中很有效。

## 二、CART：基尼指数

### 2.1 定义

$$\text{Gini}(D) = \sum_{k=1}^{|\mathcal{Y}|}\sum_{k'\ne k}p_k p_{k'} = 1 - \sum_{k=1}^{|\mathcal{Y}|}p_k^2$$

**推导最后一步**：

$$\sum_{k}\sum_{k'\ne k}p_kp_{k'} = \sum_k p_k(1-p_k) = \sum_k p_k - \sum_k p_k^2 = 1 - \sum_k p_k^2$$

### 2.2 直观理解

**概率解释**：$\text{Gini}(D)$ 等于"**从 $D$ 中随机抽两个样本，它们的类别不一致的概率**"。

- 全部同类：$p_1 = 1$，$\text{Gini} = 1 - 1 = 0$（最纯）
- 二分类各半：$\text{Gini} = 1 - (0.25+0.25) = 0.5$（最乱）

**与熵的对比**：

| 分布 | 熵（bit） | 基尼 |
| --- | --- | --- |
| $(1, 0)$ | 0 | 0 |
| $(0.9, 0.1)$ | 0.469 | 0.18 |
| $(0.7, 0.3)$ | 0.881 | 0.42 |
| $(0.5, 0.5)$ | 1.000 | 0.50 |

**关键观察**：基尼与熵**形状高度相似**（都是凸函数，都在均匀分布取最大），但基尼**不需要算对数**。

### 2.3 为什么 CART 用基尼

| 维度 | 熵 | 基尼 |
| --- | --- | --- |
| 计算 | 需 `log`（慢） | 只需乘法（快） |
| 值域 | $[0, \log k]$ | $[0, 1-1/k]$ |
| 划分选择结果 | 几乎一致 | 几乎一致 |

> **工程结论**：二分类时两者的划分选择**完全一致**（因为 $1-p^2-(1-p)^2$ 与熵的单调性在 $p\in[0,1]$ 上一致），多分类时也高度相关。所以**用基尼主要是为了省时间**——这在集成学习里要跑成千上万棵树时非常重要。

### 2.4 CART 对属性的划分：基尼指数（带属性）

$$\text{Gini\_index}(D, a) = \sum_{v=1}^{V}\frac{|D^v|}{|D|}\text{Gini}(D^v)$$

**选择准则**：$\arg\min_a \text{Gini\_index}(D, a)$（**越小越好**）。

## 三、CART 的二叉树结构

### 3.1 ID3/C4.5 vs CART

| 特性 | ID3 | C4.5 | CART |
| --- | --- | --- | --- |
| 树结构 | 多叉树 | 多叉树 | **二叉树** |
| 划分准则 | 信息增益 | 增益率 | 基尼指数（分类）/ 平方误差（回归） |
| 连续属性 | 不支持 | 支持（多路划分） | 支持（二分） |
| 剪枝 | 无 | 有（悲观剪枝） | 有（代价复杂度剪枝） |
| 特征复用 | 不重用 | 不重用 | **允许重复使用同一属性** |
| 任务 | 分类 | 分类 | **分类 + 回归** |

**CART 二叉树的优势**：

1. 每个内部结点只做"是/否"判断，规则更简单；
2. 可复用属性（例如 `x1 > 3` 和 `x1 > 7` 可以在同一路径上）；
3. 天然支持连续属性（二分）；
4. 分类回归统一框架。

### 3.2 连续属性的二分

对连续属性 $a$，把取值排序，取相邻值的中点作为划分点：

$$T_a = \left\{\frac{a^i + a^{i+1}}{2} \;\middle|\; 1\le i < n\right\}$$

对每个候选划分点 $t$，计算二分后的基尼指数：

$$\text{Gini\_index}(D, a, t) = \frac{|D^-|}{|D|}\text{Gini}(D^-) + \frac{|D^+|}{|D|}\text{Gini}(D^+)$$

选最优的 $(a, t)$ 组合。

**注意**：$n$ 个取值有 $n-1$ 个候选点，加上 $d$ 个属性，一次划分要算 $d(n-1)$ 次。

> **加速技巧**：如果某个候选划分点两侧的类别分布完全相同，则基尼值相同，可以跳过。

### 3.3 CART 回归树

**分裂准则**：最小化**平方误差和**。

$$\min_{a,t}\left[\min_{c_1}\sum_{\boldsymbol{x}_i\in D^-(a,t)}(y_i-c_1)^2 + \min_{c_2}\sum_{\boldsymbol{x}_i\in D^+(a,t)}(y_i-c_2)^2\right]$$

其中最优常数为子集均值：

$$c_1 = \text{mean}(y_i : \boldsymbol{x}_i\in D^-), \quad c_2 = \text{mean}(y_i : \boldsymbol{x}_i\in D^+)$$

**预测**：落到某叶结点，输出该叶结点内训练样本的**均值**。

**几何直观**：回归树把特征空间切成矩形区域，每个区域内用常数（均值）拟合——**阶梯函数逼近**。

```
y
↑        ┌─────┐
│        │     │
│   ┌────┘     └────┐
│   │               │
└───┴───────────────┴────→ x
    分段常数逼近任何曲线
```

## 四、三种准则的对比总结

| 准则 | 公式 | 偏好 | 计算成本 | 使用者 |
| --- | --- | --- | --- | --- |
| 信息增益 | $H(D) - H(D\|a)$ | 取值多的属性 | 中（需 log） | ID3 |
| 增益率 | $\frac{Gain}{IV(a)}$ | 取值少的属性（轻微）| 高（需 log 两次） | C4.5 |
| **基尼指数** | $1-\sum p_k^2$ | **较均衡** | **低（无 log）** | **CART** |

**工程建议**：

- 分类任务：优先 CART（速度快、支持剪枝与回归），即 sklearn 的 `DecisionTreeClassifier`；
- 对"属性取值数差异很大"的数据，C4.5 的增益率更稳健；
- 无论用什么准则，**剪枝和集成**对最终效果的影响远大于准则选择。

## 五、代码实践

```python
import numpy as np

def gini(y):
    """基尼指数: 1 - sum(p_k^2)"""
    if len(y) == 0:
        return 0.0
    _, counts = np.unique(y, return_counts=True)
    p = counts / len(y)
    return float(1.0 - (p ** 2).sum())

def gini_index(X, y, feature_idx, thresholds=None):
    """离散属性的基尼指数; 连续属性传 thresholds 做二分"""
    total = len(y)
    if thresholds is None:
        idx = 0.0
        for v in np.unique(X[:, feature_idx]):
            mask = X[:, feature_idx] == v
            idx += (mask.sum() / total) * gini(y[mask])
        return idx
    left = X[:, feature_idx] <= thresholds
    return ((left.sum() / total) * gini(y[left])
            + ((~left).sum() / total) * gini(y[~left]))
```

## 六、常见坑

| 坑 | 说明 |
| --- | --- |
| 认为增益率完全解决了 ID3 的缺陷 | 它只是"缓解"，且引入了新偏好；C4.5 用两步法折中 |
| 连续属性用多路划分 | ID3/C4.5 风格；CART 用二分（**更稳**） |
| 连续属性的候选点未排序去重 | 会产生重复划分点，浪费时间 |
| 基尼指数越大越好 | **越小越好**（是"不纯度"） |
| 回归树用基尼指数 | 回归要用平方误差（基尼只适用于分类） |
| 忘记 CART 允许特征重复使用 | 限制了树表达能力 |
| 认为熵和基尼会给出不同的树 | 绝大多数情况下结果一致或非常接近 |

**基础**

3. 说明为什么基尼指数不需要对数运算。

**进阶**

4. 证明 $\text{Gini}(D) = 1-\sum_k p_k^2$ 与"随机抽两个样本类别不同"的概率相等。
5. 对连续属性取值 $\{1, 2, 5, 7, 9\}$，写出所有候选划分点。
6. 证明二分类时，熵与基尼指数在 $p\in[0,1]$ 上给出**相同的划分偏好**（即"选熵最小的属性"与"选基尼最小的属性"等价）。

**思考题**

7. CART 允许同一属性在同一路径上重复使用，ID3/C4.5 不允许（用过就删）。这两种设计各有什么利弊？
8. 为什么说"回归树是阶梯函数"？它对非线性函数（如 $y=\sin x$）的拟合需要多少层才能达到一定精度？与多项式回归相比有什么优劣？

<details>
<summary>第 6 题答案要点</summary>

二分类时，设正例比例 $p\in[0,1]$：

$$H(p) = -p\log p-(1-p)\log(1-p)$$

$$\text{Gini}(p) = 1-p^2-(1-p)^2 = 2p(1-p)$$

两者都是关于 $p=0.5$ 对称、在 $[0,0.5]$ 上单调递增、在 $[0.5,1]$ 上单调递减的凹函数。

**关键**：对任意两个划分，比较的是加权平均后的值。由于两者都是 $p(1-p)$ 类形状的单调变换（在 $[0,0.5]$ 与 $[0.5,1]$ 上分别单调），加权平均的大小关系保持一致 ⇒ **选择结果一致**。

（严格证明需要用到"两者是同一族函数的单调变换"，可用数值验证。）
</details>

## 八、一句话总结

**三种准则解决的是同一个问题——"怎么度量划分后的纯度"，只是用不同的函数（对数 vs 平方）。CART 的基尼指数靠"不用 log"胜出，而 CART 的二叉树结构让它同时支持分类与回归。**
