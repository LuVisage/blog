> 西瓜书第 4 章（决策树）、第 8 章（集成学习）· 南瓜书第 4、8 章

决策树是**唯一能自动做特征选择**的经典模型；集成学习是**表格数据上的王者**（XGBoost / LightGBM 至今统治 Kaggle 表格赛）。这两章合起来，是"从单个模型走向模型组合"的关键一步。

---

## 本周目标

学完本周，你应该能够：

1. 推导信息熵与信息增益，从零实现 ID3 决策树；
2. 掌握 C4.5 的增益率与 CART 的基尼指数，说清三者的取舍；
3. 掌握预剪枝 / 后剪枝的流程与代价，理解为什么剪枝能防过拟合；
4. 掌握连续值二分与缺失值加权的处理技巧；
5. 从零实现 Bagging 与随机森林，并用 OOB 估计泛化误差；
6. 从零实现 AdaBoost 与 GBDT，理解"降方差"与"降偏差"的根本区别。

## 一条主线

```
                决策树（高方差、低偏置）
                       │
        ┌──────────────┴──────────────┐
        │                             │
    并行组合                      串行组合
    (Bagging)                    (Boosting)
        │                             │
   随机森林 → 降方差            AdaBoost / GBDT → 降偏差
                                      │
                                 XGBoost / LightGBM
```
