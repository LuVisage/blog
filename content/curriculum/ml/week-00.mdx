## 写在最前面：给 0 基础的你三句话

**① 不会写代码 ≠ 学不会。**
写代码和学开车一样：不是靠"懂原理"，是靠"练到肌肉记住"。本教程每天 2~3 小时，其中至少 1 小时必须是**亲手敲代码**——看会了和会了是两回事。

**② 报错不是失败，是正常流程。**
职业程序员每天也在制造报错。本教程会专门教你怎么读报错（Day1 就开始）。
**报错信息的前两行就是答案**，从头读到尾，比任何猜测都有用。

**③ 卡住超过 30 分钟就做这三件事**：
1. 把报错信息完整复制下来，从第一行读起；
2. 把"最小可复现"的代码单独拿出来跑（只留出错的几行）；
3. 还不行，带着报错去搜索——**搜报错原文**，不要搜"我的问题"。

## 环境准备（Day1 会手把手带你做）

### 1. 安装 Python

去 [python.org/downloads](https://www.python.org/downloads/) 下载 **3.11 或更新**版本。

**Windows 安装时唯一要注意的**：第一屏勾选 **"Add Python to PATH"**（不加的话命令行找不到 python 命令——这是 0 基础最常见的第一个坑）。

### 2. 安装编辑器

推荐 **VS Code**（免费）+ Python 扩展。装好后：
- `文件 → 打开文件夹`，选一个你放代码的空文件夹；
- 新建 `test.py`，输入 `print("hello")`，按 `▶` 运行。

### 3. 验证安装（打开"终端"/命令行）

**Windows**：按 `Win + R`，输入 `cmd` 回车（或在 VS Code 里 `终端 → 新建终端`）。

```bash
python --version        # 应显示 Python 3.11.x 或更新
pip --version           # 应显示 pip 24.x 或更新
```

**macOS / Linux** 用 `python3 --version`（注意带 3）。

> **如果 `python --version` 报"不是内部或外部命令"**：回到第 1 步，勾选 Add to PATH 重装；
> 或者临时用 `py --version`（Windows 的启动器）。

### 4. 安装本教程的依赖（Week00 只需要两个）

```bash
pip install numpy matplotlib
```

国内网络慢的话，先执行一次：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

## 学习方法（本教程的通用约定，全周适用）

| 约定 | 说明 |
| --- | --- |
| **代码必须亲手敲** | 不要复制粘贴。敲错→读报错→改对，这个过程就是学习本身 |
| **先猜再跑** | 每段代码运行前，先在纸上写下"我猜输出是___"，再对照 |
| **改坏它** | 跑通之后，故意改出一个错（比如去掉冒号），看报错长什么样 |
| **每天收尾自测** | 每个脚本结尾都有【自测区】，是断言式的小测验，全过才算今天完成 |

**每天的时间分配建议**（共约 2.5 小时）：

```
读文档 40 分钟 → 亲手敲代码 60 分钟 → 改坏再修好 20 分钟 → 自测区 30 分钟
```

## 常见问题（0 基础 Top 5）

**Q1：`python` 不是内部或外部命令？**
→ 没加 PATH。Windows 重装勾选 "Add Python to PATH"，或临时用 `py` 命令。

**Q2：`pip install` 很慢或超时？**
→ 用国内镜像：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`

**Q3：`ModuleNotFoundError: No module named 'numpy'`？**
→ 你装了包，但运行时用的不是那个 Python。0 基础阶段先别用虚拟环境，直接全局装；
 Week01 再学 venv（Day1 会埋伏笔）。

**Q4：中文输出乱码？**
→ Windows 命令行先执行 `chcp 65001`；或在 VS Code 终端里运行（默认 UTF-8）。

**Q5：SyntaxError: invalid syntax 指着一行看不出来？**
→ 错误往往在**上一行**（比如少了冒号、括号没闭合）。往上看一行。
