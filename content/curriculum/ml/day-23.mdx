## 一、为什么必须剪枝

### 1.1 完全生长的树 = 记住训练集

假设每个叶子只含一个样本，则：

- 训练误差 = 0（完美）；
- 测试误差：对新样本只能靠"最近的那个训练样本"判断，泛化极差。

从偏差-方差视角：

| 树深度 | 偏置 | 方差 |
| --- | --- | --- |
| 浅 | 高 | 低 |
| 深（完全生长） | **低** | **极高** |

### 1.2 剪枝的两种时机

```
ID3/C4.5 风格:  建树过程 → 预剪枝（边建边判断）
CART 风格:      建完整树 → 后剪枝（建完再砍）
```

| 类型 | 时机 | 优点 | 缺点 |
| --- | --- | --- | --- |
| **预剪枝** | 划分前判断 | 训练快、树小 | **贪心导致视界受限**（欠拟合风险） |
| **后剪枝** | 建完树后自底向上 | 保留更多分支、效果通常更好 | 训练慢（要先建完整树） |

## 二、预剪枝（Pre-pruning）

### 2.1 流程

对每个结点，在决定是否划分之前：

```
1. 用当前结点（不划分）在验证集上的精度记为 acc_no
2. 试划分，得到划分后在验证集上的精度 acc_yes
3. 若 acc_yes > acc_no → 允许划分
   否则 → 把该结点设为叶结点，停止生长
```

### 2.2 常见停止条件

| 条件 | 说明 |
| --- | --- |
| 结点样本数 &lt; 阈值 | `min_samples_split` |
| 叶结点样本数 &lt; 阈值 | `min_samples_leaf` |
| 树的深度 ≥ 阈值 | `max_depth` |
| 信息增益/基尼下降 &lt; 阈值 | `min_impurity_decrease` |
| 验证集精度不再提升 | 上面流程 |

### 2.3 视界受限（Myopia）

**问题**：预剪枝是**贪心**的。某次划分当前看起来不划算，但后续可能带来大幅提升——预剪枝会**提前否决**这个分支，导致欠拟合。

```
        当前划分效果略差
       ┌────────┴────────┐
    否决                 允许
     ↓                    ↓
 树很短            后续划分带来巨大提升
（欠拟合）          （这才是最优解）
```

**经典例子**：某个划分单独看让验证精度下降 1%，但它的子划分能让精度提升 10%。预剪枝会否决它，而后剪枝会保留它。

## 三、后剪枝（Post-pruning）

### 3.1 流程

```
1. 建一棵完整的树
2. 自底向上遍历每个内部结点
3. 对每个结点，尝试把它【变成叶子】（剪掉其子树）
4. 若验证集精度不下降（或不下降超过阈值）→ 执行剪枝
5. 直到没有可剪的结点
```

**替换成叶子时的取值**：该结点包含的样本的**多数类**（分类）或**均值**（回归）。

### 3.2 为什么后剪枝通常更好

| 对比 | 预剪枝 | 后剪枝 |
| --- | --- | --- |
| 考察的分支数 | 少（提前剪掉） | **多**（完整树） |
| 过拟合/欠拟合 | 容易欠拟合 | 平衡更好 |
| 训练时间 | 短 | 长（$O(n)$ 次验证） |
| 空间 | 小 | 临时需要整棵树 |

**代价**：后剪枝每剪一个结点就要跑一次验证，最坏情况 $O(n\log n)$ 次验证。

### 3.3 代价复杂度剪枝（CCP）

CART 使用的标准剪枝方法（`sklearn` 的 `ccp_alpha`）。

**定义子树 $T_t$ 的代价复杂度**：

$$R_\alpha(T_t) = R(T_t) + \alpha |\tilde T_t|$$

其中：

- $R(T_t)$：子树在训练集上的误差（分类用错误率，回归用 MSE）；
- $|\tilde T_t|$：子树的叶子数（复杂度）；
- $\alpha \ge 0$：**复杂度惩罚系数**。

**核心思想**：剪枝会**增加训练误差**（第一项变大），但**减少叶子数**（第二项变小）。当降低的复杂度收益大于误差增加时，就剪。

**CCP 算法**：

```
1. 对每个内部结点 t，计算"剪掉它的代价增益":
       alpha_t = (R(t) - R(T_t)) / (|T_t|_leaves - 1)
   alpha_t 越小，表示剪掉它越"划算"
2. 剪掉 alpha 最小的子树，得到一个子树序列 T_0 ⊃ T_1 ⊃ ... ⊃ T_root
3. 用【交叉验证】在序列中选最优的 alpha
```

| $\alpha$ | 效果 |
| --- | --- |
| $\alpha = 0$ | 不剪枝（完全树） |
| $\alpha$ 增大 | 剪得更狠，树更小 |
| $\alpha \to \infty$ | 只剩根结点（单结点树） |

### 3.4 其他后剪枝方法

| 方法 | 用于 | 特点 |
| --- | --- | --- |
| **CCP**（代价复杂度） | CART | 最常用，sklearn 内置 |
| **REP**（错误率降低剪枝） | 通用 | 需要验证集，简单易行 |
| **PEP**（悲观错误剪枝） | C4.5 | 不需额外验证集，用训练集 + 连续性校正 |
| **MEP**（最小错误剪枝） | 通用 | 用二项分布估计误差 |

## 四、连续属性的处理

### 4.1 二分法（CART 风格）

```
1. 把该属性在 D 上的 n 个取值排序: a^1 ≤ a^2 ≤ ... ≤ a^n
2. 候选划分点: T_a = { (a^i + a^{i+1})/2 | i = 1..n-1 }
3. 对每个划分点 t 计算划分后的准则值
4. 取最优 (a, t)
```

**实例**：属性"密度"取值为 $\{0.243, 0.245, 0.343, 0.360, 0.403\}$

候选划分点：$\{0.244, 0.294, 0.3515, 0.3815\}$（相邻中点）

### 4.2 多路划分（C4.5 风格）

C4.5 可以对连续属性做多路划分（每个取值一路），但会**严重加剧 ID3 的取值多偏好**，因此实践中不推荐。

### 4.3 计算优化

对 $n$ 个样本、$d$ 个连续属性，每个结点要计算 $d(n-1)$ 次准则值。优化方法：

1. **预排序**：在建树前对每个属性排序一次，之后按顺序扫描；
2. **跳过无变化点**：若相邻划分点两侧的类别分布相同，可跳过；
3. **近似分裂**（LightGBM）：把连续值分桶成直方图，只考虑桶边界。这是 LightGBM 比 XGBoost（精确分裂）快得多的原因之一。

## 五、缺失值的处理

### 5.1 问题

现实数据常缺失。三种思路：

| 思路 | 做法 | 缺点 |
| --- | --- | --- |
| 删除有缺失的样本 | 简单 | 浪费数据，可能引入偏差 |
| 填充（均值/中位数/众数/模型） | 通用 | 引入虚假信息 |
| **在树中直接处理** | C4.5 的加权划分 | 树专用，其他模型不通用 |

### 5.2 C4.5 的加权划分（核心技巧）

**记号**：

- $\tilde D$：$D$ 中在属性 $a$ 上**无缺失**的样本子集；
- $\rho = \frac{|\tilde D|}{|D|}$：无缺失样本比例；
- $\tilde p_k$：$\tilde D$ 中第 $k$ 类的比例；
- $\tilde r_v$：$\tilde D$ 中属性 $a$ 取值为 $v$ 的比例。

**（1）修正的信息增益**

$$\widetilde{Gain}(D, a) = \rho \times \left[H(\tilde D) - \sum_{v=1}^{V}\tilde r_v H(\tilde D^v)\right]$$

**含义**：只有 $\rho$ 比例的样本提供信息，所以增益要乘以 $\rho$。

**（2）样本的归属：按权重分配到所有子结点**

一个有缺失的样本 $\boldsymbol{x}$，会被**同时分配到所有子结点**，但携带权重：

$$w_{\boldsymbol{x}, v} = \rho_v \cdot \frac{|D^v|}{|\tilde D|}$$

**（3）预测时的处理**

若测试样本在某个结点划分属性上缺失，则**让它同时进入所有分支**，最终把各叶子输出的类别分布按分支样本比例加权求和。

### 5.3 现代做法

现代 GBDT 库（XGBoost/LightGBM）的做法更简单高效：**为缺失值分配一个默认方向**。

```
分裂时尝试: 缺失样本走左子结点 vs 走右子结点
选使损失更小的那个方向作为默认方向
```

**优点**：无需填充、训练和预测一致、速度快。

## 六、代码实践

```python
def prune_post(tree, X_val, y_val):
    """
    后剪枝（错误率降低剪枝 REP）的伪代码骨架:
    自底向上，尝试把每个内部结点变成叶子
    """
    for node in reversed(bottom_up_order(tree)):
        if node.is_leaf:
            continue
        acc_before = accuracy(tree, X_val, y_val)
        saved = (node.left, node.right, node.feature, node.threshold)
        # 试剪: 把该结点变成叶子
        node.make_leaf(majority(node.y_train))
        acc_after = accuracy(tree, X_val, y_val)
        if acc_after < acc_before:            # 变差了 -> 恢复
            node.restore(*saved)
    return tree
```

## 七、常见坑

| 坑 | 说明 |
| --- | --- |
| 用训练集做剪枝判断 | 必然不剪（训练误差总是划分后更低）；**必须用验证集** |
| 预剪枝参数设得太严 | 严重欠拟合；优先用后剪枝 |
| 认为剪枝一定提升精度 | 数据极少或噪声极低时可能无效 |
| 连续属性候选点不排序 | 划分点错误 |
| 缺失值填充时用了全量数据统计 | 数据泄漏；应在训练集上算填充值 |
| 树很深却不剪枝 | 训练快但预测慢、内存大、泛化差 |
| 用 Gini 对回归树剪枝 | 回归应用 MSE |

<details>
<summary>第 6 题答案</summary>

**不划分时**（根结点为叶）：验证集多数类是"负"（30 > 20），准确率 $= 30/50 = 0.60$。

**划分后**：

- 左子结点验证集 15 正 15 负 → 平票（取多数类，假设取负）→ 准确率 $15/30 = 0.50$
- 右子结点验证集 5 正 15 负 → 取负 → 准确率 $15/20 = 0.75$

划分后总准确率：

$$\frac{15 + 15}{50} = 0.60$$

**结论**：划分后准确率（0.60）与不划分（0.60）**相同**。

若判定规则是"严格提升才划分"，则**预剪枝会否决这次划分**；若是"不下降即划分"，则会保留。

**注意**：这里正好展示了预剪枝的"视界受限"——右子结点已经相当纯（75%），如果再往下分可能大幅提升，但这次划分被否决后就再无机会。

<details>
<summary>第 7 题答案要点</summary>

- **预剪枝**：在自顶向下建树时，只要某次划分不划算就**永久否决**该分支及其所有后代。
- **后剪枝**：先建完整树（包含所有可能的分支），再自底向上考虑是否剪掉。

因为后剪枝的每一次决策都基于**完整的子树信息**，而预剪枝的决策基于**不完整的信息**（不知道后代会怎样）。所以后剪枝等价于"在完整树上做局部最优搜索"，而预剪枝是"在部分树上做贪心搜索"。

严格地说，两者考察的候选子树集合不同：后剪枝的候选集合包含"保留部分后代"的子树，预剪枝一旦否决就整个分支消失，**其可达的子树集合是后剪枝候选集的子集**，因此后剪枝能保留更多的分支结构。
</details>

## 九、一句话总结

**树的生长是"追求训练误差最小"，剪枝是"用验证误差来约束复杂度"。预剪枝快但短视，后剪枝慢但更准——工程上首选后剪枝 + 交叉验证选 $\alpha$。**
