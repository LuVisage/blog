## 1.2 从 RNN 的两个瓶颈说起

Week13 结尾留下了两个未解决的问题：

| 瓶颈 | 具体表现 |
| --- | --- |
| **信息瓶颈** | 全部历史必须压进固定大小的 $\boldsymbol{h}$（如 128 维） |
| **串行计算** | 第 $t$ 步必须等第 $t-1$ 步算完，无法并行 |

**注意力的想法很直接**：既然压缩会丢信息，那就不压缩 —— **让每个位置直接去看所有位置**。

```
RNN:         x1 → h1 → h2 → h3 → h4      信息要"传"过去
Attention:   x1 ←→ x2 ←→ x3 ←→ x4        任意两个直接相连
```

**代价**：计算量从 $\mathcal{O}(T)$ 变成 $\mathcal{O}(T^2)$。但换来的是完全并行 + 距离无关。

## 1.3 注意力的直觉：软性检索

想象你在图书馆找书：

1. **查询（Query）**：你想找"关于 Transformer 的书"；
2. **键（Key）**：每本书的标签/标题；
3. **值（Value）**：每本书的内容。

**流程**：

- 用你的查询和**每一本**书的标签比对，得到相似度分数；
- 分数越高说明这本书越相关；
- 按分数加权，把所有书的内容**混合**起来给你。

**关键点**：不是"只取最相关的一本"（硬检索），而是**按相关度加权混合全部**（软检索）。这就是"注意力权重"。

## 1.4 查询-键-值（QKV）框架

在自注意力里，$\mathbf{Q}$、$\mathbf{K}$、$\mathbf{V}$ **都来自同一份输入**（"自"注意力）：

$$\mathbf{Q} = \mathbf{X}\mathbf{W}^Q, \qquad \mathbf{K} = \mathbf{X}\mathbf{W}^K, \qquad \mathbf{V} = \mathbf{X}\mathbf{W}^V$$

其中 $\mathbf{X}\in\mathbb{R}^{T\times d_{model}}$ 是输入序列，$\mathbf{W}^Q,\mathbf{W}^K,\mathbf{W}^V\in\mathbb{R}^{d_{model}\times d_k}$ 是**可学习的投影矩阵**。

**为什么要三个不同的投影？**

如果直接用 $\mathbf{X}$ 自己和自己做点积，那么"我该关注谁"和"我有什么内容"就被绑死在同一个表示上。三个独立投影让模型可以分别学习：

- "**该用什么特征去查询**"（$\mathbf{W}^Q$）
- "**该用什么特征被别人匹配**"（$\mathbf{W}^K$）
- "**我实际贡献什么信息**"（$\mathbf{W}^V$）

**维度**：

| 张量 | 形状 | 说明 |
| --- | --- | --- |
| $\mathbf{Q}$ | $(T, d_k)$ | 每个位置一个查询 |
| $\mathbf{K}$ | $(T, d_k)$ | 每个位置一个键 |
| $\mathbf{V}$ | $(T, d_v)$ | 每个位置一个值 |
| 注意力权重 | $(T, T)$ | **第 $i$ 行是第 $i$ 个位置对所有位置的关注度** |
| 输出 | $(T, d_v)$ | 每个位置一个加权后的新表示 |

## 1.5 缩放点积注意力

$$\boxed{\text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}}$$

**四步拆解**：

| 步骤 | 计算 | 形状 | 含义 |
| --- | --- | --- | --- |
| ① 打分 | $\mathbf{S} = \mathbf{Q}\mathbf{K}^\top$ | $(T,T)$ | 每对位置的相似度 |
| ② 缩放 | $\mathbf{S}/\sqrt{d_k}$ | $(T,T)$ | 控制数值范围 |
| ③ 归一化 | $\mathbf{A} = \text{softmax}(\mathbf{S}, \text{dim}=-1)$ | $(T,T)$ | 每行和为 1 的权重 |
| ④ 加权求和 | $\text{out} = \mathbf{A}\mathbf{V}$ | $(T,d_v)$ | 按权重混合所有位置的值 |

**为什么用 softmax 而不是别的归一化**：softmax 是"软 max"—— 放大差距但保持可导。它让模型能"几乎只看一个位置"（分布尖锐）或"平均看所有位置"（分布平坦），由数据决定。

---

## 1.6 为什么必须除以 $\sqrt{d_k}$

**这是面试高频题，并且有一个漂亮的数学证明。**

### 1.6.1 方差分析

假设 $q_i$ 和 $k_i$ 是独立的随机变量，均值 0、方差 1（这是初始化良好的网络里激活值的典型状态）。点积：

$$q\cdot k = \sum_{i=1}^{d_k} q_ik_i$$

**逐项求方差**：

$$\text{Var}(q_ik_i) = \mathbb{E}[q_i^2k_i^2] - (\mathbb{E}[q_ik_i])^2 = \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] - 0 = 1\cdot 1 = 1$$

**独立同分布求和**：

$$\text{Var}(q\cdot k) = \sum_{i=1}^{d_k}\text{Var}(q_ik_i) = d_k$$

**结论**：点积的方差是 $d_k$，标准差是 $\sqrt{d_k}$。

### 1.6.2 后果：softmax 饱和

当 $d_k = 512$ 时，点积的标准差约 22.6。也就是说，不同位置的分数可能相差几十。

**过大的输入会让 softmax 进入饱和区**：

- 分布变得极端尖锐（几乎 one-hot）；
- softmax 的梯度趋近于 **0**；
- **梯度消失，训练停滞**。

### 1.6.3 除以 $\sqrt{d_k}$ 的作用

$$\text{Var}\left(\frac{q\cdot k}{\sqrt{d_k}}\right) = \frac{d_k}{d_k} = 1$$

**方差被拉回 1**，softmax 一直在"敏感区"里工作，梯度稳定。

> **一句话**：$\sqrt{d_k}$ 是一个"温度归一化"，让注意力分布的尖锐程度不随维度增长而失控。

**实验验证**（案例代码）：对比有无缩放时，softmax 输出的**最大梯度**与**分布的熵**：

| $d_k$ | 不缩放的标准差 | 缩放后 | 不缩放的梯度 | 缩放后 |
| --- | --- | --- | --- | --- |
| 8 | 2.8 | 1.0 | 明显更小 | 正常 |
| 64 | 8.0 | 1.0 | 接近 0 | 正常 |
| 512 | 22.6 | 1.0 | **几乎为 0** | 正常 |

## 1.7 自注意力的代价：$O(T^2)$

**计算量**：

| 步骤 | FLOPs |
| --- | --- |
| $\mathbf{Q}\mathbf{K}^\top$ | $T^2 d_k$ |
| $\mathbf{A}\mathbf{V}$ | $T^2 d_v$ |

**复杂度是 $O(T^2 d)$** —— 序列长度平方级增长。

| 序列长度 $T$ | 注意力矩阵大小 | 相对 $T=512$ |
| --- | --- | --- |
| 512 | 262,144 | 1× |
| 2,048 | 4,194,304 | 16× |
| 32,768 | 1,073,741,824 | **4096×** |

**这就是"长上下文"难做的根本原因**。后来的一系列改进都在解决它：

| 方法 | 思路 |
| --- | --- |
| 稀疏注意力 | 只算部分位置对 |
| 线性注意力 | 用核函数近似，降到 $O(T)$ |
| FlashAttention | 算法层面优化显存访问（不改变复杂度但快很多） |
| 滑动窗口 | 只看附近 $w$ 个位置 |

> **但对 Week14 的学习来说，标准注意力就够了。** 理解 $O(T^2)$ 的代价比记住各种变体更重要。

## 1.8 置换等变性：位置编码的动机

**自注意力的一个关键性质**：如果你把输入序列的顺序**打乱**，输出的内容也会被同样地打乱，但**每个位置的新表示完全不变**。

用数学说：设 $\mathbf{P}$ 是任意置换矩阵，则

$$\text{Attention}(\mathbf{P}\mathbf{X}) = \mathbf{P}\cdot\text{Attention}(\mathbf{X})$$

**验证**：

$$\mathbf{Q}'\mathbf{K}'^\top = (\mathbf{P}\mathbf{X}\mathbf{W}^Q)(\mathbf{P}\mathbf{X}\mathbf{W}^K)^\top = \mathbf{P}\mathbf{X}\mathbf{W}^Q\mathbf{W}^{K\top}\mathbf{X}^\top\mathbf{P}^\top$$

因为 $\mathbf{P}\mathbf{P}^\top = \mathbf{I}$ 会被 softmax 的行归一化"吃掉"，最终输出就是 $\mathbf{P}$ 作用在原始输出上。

**这意味着什么**：

- 自注意力**完全不知道顺序** —— "我爱你"和"你爱我"对它是同一件事；
- 所以**必须显式加入位置信息**（位置编码，Day2 详述）。

**对比 RNN**：RNN 天然有序（因为递归结构），但也因此无法并行。**Transformer 用"放弃顺序 + 显式编码位置"换来了并行性。**

## 1.9 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| softmax 后全是 one-hot | 忘了除以 $\sqrt{d_k}$ | 补上缩放 |
| 梯度为 0 训不动 | softmax 饱和 | 检查缩放、降低初始化幅度 |
| 维度对不上 | 混淆了 $d_k$ 与 $d_{model}$ | 画清楚形状 |
| 掩码写错 | 遮住的位置没设成 $-\infty$ | 用 `masked_fill(mask, -inf)` |
| 输出顺序变了 | 以为注意力保序 | 记住它是置换等变的 |
| 显存爆了 | $T$ 太大，注意力矩阵 $O(T^2)$ | 减小 batch 或序列长度 |

## 1.11 一句话总结

**自注意力就是"用点积算相似度、用 softmax 归一化、用权重混合所有位置"；$\sqrt{d_k}$ 是防止 softmax 饱和的温度系数，而置换等变性则是位置编码存在的唯一理由。**
