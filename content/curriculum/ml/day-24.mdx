## 一、集成学习的基本框架

### 1.1 为什么"三个臭皮匠"能胜过诸葛亮

**前提条件**（缺一不可）：

1. **个体学习器要有一定的准确性**（准确率明显高于随机猜测）；
2. **个体学习器之间要有差异性**（犯的错不重合）。

**反例**：三个完全相同的模型投票，结果和单个模型完全一样。

### 1.2 两类集成范式

| 范式 | 代表 | 训练方式 | 主要作用 |
| --- | --- | --- | --- |
| **并行**（Bagging） | 随机森林 | 各学习器独立训练 | **降低方差** |
| **串行**（Boosting） | AdaBoost、GBDT | 后一个修正前一个 | **降低偏差** |
| 堆叠（Stacking） | 元学习器 | 用另一个模型组合 | 兼有 |

> **核心口诀**：
> **Bagging 降方差，Boosting 降偏差。**

### 1.3 数学回顾：方差为什么能降

设 $M$ 个模型，方差均为 $\sigma^2$，两两相关系数为 $\rho$，平均模型的方差为：

$$\operatorname{Var}\left(\frac{1}{M}\sum_{i=1}^M \hat f_i\right) = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$$

**两条结论**：

1. 增加 $M$（模型数量）能降低第二项，但第一项 $\rho\sigma^2$ 会"卡住"下限；
2. **降低相关性 $\rho$ 比增加模型数量更重要**。

**这正是随机森林"随机选特征"的动机**——让树之间更不相似（$\rho$ 更小）。

## 二、Bagging（Bootstrap Aggregating）

### 2.1 流程

```
输入: 数据集 D (m 个样本), 基学习器 h, 轮数 T

for t = 1 to T:
    D_t = 从 D 中【有放回】采样 m 次          # 自助采样
    h_t = 在 D_t 上训练 h
输出: H(x) = 多数投票 {h_1(x), ..., h_T(x)}   # 分类
       或 H(x) = (1/T) Σ h_t(x)             # 回归
```

**自助采样（Bootstrap）复习**：有放回抽 $m$ 次，约 **63.2%** 的样本被抽到至少一次，剩余 **36.8%** 从未被抽到：

$$p_{\text{未被抽到}} = \left(1-\frac{1}{m}\right)^m \xrightarrow{m\to\infty} \frac{1}{e}$$

### 2.2 为什么 Bagging 有效

| 视角 | 解释 |
| --- | --- |
| 方差 | 各模型的训练集不同 ⇒ 相关性 $\rho$ 降低 ⇒ 平均后方差降低 |
| 偏差 | 每个模型的偏差与单个模型相同 ⇒ **偏差几乎不变** |
| 稳定性 | 对噪声和离群点更鲁棒（少数样本被"平均掉"） |

**关键**：Bagging **不降低偏差**。所以基学习器必须是**强学习器（低偏差）**，例如**完全生长的决策树**。

### 2.3 基学习器的选择

| 基学习器 | Bagging 效果 |
| --- | --- |
| 决策树（完全生长） | 极好（高方差型，正好被降方差） |
| 线性回归 | 差（本身稳定，方差已小） |
| kNN（k=1） | 一般（降方差但采样导致距离结构变化） |
| SVM | 一般（本身较稳定） |
| 神经网络 | 好（可用不同初始化 + 采样） |

> **经验规则**：**Bagging 适合"不稳定"的基学习器**（对训练数据扰动敏感）。决策树是最典型的不稳定学习器。

## 三、随机森林（Random Forest）

### 3.1 两次随机化

**随机森林 = Bagging + 特征随机**。

| 随机化 | 做法 | 目的 |
| --- | --- | --- |
| 第 1 次 | 自助采样得到不同训练集 | 让每棵树看到不同的数据 |
| 第 2 次 | 每个结点分裂时，**只从 $k$ 个随机特征中选最优** | **降低树之间的相关性 $\rho$** |

**$k$ 的典型取值**（经验值）：

| 任务 | $k$ |
| --- | --- |
| 分类 | $\sqrt{d}$（$d$ 为特征数） |
| 回归 | $d/3$ |
| 极端随机化（Extra-Trees） | 再随机选划分点 |

> **为什么特征随机能降 $\rho$**：若数据中有几个非常强的特征，普通 Bagging 中每棵树都会优先用它们，导致所有树结构高度相似（$\rho$ 大）。特征随机强制每棵树"换着看特征"，从而增强多样性。

### 3.2 随机森林 vs Bagging

| 对比 | Bagging | 随机森林 |
| --- | --- | --- |
| 样本随机 | | |
| 特征随机 | | |
| 树间相关性 | 较高 | **较低** |
| 单棵树的强度 | 较强 | 稍弱（可选特征少） |
| 总体效果 | 好 | **通常更好** |
| 训练速度 | 慢（要遍历全部特征） | **快**（只遍历 $k$ 个特征） |

**随机森林"用更弱的树换更低的 $\rho$"，最终总体更优。**

### 3.3 包外估计（OOB）

**定义**：对每个样本 $\boldsymbol{x}_i$，找出**没有用到 $\boldsymbol{x}_i$ 训练**的那些树，用它们对 $\boldsymbol{x}_i$ 预测，得到包外预测 $\hat y_i^{\text{OOB}}$。

$$\text{OOB 误差} = \frac{1}{m}\sum_{i=1}^{m}\mathbb{1}\left[\hat y_i^{\text{OOB}} \ne y_i\right]$$

**为什么它几乎"免费"**：

- 每棵树只用了约 63.2% 的样本，剩余 36.8% 天然构成该树的验证集；
- 当 $T$ 足够大时，每个样本约有 $0.368T$ 棵树未用到它 ⇒ 预测足够可靠。

**OOB 的三大用途**：

1. **评估泛化误差**（无需额外划分验证集）；
2. **选择超参数**（$T$、$k$、`max_depth`）；
3. **估计特征重要性**（用 OOB 精度下降量）。

> **注意**：OOB 只在 Bagging 类方法中可用（Boosting 的模型相互依赖，不存在"未用某样本训练"的模型）。

### 3.4 特征重要性

**方法一：不纯度下降（Impurity Decrease）**——sklearn 默认

对每个特征 $j$，累加它在所有树的所有结点上带来的不纯度下降（加权样本数）：

$$\text{Imp}_j = \frac{1}{T}\sum_{t=1}^{T}\sum_{\text{结点 } n \text{ 用特征 } j}\frac{N_n}{N}\left[\text{Imp}(n) - \frac{N_L}{N_n}\text{Imp}(L) - \frac{N_R}{N_n}\text{Imp}(R)\right]$$

**优点**：训练时免费获得。
**缺点**：**偏向取值多/连续的特征**（与信息增益同病）。

**方法二：OOB 置换重要性（Permutation Importance）**——更可靠

```
对每个特征 j:
    1. 用 OOB 样本评估基准误差 e0
    2. 随机打乱 OOB 样本中特征 j 的取值
    3. 重新评估误差 e1
    4. 重要性 = e1 - e0
```

**优点**：无偏、可直接用到测试集、适用任何模型。
**缺点**：计算量大；相关特征会被"分摊"重要性。

## 四、随机森林的优缺点

### 优点

| 优点 | 说明 |
| --- | --- |
| 精度高、稳健 | 表格数据上的强基线 |
| 不易过拟合 | 树多了不会变差（只是收益递减） |
| 无需精细调参 | 默认参数通常就不错 |
| 天然处理混合类型特征 | 数值 + 类别都不用特殊处理 |
| 有 OOB 估计 | 免费验证 |
| 可并行 | 各树独立训练 |
| 给出特征重要性 | 可解释性尚可 |

### 缺点

| 缺点 | 说明 |
| --- | --- |
| 对高维稀疏数据（文本）效果差 | 不如线性模型 |
| 外推能力差 | 回归树输出是训练集的均值，**不能预测训练范围外的值** |
| 模型大、推理慢 | 树多时内存与延迟高 |
| 概率输出不平滑 | 受叶子纯度限制，需校准 |
| 可解释性不如单棵树 | 无法直接读出规则 |

> **外推问题详解**：回归森林的预测是若干叶子均值的平均，而叶子均值必然落在训练标签的范围内。因此**随机森林永远无法预测超出训练集 $y$ 范围的值**。这对时间序列预测是致命缺陷。

def bootstrap_sample(X, y, seed):
    rng = np.random.default_rng(seed)
    idx = rng.integers(0, len(X), len(X))        # 有放回
    return X[idx], y[idx], idx

def random_forest_fit(X, y, n_trees=100, max_features="sqrt",
                      max_depth=None, seed=0):
    rng = np.random.default_rng(seed)
    trees, oob_masks = [], []
    for t in range(n_trees):
        Xb, yb, idx = bootstrap_sample(X, y, int(rng.integers(1 << 30)))
        k = int(np.sqrt(X.shape[1])) if max_features == "sqrt" \
            else X.shape[1]
        feats = rng.choice(X.shape[1], k, replace=False)   # 只在这些特征上分裂

## 六、常见坑

| 坑 | 说明 |
| --- | --- |
| 用稳定的基学习器做 Bagging | 效果提升有限（如线性回归） |
| 认为"树越多越好" | 精度收敛后只是浪费计算；到一定数量后收益递减 |
| 忘记 `max_features` | 退化成普通 Bagging |
| 用训练误差评估随机森林 | 严重低估错误率（树能记住训练数据） |
| 用随机森林做外推预测 | 回归森林无法超出训练标签范围 |
| 直接比较连续特征与二值特征的重要性 | 不纯度重要性偏向取值多的特征 |
| 忽略 OOB 只在 Bagging 类可用 | Boosting 不能用 OOB |
| 认为随机森林完全不会过拟合 | 单棵树仍会过拟合；只是平均后缓解 |

## 七、练习题

**基础**

1. 自助采样 $m$ 次，某样本一次都没被抽到的概率是多少？$m=100$ 时约为多少？
2. 说明 Bagging 中"样本随机"与随机森林中"特征随机"各自的作用。
3. 100 棵树的随机森林，某个样本大约会被多少棵树"未看到"？

**进阶**

4. 证明 $\operatorname{Var}\left(\frac{1}{M}\sum \hat f_i\right) = \rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$。
5. 若 $\rho = 0.5$、$\sigma^2 = 1$，$M$ 从 10 增加到 1000，方差从多少变到多少？说明什么？
6. 写出基于**不纯度下降**的特征重要性计算式，并解释它为什么偏向取值多的特征。

**思考题**

7. 为什么 Bagging 主要降方差而不降偏差？请从"每个基学习器的期望"角度解释。
8. 随机森林无法外推。如果一定要用它做时间序列预测，有什么补救办法？（提示：不要直接预测原值，而是预测差分/收益率）
9. 试说明：为什么"如果所有特征都很重要且相互独立"，特征随机的收益就不大？

<details>
<summary>第 1 题答案</summary>

$$\left(1 - \frac{1}{m}\right)^m \xrightarrow{m\to\infty} e^{-1} \approx 0.368$$

$m=100$ 时：$(0.99)^{100} \approx 0.366$，约 **36.6%**。
</details>

<details>
<summary>第 5 题答案</summary>

$$\operatorname{Var} = 0.5 + \frac{0.5}{M}$$

- $M = 10$：$0.5 + 0.05 = 0.55$
- $M = 1000$：$0.5 + 0.0005 = 0.5005$

**说明**：方差迅速收敛到 $\rho\sigma^2 = 0.5$ 的**下界**。

**结论**：模型数量增加到一定程度后**几乎不再有收益**，此时唯一能继续降方差的办法是**降低相关性 $\rho$**。这就是随机森林特征随机的价值。
</details>

<details>
<summary>第 7 题答案</summary>

设第 $t$ 个基学习器的期望为 $\mathbb{E}[\hat f_t] = \bar f$（各模型同分布）。

**平均模型的期望**：

$$\mathbb{E}\left[\frac{1}{M}\sum_t \hat f_t\right] = \frac{1}{M}\sum_t \mathbb{E}[\hat f_t] = \bar f$$

**与单个模型的期望完全相同**。

而偏差定义为 $\text{Bias} = f - \bar f$，因此**偏差不变**。

只有方差项 $\mathbb{E}[(\hat f - \bar f)^2]$ 被平均化降低了 ⇒ **Bagging 只降方差**。

**推论**：若基学习器本身高偏置（如线性模型），Bagging 无法改善其系统性误差。
</details>

<details>
<summary>第 9 题提示</summary>

特征随机的目的是**降低树之间的相关性**。相关性来源于"所有树都优先选择相同的强特征"。

- 若所有特征都同等重要且相互独立，则每棵树随机选 $k$ 个特征后，选到的"强特征"分布仍近似独立 ⇒ **即使不随机化，树之间的相关性也不高**，随机化收益有限。
- 反之，若存在少数"超强特征"，不随机化时所有树都会用它们，$\rho$ 很大；随机化收益显著。

**实践含义**：当特征数很多且信息分散（如文本、高维稀疏）时，随机森林的优势不如在"少数强特征主导"的表格数据上明显。
</details>

## 八、一句话总结

**Bagging 用"自助采样 + 平均"降低方差；随机森林在此之上加一层"特征随机"，把相关系数 $\rho$ 压得更低。记住公式 $\rho\sigma^2 + \frac{1-\rho}{M}\sigma^2$，你就理解了随机森林的全部设计动机。**
