> 西瓜书第 1–2 章 · 南瓜书第 1–2 章

上一周我们把数学工具备齐了。这一周回答三个根本问题：**什么是"学习"？怎么判断模型好不好？为什么好模型也会变坏？**

---

## 本周目标

学完本周，你应该能够：

1. 用形式化语言描述一个机器学习问题：数据集、假设空间、学习算法、归纳偏好；
2. 说清"版本空间"与"归纳偏好"的关系，理解奥卡姆剃刀与 No Free Lunch 定理的含义；
3. 熟练使用留出法、k 折交叉验证、分层采样、留一法、自助法，并说清各自的适用场景；
4. 计算并解释混淆矩阵、精确率、召回率、$F_1$、ROC-AUC、PR 曲线；
5. 独立完成偏差-方差分解的推导，并用学习曲线诊断模型是过拟合还是欠拟合；
6. 从零实现 kNN 分类器，并用本周学到的评估方法给出可信的性能报告。

- [ ] 我能从零写出 kNN，并解释 $k$ 取 1 和取很大时分别会发生什么

## 一周一图

```
                     模型复杂度 →
  误差
   ↑
   |  \                    总误差
   |   \                  /      \
   |    \                /        \
   |     \  偏置^2     /            \
   |      \          /   方差         \
   |       \       /                   \
   |        \    /                       \
   +---------X----------------------------→
             最佳复杂度             （最优模型在两者交点附近）
```

这就是本周的核心：**一切模型选择的本质，都是在偏差与方差之间找平衡点。**
