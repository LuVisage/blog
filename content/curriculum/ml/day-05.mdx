## 5.2 直觉一：导数就是斜率

**问题**：`y = x²` 在 `x = 3` 这一点，"往上走一点，y 变化多快"？

**代码思路**：在 x=3 附近取两个非常近的点，算"纵向变化 ÷ 横向变化"：

```python
def f(x):
    return x ** 2

h = 0.0001
slope = (f(3 + h) - f(3)) / h
print(slope)        # 6.0001 ≈ 6
```

**对照数学**：`y = x²` 的导数是 `2x`，在 `x = 3` 处 = **6**。代码算出来的 6.0001 就是它。

**为什么这重要**：

| 概念 | 代码视角 |
| --- | --- |
| 导数 = 斜率 | "x 往右挪一点点，y 变化多少" |
| 导数为正 | y 在涨（应该**减小** x） |
| 导数为负 | y 在跌（应该**增大** x） |
| 导数为 0 | 平了——**极值点**（loss 的最低点就在这里附近） |

**梯度下降的雏形**（Week03 的主角，今天就能写出来）：

```python
x = 10.0                     # 从任意点出发
lr = 0.1                     # 步长（学习率！Week03 会正式讲）
for step in range(50):
    grad = 2 * x             # y = x² 的导数
    x = x - lr * grad        # ★ 往导数的【反方向】挪一小步
print(x)                     # → 0：滚到了最低点
```

**`x = x - lr * grad` 这一行，就是全部深度学习的训练原理**（Week07 反向传播 = 自动算 grad）。

## 5.3 直觉二：点积衡量"相似度"

```python
import numpy as np

a = np.array([1, 0, 1])
b = np.array([1, 0, 1])
c = np.array([0, 1, 0])

np.dot(a, b)      # 1*1 + 0*0 + 1*1 = 2   方向相同 -> 大
np.dot(a, c)      # 0                     完全垂直 -> 0（毫无共同点）
```

**点积的语义**：把两个向量"逐位相乘再求和"——**共同成分越多，值越大**。

**用真实场景验证**（Week15 的 embedding 检索就是它的放大版）：

```python
# 每个词用 [是否关于动物, 是否关于食物, 是否关于科技] 表示
dog    = np.array([1, 0, 0])
cat    = np.array([1, 0, 0])
banana = np.array([0, 1, 0])
chip   = np.array([0, 0, 1])

np.dot(dog, cat)      # 1   猫和狗很像
np.dot(dog, banana)   # 0   狗和香蕉没关系
```

**余弦相似度** = 点积 ÷（两个长度）——消除"向量长短"的影响，只看方向：

$$\cos(\theta) = \frac{a \cdot b}{\|a\| \, \|b\|}$$

```python
def cosine(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
```

| 余弦值 | 含义 |
| --- | --- |
| 1 | 方向完全相同（最相似） |
| 0 | 垂直（无关） |
| -1 | 方向相反 |

**Week15 的 RAG 文档检索 = 把文本变成几百维的向量，再算余弦相似度**。
今天你用 3 维理解了它，几百维只是同样的算术。

## 5.4 直觉三：矩阵乘法 = 批量变换

**先说它不是什么**：矩阵乘法**不是**"对应位置相乘"。

**规则**：`(2×3) 矩阵 × (3×2) 矩阵 = (2×2) 矩阵`——**中间的数字必须相等**，结果取两头。

```
        (2×3)   ×   (3×2)   →   (2×2)
      [1 2 3]      [7  8]
  A = [4 5 6]  B = [9 10]      C[0,0] = 1·7 + 2·9  + 3·11 = 58
                   [11 12]     C[0,1] = 1·8 + 2·10 + 3·12 = 64
                               C[1,0] = 4·7 + 5·9  + 6·11 = 139
                               ...
```

**用 NumPy 验证**：

```python
A = np.array([[1, 2, 3], [4, 5, 6]])
B = np.array([[7, 8], [9, 10], [11, 12]])
A @ B            # @ 就是矩阵乘法（注意：A * B 是对应位置相乘，别混）
```

**矩阵乘法的真正语义**（AI 的全部秘密）：

> **B 是一台"机器"：把输入向量变换成输出向量。A @ B 就是"把 A 的每一行都过一遍这台机器"。**

```python
# B 把 3 维压成 2 维（就像神经网络的一层）
input_vec  = np.array([1, 0, 0])
B @ input_vec      # [7, 8] —— 3 维输入 -> 2 维输出
```

**神经网络一层 = 一次矩阵乘法 + 一个激活函数**（Week07）：
`输出 = ReLU(输入 @ W + b)` —— W 就是学出来的"变换机器"。
现在你知道 `@` 在打什么工了。

## 5.5 直觉四：概率与条件概率（10 分钟版）

```python
# 一个班 40 人：30 男 10 女；男生里 12 人戴眼镜，女生里 4 人戴眼镜
P(男) = 30/40
P(眼镜|男) = 12/30        # 条件概率：已知是男生，戴眼镜的概率

# 联合 = 条件 × 先验
P(男 且 眼镜) = P(眼镜|男) × P(男) = 12/40

# 贝叶斯（Week05 朴素贝叶斯的心脏）：
# 已知某人戴眼镜，他是男生的概率？
P(男|眼镜) = P(眼镜|男)×P(男) / P(眼镜)
           = (12/30 × 30/40) / (16/40)
           = 12/16 = 0.75
```

**用代码验证**（Day5 脚本里真的会"发牌一万次"统计出来）：
**频率会收敛到概率**——这就是"训练=从数据里估计分布"的直觉。

## 5.6 自学方法论（比数学更重要的一节）

### 5.6.1 读报错的三层结构（复习 Day1，加入第三层）

```
Traceback (most recent call last):
  File "train.py", line 42, in <module>      ← 第三层：调用链（谁调的谁）
    model.forward(x)
  File "model.py", line 18, in forward       ← 第二层：出错的函数
    return x @ self.W                        ← 第一层：出错的那行
ValueError: shapes (4,3) and (2,2) not aligned   ← ★ 最重要：错误类型+描述
```

**长 Traceback 只看最后一行** + 第一层行号。
shape 错误（上面这个）会伴随你整个深度学习生涯——**它的修法永远是打印 shape**。

### 5.6.2 调试四板斧（按顺序使用）

| 板斧 | 做法 | 适用 |
| --- | --- | --- |
| **① print 大法** | `print(type(x), x.shape, x[:3])` | 90% 的问题 |
| **② 最小复现** | 把出错代码抠出来单独跑 | 复杂报错 |
| **③ 二分定位** | 注释一半代码，看错还在不在 | 不知道哪出错 |
| **④ 橡皮鸭** | 把代码逐行讲给橡皮听 | 逻辑错误（真的有用） |

### 5.6.3 学新概念的固定动作

```
① 先跑例子（把教程代码改两个数字再跑，观察变化）
② 再画图（能画出来 = 真懂了）

④ 最后才看公式（有了直觉，公式从"天书"变成"速记符"）
```

## 5.7 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `A * B` 结果"不对" | `*` 是对应位置相乘 | 矩阵乘法用 `A @ B` 或 `np.matmul` |
| `(2,3) @ (2,2)` 报错 | 中间维度不等 | 检查 shape：`(m,n) @ (n,k) → (m,k)` |
| 梯度下降不收敛 | 学习率太大 | 调小 `lr`（0.1 → 0.01），Week03 会系统讲 |
| `np.dot(u, v)` 全是 0 | 忘了向量是浮点 | 用 `1.0` 而不是 `1` 构造 |
| 数值比较 `== 0.3` 为 False | 浮点误差 | `abs(a - b) < 1e-9` |
