## 本周核心公式

**缩放点积注意力**：

$$\text{Attention}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}$$

> **这一个公式就是整个 Transformer 的核心。** GPT 的每一层里都有一份它。

**为什么要除以 $\sqrt{d_k}$**（方差分析）：

若 $q_i, k_i$ 独立、均值 0、方差 1，则点积 $q\cdot k = \sum_{i=1}^{d_k}q_ik_i$ 的方差是 $d_k$。除以 $\sqrt{d_k}$ 后方差回到 1，避免 softmax 进入饱和区。

**多头注意力**：

$$\text{MultiHead}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)\mathbf{W}^O$$
$$\text{head}_i = \text{Attention}(\mathbf{Q}\mathbf{W}_i^Q, \mathbf{K}\mathbf{W}_i^K, \mathbf{V}\mathbf{W}_i^V)$$

**Transformer 的一个块**：

$$\boldsymbol{x} \leftarrow \boldsymbol{x} + \text{Attention}(\text{LN}(\boldsymbol{x}))$$
$$\boldsymbol{x} \leftarrow \boldsymbol{x} + \text{FFN}(\text{LN}(\boldsymbol{x}))$$

（Pre-LN 结构，现代默认）

## 为什么这一周是"现代 AI 的分水岭"

```
Week13  RNN/LSTM                  Week14  Transformer
┌──────────────────────┐          ┌──────────────────────┐
│ 顺序计算，无法并行     │          │ 完全并行，训练快 10 倍 │
│ 信息压缩进固定向量     │   →      │ 直接看到所有位置       │
│ 长程依赖会衰减        │          │ 距离无关，O(1) 可达    │
│ 难以扩展到超长序列     │          │ 可扩展到百万 token     │
└──────────────────────┘          └──────────────────────┘
       2014-2017                          2017 → 现在
```

**2017 年之后，NLP 的所有进展都建立在 Transformer 上；2020 年之后，视觉（ViT）、语音、蛋白质结构预测（AlphaFold2）也被它统一。** 理解 Transformer，就理解了现代 AI 的半壁江山。
