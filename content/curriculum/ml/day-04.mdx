## 4.1 为什么是 NumPy（而不是 list）

```python
# list 的写法：逐个算（慢、啰嗦）
prices = [10.0, 20.0, 30.0]
doubled = []
for p in prices:
    doubled.append(p * 2)

# NumPy 的写法：整体一起算（快、就是数学公式的样子）
import numpy as np
prices = np.array([10.0, 20.0, 30.0])
doubled = prices * 2                  # array([20., 40., 60.])
```

第二个写法叫**向量化**——Week03 讲的"矩阵运算"、Week09 的"批量训练"全是它。
**NumPy 快的真正原因**：底层是 C 语言循环 + 连续内存，Python 只负责"喊口号"。

## 4.2 数组与 shape：最重要的一件事

**shape（形状）是 NumPy 唯一必须刻在脑子里的东西。**

```python
import numpy as np

a = np.array([1, 2, 3])
a.shape                # (3,)          一维：3 个元素

M = np.array([[1, 2, 3],
              [4, 5, 6]])
M.shape                # (2, 3)        二维：2 行 3 列
M[1, 2]                # 6             第 2 行第 3 列（下标从 0）
M[1]                   # array([4,5,6]) 整行
M[:, 0]                # array([1,4])  整列（冒号=全选）
```

**本教程后续的 shape 速查**（现在看不懂没关系，混个脸熟）：

| 数据 | shape | 出处 |
| --- | --- | --- |
| 一张灰度图 | `(28, 28)` | Week09 MNIST |
| 一批灰度图 | `(100, 28, 28)` | 100 张 |
| 一批彩色图 | `(100, 3, 28, 28)` | 3 = RGB 通道 |
| 一批样本特征 | `(100, 4)` | 100 个样本 × 4 个特征 |

**画图前转 NumPy 的约定**：`np.array(list)` 把 list 变数组；
`arr.tolist()` 变回 list；`type(arr)`、`arr.dtype`、`arr.shape` 三件套随时检查。

## 4.3 整体运算与广播

```python
a = np.array([1.0, 2.0, 3.0])

a * 2                  # 所有元素 ×2
a + 10                 # 所有元素 +10
a ** 2                 # 平方
np.sqrt(a)             # 开方

b = np.array([10, 20, 30])
a + b                  # 对应位置相加
a * b                  # 对应位置相乘（★ 这是"内积的一半"，点积见 Day5）
```

**广播（broadcasting）**：形状不同的数组运算时，NumPy 自动"补齐"。

```python
M = np.array([[1, 2, 3],
              [4, 5, 6]])      # shape (2, 3)
M * 10                         # (2,3) 与标量 -> 全体 ×10
M + np.array([100, 200, 300])  # (2,3) 与 (3,) -> 每行都加这个向量
```

规则直觉：**从右往左对齐 shape，某维要么相等、要么是 1（可复制）、要么缺失**。
`Week01 Day2` 会把它正式化为"线性代数运算规则"。

** 最经典的 bug**：

```python
a = np.array([1, 2, 3])
a + np.array([1, 2])       # ValueError: operands could not be broadcast...
```

报错里 ` (3,) (2,) ` 就是两个 shape——**对着 shape 调试，不要对着数字猜**。

## 4.4 axis：按行还是按列求和

```python
M = np.array([[1, 2, 3],
              [4, 5, 6]])          # shape (2, 3)

M.sum()        # 21     全部加总
M.sum(axis=0)  # array([5, 7, 9])   ★ axis=0：跨行压缩 -> 得到"每列的和"
M.sum(axis=1)  # array([ 6, 15])    ★ axis=1：跨列压缩 -> 得到"每行的和"
M.mean()       # 3.5     平均
M.max()        # 6       最大
M.argmax()     # 5       最大值的【位置】（Week02 评估、Week09 预测类别全用它）
```

**axis 的记忆法**：**axis=i 就是"把第 i 维压扁"**。

- `shape (2,3)`，`axis=0` → 2 被压掉 → 结果 shape `(3,)`（每列一个数）；
- `axis=1` → 3 被压掉 → 结果 `(2,)`（每行一个数）。

**自测**：`np.ones((4, 3)).sum(axis=0)` 的 shape 是多少？（答案 `(3,)`）

## 4.5 常用生成函数

```python
np.zeros(5)                  # [0,0,0,0,0]
np.ones((2, 3))              # 2×3 全 1
np.arange(0, 10, 2)          # [0,2,4,6,8]      同 range
np.linspace(0, 1, 5)         # [0, 0.25, 0.5, 0.75, 1]  ★ 等分采样（画曲线神器）
np.random.seed(42)           # ★ 固定随机种子（Week01 起每份代码开头都有它）
np.random.rand(3)            # 3 个 [0,1) 均匀随机数
np.random.randn(2, 3)        # 2×3 标准正态（周老师口中的"高斯噪声"）
```

**为什么天天 `np.random.seed(42)`**：让"随机"可复现——你跑出的结果和我的一样，
Week15 讲的"可复现性"从这一行开始。

## 4.6 Matplotlib：把数据画出来

```python
import matplotlib
matplotlib.use("Agg")          # 不弹窗，直接存文件（离线环境标准做法）
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)     # [0, 2π] 取 100 个点
y = np.sin(x)

plt.plot(x, y)                 # 折线图
plt.title("y = sin(x)")
plt.xlabel("x")
plt.ylabel("y")
plt.savefig("figures/sin.png", dpi=110)   # ★ 存文件
plt.close()                    # 释放内存
```

**四个高频图型**（Week02 评估会全部用到）：

| 图 | 函数 | 用途 |
| --- | --- | --- |
| 折线 | `plt.plot(x, y)` | 训练曲线（loss 随 epoch） |
| 散点 | `plt.scatter(x, y)` | 看分布（Week01 数据、Week06 聚类） |
| 柱状 | `plt.bar(names, vals)` | 类别分布（Week03 类不平衡） |
| 图像 | `plt.imshow(arr, cmap="gray")` | 看 MNIST（Week09） |

**两个易错点**：
- 中文标题显示成方块 → 本教程统一用英文标题（最省事）；
- 忘了 `plt.close()` → 内存慢慢被吃光（脚本里循环画图时）。

## 4.7 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `ValueError: operands could not be broadcast` | shape 不匹配 | 打印两个 `.shape` 对着看 |
| `sum(axis=?)` 结果维度困惑 | axis 记反了 | **axis=i 压掉第 i 维** |
| 改了 `M[0,0]` 另一个数组也变 | 切片是"视图"共享内存 | 用 `M.copy()` |
| `import numpy` 报 ModuleNotFoundError | 没装 | `pip install numpy` |
| 图不显示 | 用了 Agg 后端 | 正常，看 `savefig` 的文件 |
| 画图中文变方块 | 字体问题 | 标题用英文 |
