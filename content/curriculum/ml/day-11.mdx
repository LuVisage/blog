## 一、从"编程"到"学习"

传统编程与机器学习的根本区别：

| 范式 | 输入 | 输出 |
| --- | --- | --- |
| 传统编程 | 规则 + 数据 | 答案 |
| **机器学习** | 数据 + 答案 | **规则（模型）** |

**汤姆·米切尔（Tom Mitchell）1997 年的经典定义**：

> 对于一个计算机程序，若它在任务 $T$ 上的性能度量 $P$ 随经验 $E$ 而自动改进，则称它**从经验 $E$ 中学习**。

三个要素缺一不可：

- $T$（Task）：任务。例如"识别垃圾邮件"。
- $P$（Performance）：性能度量。例如"分类准确率"。
- $E$（Experience）：经验。例如"已标注的历史邮件"。

**例子对照**：

| 任务 $T$ | 性能度量 $P$ | 经验 $E$ |
| --- | --- | --- |
| 下棋 | 胜率 | 历史棋谱 |
| 垃圾邮件识别 | 准确率 / 召回率 | 已标注邮件 |
| 房价预测 | 均方误差 | 历史成交记录 |
| 手写数字识别 | 错误率 | 标注图片 |

> **注意**：如果 $P$ 定义得不对（比如不平衡数据只看准确率），"学习"就会朝着错误方向改进。

## 二、形式化定义

### 2.1 数据集

| 符号 | 含义 |
| --- | --- |
| $\mathcal{D} = \{\boldsymbol{x}_1, \dots, \boldsymbol{x}_m\}$ | 含 $m$ 个样本的数据集 |
| $\boldsymbol{x}_i \in \mathcal{X}$ | 第 $i$ 个样本，$\mathcal{X}$ 为**输入空间**（属性空间） |
| $\boldsymbol{x}_{ij}$ | 第 $i$ 个样本在第 $j$ 个属性上的取值 |
| $n$ | 属性（特征）个数，即 $\boldsymbol{x}_i \in \mathbb{R}^n$ |
| $y_i \in \mathcal{Y}$ | 标签，$\mathcal{Y}$ 为**输出空间**（标记空间） |
| $(\boldsymbol{x}_i, y_i)$ | 一个**样例** |
| $h: \mathcal{X} \to \mathcal{Y}$ | **假设**（hypothesis），也叫模型/学习器 |

**按 $\mathcal{Y}$ 分类**：

- $\mathcal{Y} = \{0, 1\}$ 或有限集合 → **分类**任务；
- $\mathcal{Y} = \mathbb{R}$ → **回归**任务。

**若 $y$ 是 $\boldsymbol{x}$ 的真实标签**，则称 $\boldsymbol{x}$ 为**示例（instance）**；若没有标签，$\boldsymbol{x}$ 为**样本（sample）**。日常混用无妨。

### 2.2 假设空间

**定义**：所有可能的假设构成的集合 $\mathcal{H}$。

**西瓜书的经典例子**（好瓜识别）：

属性取值：
- 色泽：青绿、乌黑、浅白（3 种）
- 根蒂：蜷缩、稍蜷、硬挺（3 种）
- 敲声：浊响、沉闷、清脆（3 种）

**假设的表示形式**：合取式，例如

```
（色泽=青绿）∧（根蒂=蜷缩）∧（敲声=浊响）
```

每个属性有三种选择：

- 取某个具体值（如"青绿"）：1 种
- 取通配符 `*`（表示任何值都行）：1 种
- 取"$\emptyset$"（表示该属性无论取什么都**不可能**是好瓜）：1 种

于是假设空间规模为：

$$|\mathcal{H}| = 1 + \underbrace{4\times4\times4}_{\text{每个属性 3 个值 + 1 个通配符}} = 1 + 64 = 65$$

（加 1 是因为要额外计入"根本不存在好瓜"这一假设。）

### 2.3 版本空间

遍历假设空间，剔除与训练集**不一致**的假设（即在某个样例上预测出错的假设），剩下的集合称为**版本空间**。

```
规则: 去掉所有与数据冲突的假设
                    ↓
假设空间 (65) ──过滤──→ 版本空间 (可能有多个假设)
```

**关键洞察**：**训练集通常无法唯一确定一个假设**，版本空间里常有多个等价假设。

**例**：训练集只有 1 个正例 `(青绿, 蜷缩, 浊响)`，1 个反例 `(乌黑, 稍蜷, 沉闷)`。

那么 `(青绿, *, *)` 和 `(青绿, 蜷缩, *)` 都与数据一致，都在版本空间里——它们对**训练集**表现完全相同，但对**新样本**的预测可能不同。

**这就引出了问题：该选哪一个？** 答案是——用**归纳偏好**。

## 三、归纳偏好

**定义**：学习算法在**多个等价假设**中做出选择的偏好。它体现了算法的"价值观"。

### 3.1 奥卡姆剃刀（Occam's Razor）

> **若有多个假设与观察一致，选最简单的那个。**

"简单"的度量方式因算法而异：

| 算法 | 简单的含义 |
| --- | --- |
| 决策树 | 树深度小、叶子少 |
| 线性模型 | 权重范数小 |
| kNN | $k$ 取较大（决策边界更平滑） |
| 神经网络 | 参数量少 / 权重小 |

**为什么偏好简单模型**：简单模型假设空间小、方差低，在有限数据下更不容易被噪声带偏（Week02 Day4 会定量说明）。

### 3.2 No Free Lunch 定理（NFL）

**定理陈述**：对所有可能的问题（目标函数）均匀分布求平均，任何学习算法的**期望性能都相同**。

**推导直觉**：设目标函数 $f$ 在训练集外的取值是完全随机的，那么算法 $A$ 和算法 $B$ 的期望错误率必然相等（$\sum_f$ 时，每个 $f$ 都有对应的"反函数"抵消优势）。

**NFL 的正确解读**（很多人误读）：

| 常见误读 | 正确理解 |
| --- | --- |
| 所有算法一样好，随便选 | 前提是"对所有问题均匀平均" |
| 所以不需要研究算法 | 真实问题不服从均匀分布 |

**真正的结论**：

> **既然没有普适的最优算法，就必须针对具体问题引入"先验假设"（归纳偏好）。算法效果的好坏，取决于它的归纳偏好是否与当前问题匹配。**

**实践推论**：

- 图像任务选 CNN（先验：局部性、平移不变性）；
- 序列任务选 RNN/Transformer（先验：时序依赖、注意力）；
- 表格数据选树模型（先验：特征交互稀疏）；
- 无先验时，从简单模型开始（线性 / kNN）建立 baseline。

## 四、学习任务的分类

### 4.1 按监督信息

| 类型 | 数据 | 典型任务 | 代表算法 |
| --- | --- | --- | --- |
| **监督学习** | $(\boldsymbol{x}_i, y_i)$ 全标注 | 分类、回归 | 线性回归、SVM、决策树 |
| **无监督学习** | 仅 $\boldsymbol{x}_i$ | 聚类、降维、密度估计 | K-Means、PCA、GMM |
| **半监督学习** | 少量标注 + 大量未标注 | 分类 | 半监督 SVM、标签传播 |
| **强化学习** | 与环境交互获得奖励 | 决策、控制 | Q-Learning、DQN、PPO |
| **自监督学习** | 从数据本身构造监督信号 | 预训练 | BERT 的 MLM、对比学习 |

### 4.2 按任务类型

| 任务 | 输出 | 例子 |
| --- | --- | --- |
| **分类** | 离散标签 | 垃圾邮件识别 |
| **回归** | 连续值 | 房价预测 |
| **聚类** | 簇划分 | 用户分群 |
| **降维** | 低维表示 | 可视化、去噪 |
| **排序** | 序列次序 | 搜索结果排序 |
| **生成** | 新样本 | 图像生成、文本生成 |

## 五、机器学习的三要素（贯穿全课程）

任何一个机器学习算法，都可以用这三个问题来解剖：

$$\boxed{\ 1.\ \text{模型/假设空间}\quad 2.\ \text{损失函数/策略}\quad 3.\ \text{优化算法}\ }$$

以线性回归为例：

| 要素 | 线性回归的具体形式 |
| --- | --- |
| 模型 | $h(\boldsymbol{x}) = \boldsymbol{w}^\top\boldsymbol{x} + b$ |
| 损失 | $L(\boldsymbol{w}) = \sum_i (y_i - \boldsymbol{w}^\top\boldsymbol{x}_i)^2$ |
| 优化 | 最小二乘（解析解）或梯度下降 |

以逻辑回归为例：

| 要素 | 逻辑回归的具体形式 |
| --- | --- |
| 模型 | $h(\boldsymbol{x}) = \sigma(\boldsymbol{w}^\top\boldsymbol{x} + b)$ |
| 损失 | 交叉熵（负对数似然） |
| 优化 | 梯度下降 / 牛顿法 |

> **学习习惯建议**：以后遇到任何新算法，先问这 3 个问题。如果能答上来，你就已经理解它了。

## 六、代码实践：枚举版本空间

```python
import itertools
import numpy as np

# 属性及取值
attrs = {
    "色泽": ["青绿", "乌黑", "浅白"],
    "根蒂": ["蜷缩", "稍蜷", "硬挺"],
    "敲声": ["浊响", "沉闷", "清脆"],
}
attr_names = list(attrs.keys())
WILDCARD = "*"      # 通配符
EMPTY = "Ø"         # 表示"不存在好瓜"

# 训练集（西瓜书表 1.1 的简化版）
train = [
    (("青绿", "蜷缩", "浊响"), 1),   # 正例
    (("乌黑", "稍蜷", "沉闷"), 0),   # 反例
]

def build_hypothesis_space():
    """每个属性取值: 3 个具体值 + 1 个通配符 = 4 种"""
    options = [[*attrs[a], WILDCARD] for a in attr_names]
    space = list(itertools.product(*options))
    space.append(EMPTY)              # 加上"不存在好瓜"
    return space

def predicts_positive(h, x):
    """假设 h 对样本 x 的预测: 1 表示好瓜"""
    if h == EMPTY:
        return 0
    for hv, xv in zip(h, x):
        if hv != WILDCARD and hv != xv:
            return 0
    return 1

def version_space(train):
    return [h for h in build_hypothesis_space()
            if all(predicts_positive(h, x) == y for x, y in train)]
```

完整版本见 `code/day1_what_is_ml.py`，它会打印：

- 假设空间大小；
- 版本空间大小及全部元素；
- 两个不同假设在新样本上的**预测分歧**（说明归纳偏好的必要性）。

## 七、常见坑

| 坑 | 说明 |
| --- | --- |
| 把"训练误差低"当成"模型好" | 训练误差可以通过死记硬背降到 0，关键是泛化误差 |
| 认为 NFL 说明算法无优劣 | NFL 的前提是"对所有问题均匀平均"，真实问题有结构 |
| 混淆"样本"与"示例" | 西瓜书有严格区分，日常交流不用纠结 |
| 忽略归纳偏好 | 每个算法的默认偏好都是隐藏假设，不匹配问题就会表现差 |
| 以为无监督学习不需要评估 | 无监督也需要评估（内部指标如轮廓系数、外部指标如 NMI） |

**进阶**

**思考题**

7. NFL 定理说明"没有普适最优算法"。那么"A 算法在数据集 X 上优于 B 算法"这一陈述是否有意义？请说明加入什么前提后它才成立。
8. 为什么深度学习在图像上如此成功，而梯度提升树（GBDT）在表格数据上往往更强？请从"归纳偏好与数据结构匹配"的角度分析。

<details>
<summary>第 2 题答案</summary>

4 个属性，每个属性 3 个取值 + 1 个通配符 = 4 种选择：

$$|\mathcal{H}| = 1 + 4^4 = 1 + 256 = 257$$
</details>

<details>
<summary>第 6 题提示</summary>

MAP 估计：

$$\hat{h}_{\text{MAP}} = \arg\max_h \left[\log P(\mathcal{D}|h) + \log P(h)\right]$$

若先验 $P(h)$ 对"简单"假设赋予更高概率（例如权重服从高斯先验，权重范数小则概率大），则 MAP 会优选简单假设。**正则化就是奥卡姆剃刀的数学实现。**
</details>

## 九、一句话总结

**机器学习的本质是：在一个受限的假设空间里，根据数据挑出一个假设；而挑哪个，取决于算法内置的归纳偏好。**
