## 一、为什么准确率不够用

考虑一个**欺诈检测**场景：10000 笔交易中只有 100 笔是欺诈。

现在训练一个"傻瓜模型"：**把所有交易都判为正常**。

$$\text{准确率} = \frac{9900}{10000} = 99\%$$

但它**一笔欺诈都没抓到**。这个模型毫无价值。

**根本原因**：准确率对**不同类别的错误一视同仁**，而在真实问题中，漏掉一个欺诈 vs 误判一个正常交易，代价完全不同。

## 二、混淆矩阵

二分类问题的四种结果：

| | 预测为正 | 预测为负 |
| --- | --- | --- |
| **真实为正** | TP（真正例） | FN（假反例） |
| **真实为负** | FP（假正例） | TN（真反例） |

**记忆方法**：第一个字母 T/F 表示预测对不对，第二个字母 P/N 表示**预测**成了什么。

- **TP**：预测为正，且对了；
- **FN**：预测为负，错了（漏报，Miss）；
- **FP**：预测为正，错了（误报，False Alarm）；
- **TN**：预测为负，且对了。

**多分类**：混淆矩阵 $k\times k$，$M_{ij}$ = 真实类别 $i$ 被预测为类别 $j$ 的样本数。对角线是正确预测。

## 三、核心指标

### 3.1 精确率（查准率 Precision）

$$P = \frac{TP}{TP + FP}$$

**含义**：**预测为正的样本中，有多少是真的正**。

**关注场景**：误报代价高。例如垃圾邮件过滤——把正常邮件判成垃圾（FP）会让用户错过重要信息。

> **口诀**："我说的正例里，有多少是真的。"

### 3.2 召回率（查全率 Recall / 灵敏度）

$$R = \frac{TP}{TP + FN}$$

**含义**：**真实为正的样本中，有多少被找出来了**。

**关注场景**：漏报代价高。例如癌症筛查——漏诊（FN）后果严重。

> **口诀**："真实的正例里，我找出来多少。"

### 3.3 二者的矛盾

$$P = \frac{TP}{TP+FP}, \qquad R = \frac{TP}{TP+FN}$$

分母不同，**通常无法同时最优**。

```
提高阈值（更严格判为正）     降低阈值（更宽松判为正）
      ↓                            ↓
   FP ↓ → P ↑                   FP ↑ → P ↓
   FN ↑ → R ↓                   FN ↓ → R ↑
```

**极端情形**：

| 策略 | $P$ | $R$ |
| --- | --- | --- |
| 只把最确定的 1 个样本判为正 | 1.0 | 极低 |
| 把所有样本都判为正 | 极低 | 1.0 |

### 3.4 $F_1$ 分数

调和平均（比算术平均更惩罚极端值）：

$$F_1 = \frac{2 \cdot P \cdot R}{P + R} = \frac{2\,TP}{2\,TP + FP + FN}$$

**为什么用调和平均**：算术平均下，$P=1.0, R=0.01$ 会得到 0.505，看起来还行；调和平均得到 $F_1 = 0.0198$，正确反映了"其中一项几乎为 0，整体就不好"。

### 3.5 $F_\beta$ 分数

当 $P$ 与 $R$ 重要性不同时：

$$F_\beta = \frac{(1+\beta^2)\cdot P \cdot R}{\beta^2 P + R}$$

| $\beta$ | 侧重 | 场景 |
| --- | --- | --- |
| $\beta < 1$ | 偏向**精确率** | 垃圾邮件过滤 |
| $\beta = 1$ | 平衡 | 一般场景 |
| $\beta > 1$ | 偏向**召回率** | 疾病筛查 |

### 3.6 其他常用指标

| 指标 | 公式 | 用途 |
| --- | --- | --- |
| 特异度（Specificity） | $TN/(TN+FP)$ | 真负例率，医学常用 |
| 准确率（Accuracy） | $(TP+TN)/m$ | 类别均衡时可用 |
| 平衡准确率 | $(R + \text{特异度})/2$ | 不平衡数据 |
| 马修斯相关系数 MCC | $\frac{TP\cdot TN - FP\cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$ | 对不平衡最鲁棒 |

## 四、PR 曲线与 ROC 曲线

分类器输出的通常是**概率（得分）**。设定不同阈值，就得到不同的 $(P, R)$ 或 $(FPR, TPR)$ 组合。把这些点连起来就是曲线。

### 4.1 PR 曲线

- 横轴：召回率 $R$
- 纵轴：精确率 $P$

**平衡点（BEP）**：$P = R$ 处的取值，可用来比较学习器。

**平均精度 AP（Average Precision）**：PR 曲线下的面积，等价于对各类别分别计算 $P$-$R$ 后求平均（西瓜书称为"宏平均 AUC"的一种形式）。

### 4.2 ROC 曲线

**定义两个坐标轴**：

$$TPR = \frac{TP}{TP+FN} = R \quad(\text{真正例率，即召回率})$$

$$FPR = \frac{FP}{FP+TN} \quad(\text{假正例率})$$

以 $FPR$ 为横轴、$TPR$ 为纵轴作图。

```
TPR
 1 ┤            ______--------█  (完美分类器：从 (0,0) 直上到 (0,1)，再横到 (1,1))
   │        ____/
   │     __/                    ← 优于随机猜测的曲线（上凸）
   │   _/
   │  /  ← 随机猜测：对角线 (AUC = 0.5)
   │ /
 0 ┼─────────────────────────→ FPR
   0                          1
```

| 曲线位置 | 含义 |
| --- | --- |
| 左上角 (0,1) | 完美分类器 |
| 对角线 | 随机猜测（AUC = 0.5） |
| 右下角 | 比随机还差（AUC &lt; 0.5，反向使用即可 > 0.5） |

### 4.3 AUC（Area Under Curve）

**几何定义**：ROC 曲线下的面积，$\text{AUC} \in [0,1]$。

**概率定义（非常重要）**：

$$\text{AUC} = P\left(s(\boldsymbol{x}^+) > s(\boldsymbol{x}^-)\right)$$

即：**随机取一个正样本和一个负样本，模型给正样本的分数更高的概率。**

**计算方式**（用曼-惠特尼 U 统计量）：

$$\text{AUC} = \frac{\sum_{i\in\text{正}}\sum_{j\in\text{负}} \mathbb{1}[s_i > s_j] + 0.5\,\mathbb{1}[s_i = s_j]}{N_+ \cdot N_-}$$

### 4.4 AUC 的优点

1. **对阈值不敏感**：只关心排序能力，不需要选定阈值；
2. **对类别不平衡相对鲁棒**：因为 $TPR$ 和 $FPR$ 分别在各自动分母内归一化。

> **"AUC 对不平衡鲁棒"这句话要谨慎理解**：
> AUC 对**类别比例的变化**确实不敏感（这是优点），但当**负例数量极大**时，即使 FPR 很小，FP 的绝对数量仍可能很大。此时 PR 曲线更能反映实际业务效果。

### 4.5 何时用 PR，何时用 ROC

| 场景 | 推荐 |
| --- | --- |
| 类别大致均衡 | ROC-AUC |
| **正例极少**（如 1%） | **PR 曲线 / AP** |
| 关心"预测为正的准确度" | PR |
| 关心"全体排序能力" | ROC |

**原因**：$FPR = FP/(FP+TN)$，当 $TN$ 极大时，$FPR$ 的变化被稀释，ROC 曲线看起来很漂亮，但实际 PR 很差。

## 五、代价敏感学习

### 5.1 代价矩阵

设 $cost_{ij}$ 表示"真实为 $i$、预测为 $j$"的代价（$i,j\in\{0,1\}$）。

**总体代价**：

$$L_{\text{total}} = cost_{01}\cdot FN + cost_{10}\cdot FP$$

若认为"把正例判成负例"的代价是反向的 $k$ 倍（$cost_{01} = k \cdot cost_{10}$），则需在损失函数中加权。

### 5.2 最优阈值的选取

给定类别先验 $P(+)$、$P(-)$ 与代价矩阵，理论最优阈值为：

$$\text{预测为正} \iff \frac{p(+|\boldsymbol{x})}{p(-|\boldsymbol{x})} > \frac{cost_{10}\cdot P(-)}{cost_{01}\cdot P(+)}$$

**特例**：若代价相等（$cost_{01}=cost_{10}$），阈值退化为 $\frac{P(+)}{P(-)}$，即在类别不平衡时**不应直接把阈值设为 0.5**。

> **实践建议**：不平衡数据上，不要用 0.5 作为阈值。应在验证集上扫描阈值，选择使业务指标（如 $F_1$ 或总代价）最优的那个。

### 5.3 通过采样调整类别分布

| 方法 | 做法 | 缺点 |
| --- | --- | --- |
| 欠采样 | 丢弃部分负例 | 丢失信息 |
| 过采样 | 复制/生成正例 | 可能过拟合 |
| SMOTE | 在正例间插值生成新样本 | 可能生成噪声样本 |
| 类别权重 | 在损失函数中给少数类更高权重 | 最推荐，无信息损失 |

## 六、回归任务的度量

| 指标 | 公式 | 特点 |
| --- | --- | --- |
| MSE | $\frac{1}{m}\sum(y_i-\hat y_i)^2$ | 对大误差敏感，处处可导 |
| RMSE | $\sqrt{\text{MSE}}$ | 与 $y$ 同量纲 |
| MAE | $\frac{1}{m}\sum\|y_i-\hat y_i\|$ | 对离群点鲁棒，0 点不可导 |
| MAPE | $\frac{1}{m}\sum\left\|\frac{y_i-\hat y_i}{y_i}\right\|$ | 相对误差，$y_i$ 接近 0 时爆炸 |
| $R^2$ | $1 - \frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$ | 解释方差比例，$\le 1$ |

**$R^2$ 的性质**：

- $R^2 = 1$：完美预测；
- $R^2 = 0$：等价于"永远预测均值"；
- $R^2 < 0$：比预测均值还差（可能发生在测试集上）。

> **MSE 与 MAE 的选择**见 Week01 Day5 第 8 题：**损失函数 = 负对数似然，由噪声分布决定**。高斯噪声 → MSE，拉普拉斯噪声 → MAE。

## 七、代码实践

```python
import numpy as np

def confusion_matrix_binary(y_true, y_pred):
    tp = np.sum((y_true == 1) & (y_pred == 1))
    fn = np.sum((y_true == 1) & (y_pred == 0))
    fp = np.sum((y_true == 0) & (y_pred == 1))
    tn = np.sum((y_true == 0) & (y_pred == 0))
    return tp, fn, fp, tn

def precision_recall_f1(tp, fn, fp):
    p = tp / (tp + fp) if tp + fp > 0 else 0.0
    r = tp / (tp + fn) if tp + fn > 0 else 0.0
    f1 = 2 * p * r / (p + r) if p + r > 0 else 0.0
    return p, r, f1

def auc_rank(y_true, scores):
    """用曼-惠特尼 U 统计量计算 AUC（概率定义）"""
    pos = scores[y_true == 1]
    neg = scores[y_true == 0]
    # 对每一对 (正, 负) 比较，用排序法向量化加速
    order = np.argsort(scores, kind="mergesort")
    ranks = np.empty(len(scores), dtype=float)
    ranks[order] = np.arange(1, len(scores) + 1)
    # 处理并列：用平均秩
    s_sorted = scores[order]
    i = 0
    while i < len(s_sorted):
        j = i
        while j + 1 < len(s_sorted) and s_sorted[j + 1] == s_sorted[i]:
            j += 1
        if j > i:
            ranks[order[i:j + 1]] = ranks[order[i:j + 1]].mean()
        i = j + 1
    n_pos, n_neg = len(pos), len(neg)
    auc = (ranks[y_true == 1].sum() - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
    return auc
```

## 八、常见坑

| 坑 | 说明 |
| --- | --- |
| 不平衡数据只看准确率 | 99% 准确率可能等于什么都没做 |
| 混淆"精确率"与"准确率" | Precision 分母是"预测为正"，Accuracy 分母是全体 |
| 用 0.5 作为不平衡数据的阈值 | 应基于业务与代价选择阈值 |
| 不平衡数据只看 ROC-AUC | 负例极多时看 PR 更实际 |
| 混淆矩阵只算 Accuracy | 一定要看每一类的召回率 |
| 用 `np.mean(pred == y)` 忽略样本权重 | 加权场景需加权计算 |
| 对概率输出直接算 accuracy | 应先确定阈值再比较 |
| 回归任务用 MAPE 且 $y$ 有 0 值 | 会得到 inf |

## 九、练习题

**基础**

1. 某分类器在测试集上得到 $TP=80, FN=20, FP=40, TN=860$。计算准确率、精确率、召回率、$F_1$、特异度。
2. 判断下列场景应优先优化精确率还是召回率：
 (a) 垃圾邮件过滤 (b) 癌症筛查 (c) 推荐系统的首屏展示 (d) 反洗钱预警
3. 说明 AUC = 0.5 意味着什么。

**进阶**

4. 证明 $F_1 = \frac{2TP}{2TP + FP + FN}$。
5. 证明 AUC 的概率定义与面积定义等价。（提示：AUC 等于 ROC 曲线下面积，也可写成 $\int TPR\, d(FPR)$）
6. 给定一个分类器把每个样本输出为 0–1 的概率分数。写出扫描阈值的伪代码，并说明如何选择"最优"阈值。

**思考题**

7. 一个数据集正负比为 1:1000。模型 A 的 AUC = 0.95，模型 B 的 AUC = 0.90，但 B 在实际业务中效果更好。请构造一个合理解释。
8. 为什么说"$F_1$ 分数高但业务效果差"是可能的？请举一个具体场景。

<details>
<summary>第 1 题答案</summary>

$$P = \frac{80}{80+40} = 0.667, \quad R = \frac{80}{80+20} = 0.80, \quad F_1 = \frac{2\times0.667\times0.8}{0.667+0.8} = 0.727$$

$$\text{Accuracy} = \frac{80+860}{1000} = 0.94, \quad \text{特异度} = \frac{860}{860+40} = 0.956$$
</details>

<details>
<summary>第 4 题答案</summary>

$$F_1 = \frac{2PR}{P+R} = \frac{2 \cdot \frac{TP}{TP+FP}\cdot\frac{TP}{TP+FN}}{\frac{TP}{TP+FP}+\frac{TP}{TP+FN}} = \frac{2\cdot\frac{TP^2}{(TP+FP)(TP+FN)}}{TP\cdot\frac{(TP+FN)+(TP+FP)}{(TP+FP)(TP+FN)}} = \frac{2TP}{2TP+FP+FN}$$
</details>

<details>
<summary>第 8 题要点</summary>

$F_1$ 只衡量"找得准不准、全不全"，不衡量"找到的东西价值多大"。

**例**：反欺诈系统召回了 90% 的欺诈交易（$F_1$ 0.85），但这些欺诈的交易额都只有几块钱，真正的大额欺诈全部漏掉。业务损失依然巨大。

**结论**：$F_1$ 是**样本级**指标，业务价值往往是**金额级 / 权重级**的，需要加权指标。
</details>
