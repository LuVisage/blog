## 1.2 全连接层处理图像的三个问题

MNIST 输入是 $28\times28$，展平后 784 维。第一层 128 个神经元需要 $784\times128 = 100{,}352$ 个参数。

如果换成 $256\times256$ 的彩色照片：$256\times256\times3 = 196{,}608$ 维输入，同样 128 个神经元需要 **2517 万**参数 —— 仅仅第一层。

**三个结构性问题**：

| 问题 | 说明 |
| --- | --- |
| **参数量爆炸** | 参数量正比于输入像素数，与图像大小平方相关 |
| **破坏空间结构** | 展平后，"相邻像素"这个信息完全丢失 |
| **没有平移不变性** | 猫出现在左上角与右下角，需要两套完全不同的权重去学 |

**卷积的三个对应设计**：

| 设计 | 解决 |
| --- | --- |
| **局部连接**（每个输出只看 $K\times K$ 邻域） | 参数量骤降 |
| **权重共享**（所有位置用同一组权重） | 参数量与图像大小**无关**；获得平移等变性 |
| **保留二维结构**（输入输出都是特征图） | 空间关系不丢失 |

## 1.3 卷积的定义

### 1.3.1 单通道、单核

给定输入 $\mathbf{X} \in \mathbb{R}^{H\times W}$ 与卷积核 $\mathbf{K} \in \mathbb{R}^{k\times k}$，输出：

$$\mathbf{Y}_{i,j} = \sum_{u=0}^{k-1}\sum_{v=0}^{k-1} \mathbf{X}_{i+u,\ j+v}\cdot \mathbf{K}_{u,v} + b$$

**直观理解**：把卷积核当作一个"模板"，在图像上滑动，每个位置计算模板与局部区域的**逐元素乘积之和**（即内积）。内积大 = 该位置与模板很像。

> **术语提醒**：深度学习里的"卷积"严格来说是**互相关（cross-correlation）**，没有做核翻转。因为核是可学习的，翻不翻转等价。花书 9.1 有说明。

### 1.3.2 一个手算例子

```
输入 X (5×5)              核 K (3×3)          输出 Y (3×3)
1  2  3  0  1             1  0  1
4  5  6  1  0             0  1  0             Y[0,0] = 1*1+2*0+3*1
7  8  9  2  1             1  0  1                     + 4*0+5*1+6*0
0  1  2  3  4                                        + 7*1+8*0+9*1
5  6  7  8  9                                     = 1+3+5+7+9 = 25
```

这个核（四角 + 中心为 1）在检测"X 形"或"棋盘纹理"。

### 1.3.3 四种常见的"检测器"核

| 核 | 数值 | 检测什么 |
| --- | --- | --- |
| 均值模糊 | $\frac{1}{9}\mathbf{1}_{3\times3}$ | 平滑、去噪 |
| 垂直边缘 | $\begin{bmatrix}1&0&-1\\1&0&-1\\1&0&-1\end{bmatrix}$ | 竖直边缘 |
| 水平边缘 | $\begin{bmatrix}1&1&1\\0&0&0\\-1&-1&-1\end{bmatrix}$ | 水平边缘 |
| 锐化 | $\begin{bmatrix}0&-1&0\\-1&5&-1\\0&-1&0\end{bmatrix}$ | 增强细节 |

**关键认识**：这些核是**手工设计**的特征提取器（传统图像处理的全部家当）。CNN 做的是**让网络自己学出该用什么样的核** —— 而且第一层学到的往往就长成边缘检测器的样子（Day4 可视化会看到）。

## 1.4 padding / stride / 输出尺寸

### 1.4.1 三种问题

**问题 1：输出会变小。** $5\times5$ 经 $3\times3$ 卷积变 $3\times3$；堆几层就没了。

**问题 2：边缘像素被用到的次数远少于中心像素。** 角落只被用 1 次，中心被用 9 次 —— 边缘信息利用不足。

**问题 3：有时需要降采样**（减少计算量、扩大感受野）。

**解决方案**：padding 与 stride。

### 1.4.2 padding（填充）

在输入四周补 0：

```
P=1 时，5×5 变成 7×7

0 0 0 0 0 0 0
0 1 2 3 0 1 0
0 4 5 6 1 0 0
0 7 8 9 2 1 0
0 0 1 2 3 4 0
0 5 6 7 8 9 0
0 0 0 0 0 0 0

此时 3×3 卷积输出仍是 5×5
```

| padding 方式 | 作用 |
| --- | --- |
| `valid`（P=0） | 输出变小 |
| `same`（$P=(K-1)/2$，$S=1$） | **输出尺寸不变**，最常用 |
| `full` | 输出变大（很少用） |

**为什么补 0 而不是别的值**：0 在卷积中不贡献内积（对应位置乘 0），相当于"不存在的像素"，语义上最干净。

### 1.4.3 stride（步长）

滑动步长 $S$。$S=2$ 时输出尺寸大致减半，是一种**降采样**手段（现代网络中常被池化或 stride 卷积替代，见 Day2）。

### 1.4.4 输出尺寸公式（必须背下来）

$$\boxed{H_{out} = \left\lfloor \frac{H_{in} + 2P - K}{S}\right\rfloor + 1}$$

**心算练习**（答案在文末）：

| 输入 | K | P | S | 输出 |
| --- | --- | --- | --- | --- |
| 28 | 3 | 1 | 1 | ? |
| 28 | 3 | 0 | 1 | ? |
| 28 | 3 | 1 | 2 | ? |
| 32 | 5 | 2 | 1 | ? |
| 224 | 7 | 3 | 2 | ? |

> 第五个是 AlexNet 的第一层（Week11 Day5），输出 112 —— 把 224 的输入降到一半。

## 1.5 多通道与批量

### 1.5.1 多通道（通道是"深度"）

**规则：卷积核的通道数必须等于输入的通道数。**

- 输入 $\mathbf{X}$：$(C_{in}, H, W)$
- 核 $\mathbf{K}$：$(C_{in}, k, k)$ —— 每个输入通道配一个 $k\times k$ 子核
- 输出：$(1, H_{out}, W_{out})$ —— **求和后合并成一个通道**

**要输出多个通道怎么办？用多个核！**

$$\mathbf{W}: (C_{out}, C_{in}, k, k) \Rightarrow \mathbf{Y}: (C_{out}, H_{out}, W_{out})$$

**参数量** = $C_{out}\times C_{in}\times k\times k + C_{out}$（偏置）

> **这是最容易搞混的一点**：`nn.Conv2d(3, 64, 3)` 的权重形状是 `(64, 3, 3, 3)`，不是 `(3, 64, 3, 3)`。这就是 Week09 Day2 讲过的"`nn.Linear` 权重转置"同类问题的 2D 版本。

### 1.5.2 批量

$$\text{输入}: (N, C_{in}, H, W) \Rightarrow \text{输出}: (N, C_{out}, H_{out}, W_{out})$$

**批量维度 $N$ 不参与卷积计算**，各样本独立处理。这也是为什么卷积天然支持任意 batch size。

### 1.5.3 维度变化速查

```
Input:  (N, C_in,  H,     W    )
Weight: (C_out, C_in,  k,     k    )
Output: (N, C_out, H_out, W_out)

其中 H_out = floor((H + 2P - k)/S) + 1
```

## 1.6 参数量与计算量

**两个必须会算的量**：

| 量 | 公式 | 例子：`Conv2d(3, 64, 3)` (P=1) |
| --- | --- | --- |
| 参数量 | $C_{out}(C_{in}k^2 + 1)$ | $64\times(3\times9+1) = 1792$ |
| 输出尺寸 | 见 1.4.4 | 输入 $224\times224$ → $224\times224$ |
| FLOPs | $H_{out}W_{out}\cdot C_{out}\cdot C_{in}k^2$ | $224^2\times64\times3\times9 \approx 8.7\times10^7$ |

**对比全连接**：若把这层换成"$150528$ 维输入 → $64\times224\times224$ 维输出"的全连接层，参数量是 $1.5\times10^5 \times 3.2\times10^6 \approx 4.8\times10^{11}$ —— 多出 2.7 亿倍。

> **记住这个数量级的差距**，它是卷积统治计算机视觉的根本原因。

## 1.7 两个常被搞混的性质

| 性质 | 含义 | 公式 |
| --- | --- | --- |
| **平移等变** | 输入平移，输出**跟着平移** | $f(\text{shift}(x)) = \text{shift}(f(x))$ |
| **平移不变** | 输入平移，输出**不变** | $f(\text{shift}(x)) = f(x)$ |

**卷积本身是平移等变的**：把物体挪一格，特征图上的强响应也挪一格。**平移不变性来自池化和全局池化**：不管物体在哪，最后取最大/平均，结果都一样。

这个区别是面试常见考点，也是理解 CNN 为什么有效的关键。

## 1.8 感受野：为什么深层能"看全局"

**感受野（Receptive Field）**：输出特征图上一个像素，对应输入图像上的区域大小。

递推公式：

$$r_{l} = r_{l-1} + (k_l - 1)\prod_{i=1}^{l-1}s_i$$

**简化记忆**：

- 两层 $3\times3$ 卷积（$S=1$）的感受野 = $3 + 2 = 5$（等价于一个 $5\times5$ 卷积）
- 三层 $3\times3$ = $3 + 2 + 2 = 7$（等价于 $7\times7$）

**这就是 VGG 的核心洞察**：用堆叠的 $3\times3$ 替代大核，感受野相同但参数更少、非线性更多（Day5 细讲）。

## 1.9 手写卷积：两种实现

### 1.9.1 朴素版（四重循环，直观）

```python
def conv2d_naive(x, w, b=None, stride=1, padding=0):
    """x: (C_in, H, W),  w: (C_out, C_in, k, k)"""
    C_in, H, W = x.shape
    C_out, _, k, _ = w.shape

    if padding:
        x = np.pad(x, ((0, 0), (padding, padding), (padding, padding)))

    H_out = (H + 2 * padding - k) // stride + 1
    W_out = (W + 2 * padding - k) // stride + 1
    y = np.zeros((C_out, H_out, W_out))

    for oc in range(C_out):                    # 每个输出通道
        for i in range(H_out):                 # 每个输出位置
            for j in range(W_out):
                region = x[:, i*stride:i*stride+k, j*stride:j*stride+k]
                y[oc, i, j] = (region * w[oc]).sum()   # 逐元素乘后求和
        if b is not None:
            y[oc] += b[oc]
    return y
```

**关键理解**：`(region * w[oc]).sum()` —— 这是"内积"，不是矩阵乘。所有通道的贡献被加在一起。

### 1.9.2 im2col 版（工业实现）

把每个位置的局部块"拉"成一行，然后一次矩阵乘法搞定（鱼书 7.4 的核心技巧）：

```python
def im2col(x, k, stride, padding):
    C, H, W = x.shape
    x = np.pad(x, ((0, 0), (padding, padding), (padding, padding)))
    H_out = (H + 2 * padding - k) // stride + 1
    W_out = (W + 2 * padding - k) // stride + 1
    cols = np.zeros((C * k * k, H_out * W_out))
    idx = 0
    for i in range(0, H_out * stride, stride):
        for j in range(0, W_out * stride, stride):
            cols[:, idx] = x[:, i:i+k, j:j+k].ravel()
            idx += 1
    return cols, H_out, W_out
```

然后：`Y = W_reshaped @ cols`，形状 `(C_out, H_out*W_out)` → reshape 成 `(C_out, H_out, W_out)`。

**为什么快**：把卷积变成了矩阵乘，可以直接调用高度优化的 BLAS 库。代价是内存占用（`im2col` 会放大 $k^2$ 倍）。这也是现代框架的实际做法。

## 1.10 常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `Conv2d` 权重形状理解错 | 顺序是 `(C_out, C_in, kH, kW)` | 记住"输出在前" |
| 输出尺寸算错 | 忘了加 1、或忘记取整 | 套公式并实际验证 |
| 多通道输入报形状错误 | 忘记核的 `C_in` 必须匹配 | 检查输入通道数 |
| 手写卷积结果和 PyTorch 差一点 | 忘了加偏置 / padding 方式不一致 | 逐项对比 |
| 以为卷积是平移不变的 | 混淆了等变与不变 | 见 1.7 |
| padding 后输出还是变小 | $S>1$ 时"same"不成立 | $P=(K-1)/2$ 只在 $S=1$ 时 same |
| 训练很慢 | 用了朴素四重循环 | 框架内部是 im2col |

## 1.11 心算练习答案

| 输入 | K | P | S | 输出 | 计算 |
| --- | --- | --- | --- | --- | --- |
| 28 | 3 | 1 | 1 | 28 | $(28+2-3)/1+1$ |
| 28 | 3 | 0 | 1 | 26 | $(28-3)/1+1$ |
| 28 | 3 | 1 | 2 | 14 | $(28+2-3)/2+1 = 13.5\to13$，$13+1=14$ |
| 32 | 5 | 2 | 1 | 32 | $(32+4-5)/1+1 = 32$ |
| 224 | 7 | 3 | 2 | 112 | $(224+6-7)/2+1 = 111.5\to111$，$111+1=112$ |

> 第 3、5 行要注意**向下取整发生在除法之后**：$(28+2-3)/2 = 13.5$，取整得 13，再加 1 得 14。
> 含义是：滑到最后，剩余不足一个核宽的部分会被**直接丢弃**（不补零、不缩小核）。
