## 一、误差的层次

| 术语 | 定义 | 能否观测 |
| --- | --- | --- |
| **训练误差 / 经验误差** | 模型在训练集上的误差 | 能 |
| **测试误差** | 模型在测试集上的误差 | 能 |
| **泛化误差** | 模型在**所有新样本**上的期望误差 | 不能，只能用测试误差近似 |

**记号**：

$$E_{\text{in}}(h) = \frac{1}{m}\sum_{i=1}^m \mathbb{1}[h(\boldsymbol{x}_i) \ne y_i] \quad \text{（训练误差）}$$

$$E_{\text{out}}(h) = \mathbb{E}_{(\boldsymbol{x},y)\sim \mathcal{P}}\left[\mathbb{1}[h(\boldsymbol{x})\ne y]\right] \quad \text{（泛化误差）}$$

**我们真正关心的永远是 $E_{\text{out}}$**，但只能通过有限的测试集去估计它。

**泛化误差的分解**（Day4 详细展开）：

$$E_{\text{out}} = \text{偏置}^2 + \text{方差} + \text{不可约噪声}$$

## 二、过拟合与欠拟合

### 2.1 定义

| 现象 | 训练误差 | 测试误差 | 本质 |
| --- | --- | --- | --- |
| **欠拟合** | 高 | 高 | 模型太简单，没学到数据的规律 |
| **过拟合** | 极低 | 高 | 模型太复杂，把噪声也学到了 |

### 2.2 直观图示（多项式拟合）

```
   数据点: 一排 y=sin(x) 上的点 + 噪声

   degree=1 (欠拟合)     degree=3 (合适)      degree=15 (过拟合)
      ────────                ╭─╮             ╭┐╭──╮ ╭╮
     /                      ╱   ╲           ╱ ││  │ │ ╲
    /                     ╱      ╲        ─╯  ╰╯  ╰─╯  ╰
   直线穿过所有点附近       平滑贴合趋势      剧烈震荡，穿过每个点
   训练/测试误差都大        两者都小         训练≈0，测试很大
```

### 2.3 成因与对策

| 过拟合的成因 | 对策 |
| --- | --- |
| 模型容量过大 | 减小模型 / 降低多项式阶数 |
| 训练数据太少 | 增加数据 / 数据增强 |
| 特征太多且无效 | 特征选择 / 降维 |
| 训练轮数过多 | 早停（Early Stopping） |
| — | 正则化（L1/L2）、Dropout、集成学习 |

| 欠拟合的成因 | 对策 |
| --- | --- |
| 模型容量不足 | 提高模型复杂度 |
| 特征表达能力弱 | 特征工程 / 加入非线性 |
| 正则化过强 | 减小 $\lambda$ |
| 训练不充分 | 增加迭代轮数 / 调学习率 |

> **一句话**：欠拟合是"没学会"，过拟合是"学过头"。

## 三、评估方法

### 3.1 留出法（Hold-out）

**做法**：把数据集 $\mathcal{D}$ 划分为互斥的两个集合：训练集 $S$ 与测试集 $T$。

$$S \cup T = \mathcal{D}, \quad S \cap T = \varnothing$$

**常见的划分比例**：训练 : 测试 = 7:3 或 8:2。

**关键注意事项**：

| 注意点 | 原因 |
| --- | --- |
| **保持数据分布一致** | 分类任务要**分层采样**（stratified），保证正负样本比例一致 |
| **多次随机划分取平均** | 单次划分结果不稳定，通常重复 5–10 次 |
| **训练集内再分验证集** | 用于调参，不能用测试集 |

**典型三段划分**：训练集 60% / 验证集 20% / 测试集 20%。

> **为什么不能用测试集调参？**
> 因为调参过程本身就是"用测试集信息去拟合模型选择"。你试了 100 组超参，选了测试集上最好的那一组，这个"最好"很可能只是**测试集上的随机起伏**。这样得到的性能估计是**乐观偏差（optimistically biased）**的，真实泛化能力会明显更差。

### 3.2 k 折交叉验证（k-fold Cross Validation）

**做法**：把 $\mathcal{D}$ 划成 $k$ 个大小相近的互斥子集，每次用 $k-1$ 个作训练、剩下的 1 个作验证，重复 $k$ 次取平均。

$$\text{CV}_k = \frac{1}{k}\sum_{i=1}^{k} E\!\left(h_i, D_i\right)$$

```
数据: [D1][D2][D3][D4][D5]          k = 5

轮次1: [训练][训练][训练][训练][验证]  → E1
轮次2: [训练][训练][训练][验证][训练]  → E2
轮次3: [训练][训练][验证][训练][训练]  → E3
轮次4: [训练][验证][训练][训练][训练]  → E4
轮次5: [验证][训练][训练][训练][训练]  → E5

结果 = (E1+E2+E3+E4+E5)/5
```

**$k$ 的取值**：

| $k$ | 特点 |
| --- | --- |
| 5 或 10 | **最常用**，偏差-方差折中较好 |
| 2 | 偏差大，训练集太小 |
| $m$（留一法） | 偏差极小，但方差大、计算代价高 |

**变体**：

- **分层 k 折**：保持每折的类别比例，不平衡数据必用；
- **重复 k 折**：重复 $r$ 次不同划分，进一步降低方差；
- **分组 k 折**：同一用户的多个样本必须分在同一折（防止信息泄漏）。

### 3.3 留一法（LOO, Leave-One-Out）

每次只留 1 个样本作测试集，其余全部训练，重复 $m$ 次。

- **优点**：训练集几乎等于原始数据集，偏差极小；结果确定（无随机性）；
- **缺点**：计算代价 $O(m)$ 次训练；**方差大**（各折的模型高度相关）；对不平衡数据可能每折只有一个类别。

**西瓜书结论**：LOO 的评估结果往往比 k 折**略乐观**，但方差更大。

### 3.4 自助法（Bootstrapping）

**做法**：有放回地采样 $m$ 次，得到与 $\mathcal{D}$ 同大小的训练集 $\mathcal{D}'$，未抽到的样本作测试集。

一个样本在 $m$ 次采样中从未被抽到的概率：

$$p_{\text{未被抽到}} = \left(1 - \frac{1}{m}\right)^m \xrightarrow{m\to\infty} \frac{1}{e} \approx 0.368$$

所以约 **36.8% 的样本**会成为测试集（称为**包外估计**，out-of-bag estimate）。

**适用场景**：

- 数据集**很小**，留出法会让训练集过小；
- 集成学习中天然可用（随机森林的 OOB 误差）；
- **不适合**：数据量足够时（会引入重复样本，改变数据分布）。

## 四、调参与最终模型

### 4.1 标准流程

```
完整数据集 D (100%)
│
├── 训练+验证集 D_trainval (80%)          测试集 D_test (20%)  ← 只用一次！
│   │
│   ├── 训练集 (通过 k 折 CV 划分)
│   └── 验证集 (用于选择超参数)
│
└── 确定超参数后，用 D_trainval 全部数据重新训练 → 最终模型
└── 在 D_test 上评估 → 报告结果
```

**关键点**：

1. **验证集用于选超参**（学习率、正则化系数、树深度……）；
2. 选好超参后，**用全部训练数据重新训练**（不要浪费那部分验证数据）；
3. **测试集只用一次**，最后报告结果；
4. 若必须多次看测试集，那就承认这是"用测试集调参"，需额外留一个 hold-out 集。

### 4.2 网格搜索与随机搜索

| 方法 | 做法 | 特点 |
| --- | --- | --- |
| 网格搜索 | 遍历超参组合的笛卡尔积 | 维度高时指数爆炸 |
| 随机搜索 | 随机采样超参组合 | 维度高时更高效（Bergstra & Bengio, 2012） |
| 贝叶斯优化 | 用代理模型指导采样 | 样本效率最高，实现复杂 |

> **经验**：超参中真正重要的通常只有 2–3 个（学习率、正则化强度、模型容量）。先把这几个调好，再考虑其他。

## 五、数据划分的坑

| 坑 | 后果 | 正确做法 |
| --- | --- | --- |
| 分类数据随机划分不分层 | 小类别可能在某一折中完全消失 | `StratifiedKFold` |
| 时间序列随机划分 | **未来信息泄漏到训练集**，结果虚高 | 按时间顺序切分，或用时间序列 CV |
| 同一用户/设备的多条记录分到不同折 | 数据泄漏（同一实体出现在训练与验证） | `GroupKFold` |
| 先做全局标准化再划分 | 测试集统计量泄漏进训练 | **先划分，再在训练集上 fit 标准化器** |
| 先做特征选择再交叉验证 | 选择过程用了验证集信息 | 把特征选择放进 CV 的 pipeline 内 |
| 用测试集反复调参 | 严重乐观偏差 | 只用验证集 |

> **数据泄漏（Data Leakage）是机器学习实验中最隐蔽、最常见的错误。** 它的表现是：离线指标极其漂亮，上线后效果大幅下滑。

## 六、代码实践

```python
import numpy as np

def stratified_kfold(y, k=5, seed=0):
    """手写分层 k 折划分: 返回 k 组 (train_idx, val_idx)"""
    rng = np.random.default_rng(seed)
    folds = [[] for _ in range(k)]
    for label in np.unique(y):
        idx = np.where(y == label)[0]
        rng.shuffle(idx)
        for i, j in enumerate(idx):
            folds[i % k].append(j)          # 轮转发牌，保证每折比例一致
    result = []
    all_idx = np.arange(len(y))
    for i in range(k):
        val = np.array(sorted(folds[i]))
        train = np.setdiff1d(all_idx, val)
        result.append((train, val))
    return result

y = np.array([0]*90 + [1]*10)               # 9:1 不平衡
for i, (tr, va) in enumerate(stratified_kfold(y)):
    print(f"fold{i}: train 正例率={y[tr].mean():.3f}  val 正例率={y[va].mean():.3f}")
    # 每折的正例率都约等于 0.1 => 分层成功
```

1. 留出法 vs 5 折 CV vs 10 折 CV 的稳定性对比；
2. 分层 vs 非分层在不平衡数据上的差异；
3. 用验证曲线（validation curve）选超参数；
4. 演示"用测试集调参"导致的乐观偏差有多大。

**基础**

2. 数据集含 1000 个样本，用 10 折交叉验证做一次评估，共训练了多少次模型？
3. 计算 $m=1000$ 时自助法的包外样本比例。

**进阶**

4. 推导 $\lim_{m\to\infty}(1-1/m)^m = 1/e$。
5. 某数据集 95% 是负例、5% 是正例。用普通 5 折划分，某一折可能完全没有正例吗？概率大约是多少？用分层划分后呢？
6. 假设你试了 200 组超参，每组都在测试集上评估，选出最好的那组的测试准确率是 92%。请解释为什么真实性能很可能远低于 92%（提示：考虑最大值统计量的偏差）。

**思考题**

7. 为什么"先对全量数据做标准化，再划分训练/测试集"会造成数据泄漏？请举一个具体的数值例子说明它对测试误差的乐观影响。
8. 在一次 Kaggle 比赛中，你发现 5 折 CV 分数 0.85，公开榜 0.83，私有榜 0.72。请分析可能的原因（提示：从数据泄漏、分布偏移、过拟合 CV 三个角度）。

<details>
<summary>第 3 题答案</summary>

$$(1 - 1/1000)^{1000} \approx e^{-1} \approx 0.3679$$

约 36.8% 的样本从未被抽到，可作测试集（包外估计）。
</details>

<details>
<summary>第 5 题提示</summary>

普通 5 折：每折 200 个样本，期望含 10 个正例，实际服从超几何分布。$P(\text{正例数}=0)$ 虽小但非零。

用 `StratifiedKFold` 后，每折强制含 $0.05 \times 200 = 10$ 个正例，比例严格保持。
</details>

## 八、一句话总结

**评估方法的核心只有一条纪律：训练集学参数，验证集选超参，测试集只报告一次。破坏任何一条，你的所有实验数字都会失去意义。**
